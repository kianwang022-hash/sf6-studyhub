## Spacing/contact-timing condition audit

Dhalsim's long active limbs require a different verification rule from ordinary footsie normals.

- official-reference table records baseline values.
- UFD shows large practical ranges for long slides/limbs because late active contact changes when recovery begins relative to hit/blockstun.
- therefore 2LK / 2MK / 2HK late-contact claims are conditioned, not universal.
- no learner row may infer “safe because long” from reach alone.

## Projectile geometry audit

- current UFD models effective post-recovery hit/block budget around +29/+27 for a later projectile contact.
- learner language must explicitly say this is delayed projectile geometry, not raw close-range frame advantage.
