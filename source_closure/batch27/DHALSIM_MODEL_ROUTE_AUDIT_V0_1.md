# Dhalsim Character Model ↔ Route Audit v0.1

Status: PHASE H PASS

## Claim 1 — Dhalsim cannot be taught as “stay away forever”

Evidence:
- current Year4 guide explicitly states it is difficult to win only by repeatedly handling approaches; opponents continue to jump and Drive Impact, so Dhalsim eventually needs offense.
- forward throw, Yoga Flame/Blast knockdowns and corner setplay all provide current close-pressure states.
- M Yoga Blast -> forward Teleport directly converts a knockdown into point-blank +3.

Judgment: SUPPORTED.

## Claim 2 — range geometry must precede combo complexity

Evidence:
- many standing/crouching normals are unusually long and slow compared with ordinary characters.
- 2LK / 2MK / 2HK have long active windows, and UFD records practical advantage ranges that shift with late contact.
- Yoga Fire and Yoga Arch shape different approach lanes/timings.

Judgment: SUPPORTED.

The learner must reinterpret range before memorizing mobility trees.

## Claim 3 — one Teleport conversion belongs in S0

Evidence:
- M Yoga Blast +42 -> immediate forward P Yoga Teleport -> point-blank +3 is explicitly published as an Oki-focus route.
- it cleanly demonstrates that remote control can become close pressure.
- raw Teleport does not receive the +3, so the setup naturally teaches “earned mobility”.

Judgment: SUPPORTED.

Hiding Teleport entirely until late would erase the key state transition; teaching raw Teleport neutral flowcharts would be premature.

## Claim 4 — Float belongs after the ground loop

Evidence:
- Aerial Yoga Float > j.HP > 1HP > M Yoga Flame is an important current basic route.
- however stable 4MK > M Yoga Flame and ground/anti-air tools already create a complete S0 round.
- Float introduces trajectory/height complexity that is not required to understand the first identity loop.

Judgment: SUPPORTED.

## Claim 5 — exact plus values require state ownership

Evidence:
- M Flame +33, H Flame +45, OD Flame +51 are distinct.
- M/H Blast +42, L Blast +39 are distinct.
- corner H Blast -> L Blast creates +37 setplay.
- Yoga Arch effective plus frames arise from delayed projectile contact.
- long limbs themselves can change practical advantage through late active contact.

Judgment: SUPPORTED.

## S0 identity gate

Accepted S0:
- Yoga Fire plus long 5MP / 2MK geometry.
- 4MP close-angle anti-air and 5HK far-angle anti-air.
- 4MK > M Yoga Flame +33 close confirm.
- exactly one remote-to-close route:
  2LP > CDR > 5LP > 4MP > M Yoga Blast +42 > immediate forward P Yoga Teleport -> point-blank +3.
- no full Float/Teleport tree.

Judgment: PASS.

This cannot be copied to another zoner by renaming a projectile: Dhalsim's long active limbs, lane-specific anti-air and knockdown-covered Teleport conversion change the neutral model itself.

## Transfer check

Transfers in:
- projectile control.
- anti-air discipline.
- strike / throw.
- knockdown -> Oki.
- position value.

New:
- long-limb contact timing.
- multi-trajectory projectile geometry.
- anti-air by lane.
- knockdown-covered Teleport conversion.
- far-control <-> close-cashout state transition.
- Float / Drill / Comet height later.

Unlearn:
- all neutral lives at conventional footsie range.
- long reach implies safety.
- one frame row describes every spacing.
- zoner should stay away after knockdown.
- raw Teleport owns +3.
- every +42/+45/+51 state is interchangeable.

## Audit outcome

Character Model v0 survives route/Oki evidence.

Freeze learner center:

range geometry -> force predictable approach -> lane anti-air / stable knockdown -> one earned forward Teleport conversion -> close strike/throw -> return to range when opponent escapes -> delayed projectile/Float/corner setplay layer only after this loop is stable.

Proceed to S0–S4 and learner assets.
