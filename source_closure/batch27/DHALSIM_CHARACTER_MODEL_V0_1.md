# Dhalsim Character Model v0.1

Status: PROVISIONAL — must survive Route/Oki audit  
Character: DHALSIM  
Primary evidence: SRC03 / SRC05 / SRC06

## essence_short

Dhalsim先用长肢与火球几何逼对手从可预测的路线接近；一旦anti-air或击倒成功，就用Teleport/Float把远距离控制兑现成近身回合，而不是永远后退。

## essence_detail

Dhalsim不是“站最远处一直按长手”的角色。长肢、Yoga Fire和Yoga Arch的第一任务，是让对手的前走、跳跃、Drive Impact和等待变得可预测；但current Year4指南明确指出，只靠一次又一次把对手挡回去很难赢，最终必须主动进攻。Dhalsim真正独特的循环因此是“远距离几何 -> 可预测接近 -> 反空/击倒 -> 近身转换”。例如M Yoga Blast命中+42后立刻forward P Yoga Teleport，可以直接变成point-blank +3；也就是说一个远端/中距离conversion可以瞬间变成strike/throw/Float的近身turn。与此同时，他的长肢Normal不是普通脚战按钮：2LK/2MK/2HK等拥有很长active window，实际命中/被防优势会随接触时机和距离改变，不能只看一张固定表。成熟Dhalsim会在“继续保持几何优势”与“已经赚到knockdown，现在Teleport进去现金化”之间切换，而不是把zoner和rushdown当成两套互不相干的模式。

## force_opponent_to

- 在长肢与Yoga Fire覆盖下选择前走、跳、DI、Parry或等待，而不是自由接近。
- 跳跃路线必须经过4MP / 5HK / Yoga Blast等anti-air lanes。
- M Yoga Blast等击倒后必须立刻处理forward Teleport带来的近身turn。
- Yoga Arch在空中滞留时，不能只按普通地面节奏前进。
- 角落+37/+45/+51等状态下必须处理真正的近身setplay。

## create_respect_with

- 5MP / 5HP / 2MK等长距离接触。
- Yoga Fire逼迫跳跃/等待。
- 4MP Yoga Uppercut近角度anti-air。
- 5HK远角度anti-air。
- 4MK > M Yoga Flame稳定close confirm。
- M Yoga Blast +42 -> forward Teleport +3身份路线。

## payoff_after_respect

- 对手开始犹豫接近后，Yoga Fire / Arch可以继续塑造路线。
- anti-air或knockdown后，forward Teleport把远程优势换成point-blank offense。
- Float让空中停留/落点成为第二个几何维度。
- forward throw +31与corner +37 setplay进一步维持close turn。
- 对手为了逃近身turn后重新跳/后退，又回到Dhalsim擅长的远距预测。

## core_tradeoff

继续保持远距离几何控制，还是在已经赚到knockdown后主动Teleport/Float进去现金化。过早进场会放弃长手优势；永远不进场又会让对手无限重试jump/DI/approach。

## successful_round

1. 用长肢 / Yoga Fire / Yoga Arch塑造对手接近路线。
2. 识别jump/DI/forward walk，用anti-air或counter拿击倒。
3. 最稳时用4MK > M Yoga Flame拿+33；有Drive时用M Yoga Blast route拿+42。
4. 选定值得的knockdown后forward Teleport，把远距离结果转成point-blank turn。
5. 近身用4MK / throw / delayed strike / Float继续一轮。
6. 对手逃出去后重新建立远距离几何，而不是执着贴身或执着后退。

## common_misplays

- 把“长手角色”理解成永远后退，击倒后也不现金化。
- 看固定frame table就认为所有长肢每次都是同一正负帧。
- 因为长肢很远就把它们当安全poke，忽略DI/whiff/pushback风险。
- raw forward Teleport进场，误以为它自带+3。
- S0就同时学Float、Teleport cross-up、Comet、Arch全部空中树。
- 把M Blast +42、corner +37、H Flame +45等数字跨route泛化。

## unique_decision

Dhalsim新增的是geometry-to-proximity conversion：远程工具先塑造对手的路径与时机；一旦得到特定knockdown，就决定是否用Teleport/Float把“远距离控制”转换成“近距离frame advantage”。

## transfer_in

- projectile / anti-air纪律。
- strike / throw / shimmy。
- knockdown -> Oki。
- 位置价值判断。

## new_skill

- long-limb spacing / active-contact timing。
- projectile geometry而非单一直线火球。
- anti-air by approach lane。
- knockdown -> forward Teleport proximity conversion。
- Float / Drill / Comet的高度与落点管理。
- far-control vs close-cashout的状态切换。
