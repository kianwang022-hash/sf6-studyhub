# Alex Character Model v0.1

Status: PROVISIONAL — must survive Route/Oki audit  
Character: ALEX  
Primary evidence: SRC02 / SRC03 / SRC06 / SRC07

## essence_short

Alex先用5MP、4MK和稳定击倒逼对手尊重；尊重一出现，就用Power Bomb与Prowler高低投分支让防守不能只押一种答案。

## essence_detail

Alex不是“走上去猜指令投”的角色。当前Year4把5MP命中加强到+4、4MK被防加强到+2，并让2HK命中可以直接进入Prowler；这些改动都在强化同一件事：先用普通地面接触和稳定击倒把回合拿住，再把对手的防守选择越压越窄。Light和5MP可以稳定收进Flash Axe或Aerial Knee Smash，Knee、前投和M Flash Axe又给出明确的下一拍。等对手开始愿意站着防，Power Bomb才从“高风险裸猜”变成真实威胁；而Prowler不是让你在neutral里长期蹲着等，而是从M Flash Axe、2HP、2HK命中或charged button等已赚到的入口切进去，用Heavy Lariat正帧、Air Stampede overhead、Sweep low、Prowler throw等不同答案让对手不能固定只防一种。Alex真正的循环是：稳定strike先买到respect，再用throw/stance把respect兑现；对手为了躲投而跳、后退、乱按时，普通strike和anti-air又重新升值。

## force_opponent_to

- 尊重5MP与稳定confirm，不敢每次都抢。
- 处理4MK Block +2后的下一拍，而不是把回合当成已经结束。
- 在M Flash Axe / 2HK等明确入口后处理Prowler不同分支。
- 一旦开始站防，就必须考虑Power Bomb。

## create_respect_with

- 5MP / 2MP普通ground contact。
- Light -> L Flash Axe稳定确认。
- 5MP -> H Aerial Knee Smash稳定击倒。
- 4MK Block +2后的5LP / strike。
- H Knee、forward throw后的具体Oki。

## payoff_after_respect

- H Power Bomb进入真实read。
- Prowler Heavy Lariat / Air Stampede / Sweep / throw构成高低投分支。
- 对手为躲grab跳/后退/乱按后，strike与anti-air再次变强。
- corner Flying Cross Chop +8把一次route变成更强的下一轮。

## core_tradeoff

继续用稳定strike/Oki守住回合，还是把已赚到的入口投入Prowler / Power Bomb，换更高回报但承担更高commitment。Alex的高收益不是免费，而是建立在先赚到respect与entry上。

## successful_round

1. 用5MP / 2MP / light确认拿到第一次接触。
2. 以Flash Axe或Aerial Knee Smash拿稳定结果。
3. 用4MK +2、throw/Knee Oki继续strike，让对手开始尊重。
4. respect成立后加入Power Bomb，或从明确入口进入Prowler。
5. 对手开始jump / backwalk / mash逃grab时，用strike与anti-air惩罚。
6. 进角后用Flying Cross Chop +8等状态把下一轮继续放大。

## common_misplays

- neutral里裸进Prowler，把不能block的commitment当成常驻模式。
- 看到4MK +2就把Power Bomb当guaranteed。
- Power Bomb +15后假装有保证贴脸Oki。
- 为了“像Alex”每回合都猜command grab，反而不先用strike建立respect。
- 把Sweep/active-frame/角落+8等条件路线泛化成默认答案。

## unique_decision

Alex新增的是choice-denial layering：先用正常SF6的strike/plus/Oki把对手压到愿意防，再用Power Bomb和Prowler多分支让“只防一种”失效；他的角色特性来自入口后的分支质量，不来自开局就赌抓。

## transfer_in

- Marisa / Lily / Manon已经学过的respect -> command-grab反馈。
- grounded spacing / anti-air / strike-throw。
- 大体型角色耐心拿contact再现金化的节奏。

## new_skill

- Prowler不是neutral常驻，而是earned-entry stance。
- 同一个Prowler入口要在plus strike / overhead / low / throw之间按对手反应切换。
- 4MK +2与Knee/throw Oki是制造respect的桥，不是保证抓。
- damage / stance entry / side switch / Oki之间的route取舍。

## unlearn

- “大体型command-grab角色就应该优先裸抓”。
- “有plus frame就等于throw guaranteed”。
- “Prowler可以在neutral里长期蹲着等”。
- “Power Bomb命中后一定有贴脸继续抓”。
