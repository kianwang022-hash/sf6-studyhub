# E. Honda Character Model v0.1

Status: **PROVISIONAL — must survive Route/Oki audit**
Character: **E. HONDA**
Sources: SRC03 / SRC04 / SRC05

## essence_short

Honda一边保存Headbutt / Smash的charge，一边用正常地面和Sumo Dash拿击倒；真正的角色回报是先让对手尊重strike，再让6F Oicho Throw变成高价值威胁。

## essence_detail

Honda不是“蓄力好以后就Headbutt”的角色。Charge只是后台资格：你在普通防守、地面按钮和等待跳跃时保存后/下蓄力，让Headbutt和Sumo Smash随时有可能出现。但当前Game Plan真正反复出现的是另一条链：5MP/普通contact进入Sumo Dash / Taiho Cannon Lift，接Sumo Smash或Headbutt拿到+23、+40、+42等击倒预算，再用meaty strike、throw和Oicho Throw继续压。Oicho本身是6F高伤command grab，但它不是“击倒后自动能抓”；只有对手先因为你的strike/meaty愿意站着防，Oicho才真正值钱。

这让Honda成为Charge章向高收益猜拳章的桥：Guile管理空间，Dee Jay管理节奏，Honda开始管理“respect”。成熟Honda会先用+1的5MP、Hands、Sumo Smash Oki、Headbutt/Smash charge威胁让对手收手，再在对手防守倾向形成后用Oicho或shimmy兑现。Sumo Spirit和OD Teppo +3属于更后面的pressure升级，不应该抢走这条基础因果链。

## force_opponent_to

- 尊重Headbutt / Sumo Smash的charge威胁，不敢只按一个地面节奏推进。
- 在Sumo Smash +23 / Headbutt / Teppo击倒后先防meaty strike。
- 一旦开始站着防，Oicho Throw会直接惩罚过度respect。
- 对手为躲Oicho跳/后退以后，strike和active-frame meaty再次变强。

## create_respect_with

- 5MP block +1：最清楚的普通respect点。
- L Hundred Hand Slap：基础light ender。
- Sumo Smash +23：S0/S1稳定Oki预算。
- Sumo Dash -> Teppo / Taiho：接触转换与高预算击倒。
- charge-ready Headbutt / Smash：让neutral不能只盯地面按钮。

## payoff_after_respect

- Oicho Throw 6F高伤command grab变得可信。
- shimmy开始惩罚跳/tech。
- Sumo Smash dash +4可以不断重建strike vs Oicho。
- +42/+45/+64状态进一步放大safe jump与command-grab循环。
- Sumo Spirit后Hands变得更安全，pressure继续升级。

## core_tradeoff

稳定strike/Oki vs Oicho高收益猜拳。另一个取舍是保charge与主动前进/走位：Honda不应该为了charge僵死，也不应该为了Oicho在没有respect时硬猜。

## successful_round

1. 普通防守/按钮里存charge
2. light / 5MP / Sumo Dash拿contact
3. Sumo Smash / Headbutt / Teppo拿击倒预算
4. 先用meaty strike建立respect
5. 对手开始站防后加入Oicho
6. 对手跳/后退躲Oicho后，strike/shimmy重新变强

## common_misplays

- 一有charge就Headbutt，ground game消失。
- 击倒后马上command grab，不先建立respect。
- 把+42 safe jump当所有Headbutt/Teppo都成立。
- Sumo Spirit还没必要就花52F去启动。
- 把OD Teppo +3当所有Sumo Dash follow-up都plus。

## unique_decision

Honda新增的是“respect conversion”：charge帮助你制造大击倒和必须防的strike，Oicho再把这份respect换成command-grab收益。

## transfer_in

- Guile/Dee Jay的charge storage基本功。
- grounded spacing、strike / throw / shimmy。
- punish / corner / knockdown -> Oki。

## new_skill

- strike -> respect -> Oicho反馈循环。
- Sumo Dash -> Teppo / Taiho路线分工。
- Sumo Smash +23与+40/+42高预算Oki。
- Sumo Spirit改变Hundred Hand Slap状态。
- command-grab不是guaranteed Oki的纪律。

## unlearn

- charge角色主要任务就是保持charge并立刻用special。
- command grab有机会就应该马上猜。
- 所有大knockdown都自动给贴脸Oicho。
- Teppo/Spirit升级应该第一天全部学。
