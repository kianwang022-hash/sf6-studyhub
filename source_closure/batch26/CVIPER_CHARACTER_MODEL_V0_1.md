# C. Viper Character Model v0.1

Status: PROVISIONAL — must survive Route/Oki audit  
Character: C. VIPER  
Primary evidence: SRC03 / SRC05 / SRC06

## essence_short

Viper先用st.MP +1和稳定Thunder Dash击倒跑普通回合；真正新增的是High Jump Cancel——把已经命中的Normal重新路由进special，让低段、重拳和Seismic Hammer都能变成她自己的转换链。

## essence_detail

C. Viper不是“操作越难越像Viper”。她的第一层仍然是普通SF6：st.MP被防+1后做2LP、throw、shimmy；light确认到H Thunder Dash再接Tracer Combination，可以拿到约+25击倒，dash后还有+4..+5继续strike/throw。角色真正独特的地方是High Jump Cancel：除2HK和unique attacks外，多数ground normal都能在hit/block后取消到High Jump，而High Jump的pre-jump又可以special cancel，于是原本不能直接special-cancel的st.MK、cr.MK、st.HP等也能被“转接”进Thunder Dash、Seismic Hammer等route。Year4又把st.MK提高到Hit +5、cr.MK保持Hit +5/-1，使这种normal→HJC→special grammar更实用。成熟Viper不是每次都做最复杂HJC，而是在普通Oki已经成立后，根据opening价值选择：最稳Thunder Dash、HJC conversion、Seismic launcher、Burning Kick hit/block分支，还是直接保留Drive与位置。

## force_opponent_to

- 尊重st.MP Block +1后的2LP / throw / shimmy。
- H Thunder Dash -> Tracer击倒后处理+4..+5的下一拍。
- 不能放心后退，因为Year4 cr.MK / st.MK都能通过HJC转成角色route。
- Seismic Hammer命中后必须处理空中route与setplay，而不是只吃一次700伤害。
- Burning Kick被防后要考虑Double Burn，命中时则要考虑Knuckled Pursuit延伸。

## create_respect_with

- st.MP Block +1。
- light -> H Thunder Dash -> Tracer Combination。
- st.MK -> st.LK -> M Thunder Dash。
- H Thunder Dash / Tracer knockdown Oki。
- cr.MK HJC route作为低段conversion威胁。

## payoff_after_respect

- cr.MK / st.MK / st.HP等可以用HJC重新接入special route。
- Seismic Hammer launch可以转空中Burning Kick / Thunder Dash / corner carry。
- Burning Kick hit/block可分别选Knuckled Pursuit或Double Burn。
- +42/+44/+45 exact states进一步转safe jump / jump-in / active meaty。
- SA1 install后HJC和special follow-up不再消耗Drive，才真正进入高密度Viper。

## core_tradeoff

用最稳定的普通confirm/Oki守住Drive和位置，还是花Drive把normal通过HJC升级成更强的conversion、carry和setplay。复杂route只有在它买到明确价值时才值得执行。

## successful_round

1. 用st.MP +1、cr.MK、st.MK赢ground contact。
2. 最稳时confirm到H Thunder Dash -> Tracer，拿+25左右Oki。
3. dash后用st.MP / throw / shimmy继续建立respect。
4. opening更值钱时，用一条已练熟的HJC route把normal转成special。
5. Seismic / Burning Kick route把人送角或拿exact jump-in state。
6. SA1 /高复杂度HJC只在资源与回合价值值得时打开。

## common_misplays

- 入门先练最大HJC长连，st.MP +1和击倒Oki反而不会。
- 把HJC当免费special cancel，忘记Drive成本。
- 说“所有normal都能HJC”，忽略2HK/unique attack例外。
- H Thunder Dash没确认就裸交，Block -24被罚。
- Burning Kick命中/被防都按同一个follow-up。
- 把+42/+44/+45安全跳数字脱离exact route使用。

## unique_decision

Viper新增的是cancel-routing grammar：normal contact可以先HJC，再在pre-jump中取消到special，把“这个normal原本能不能special cancel”从固定属性变成资源与执行选择。

## transfer_in

- ordinary grounded spacing。
- strike / throw / shimmy。
- knockdown -> Oki。
- Drive资源价值判断。
- Chun-Li的“route grammar优先于背全招”学习习惯。

## new_skill

- High Jump Cancel input / Drive ownership。
- normal -> HJC -> special route。
- hit-confirmed Thunder Dash / Tracer Oki。
- Burning Kick hit vs block follow-up split。
- Seismic Hammer air conversion。
- exact-state jump-in/setplay ownership。

## unlearn

- “复杂角色就该一直走最复杂route”。
- “HJC免费”。
- “所有normal都能HJC”。
- “Burning Kick后固定一个follow-up”。
