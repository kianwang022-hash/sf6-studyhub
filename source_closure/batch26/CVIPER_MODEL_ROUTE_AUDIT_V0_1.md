# C. Viper Character Model ↔ Route Audit v0.1

Status: PHASE H PASS

## Claim 1 — ordinary pressure exists before HJC complexity

Evidence:
- 5MP is current Block +1.
- current guide explicitly gives 5MP -> 2LP / throw / 5HK / 2MK pressure.
- H Thunder Dash -> Tracer produces a short, concrete +25..26 knockdown loop.
- Year4 5MK +5 supports a simple meterless 5MK -> 5LK -> M Thunder Dash route.

Judgment: SUPPORTED.

Viper does not need a long HJC route to become playable.

## Claim 2 — HJC is the character's unique route grammar

Evidence:
- current UFD notes all standard normals except 2HK are HJC-capable.
- High Jump can special-cancel during pre-jump.
- current guide specifically promotes 2MK / 5MK -> HJC M Thunder Dash and HJC Seismic routes.
- st.MK and cr.MK are not ordinary direct-special-cancel owners, so HJC truly changes their route possibilities.

Judgment: SUPPORTED.

## Claim 3 — one HJC route belongs in S0, full tree does not

Evidence:
- current game plan begins with cr.MK / st.MK / Seismic contact and HJC conversion.
- the route guide also supplies simple meterless and ordinary pressure routes.
- therefore hiding HJC entirely would erase identity, but exposing every HJC/Seismic variation immediately would be unnecessary.

Judgment: SUPPORTED.

## Claim 4 — complexity should be value-driven

Evidence:
- HJC costs Drive outside SA1 install.
- Tracer also costs Drive.
- ordinary routes can preserve Drive.
- higher-complexity routes buy concrete values: carry, launcher, +42/+44/+45 setplay, corner damage or SA install economy.

Judgment: SUPPORTED.

## Claim 5 — hit/block branches matter more than move-name memorization

Evidence:
- Burning Kick hit supports Knuckled Pursuit.
- Burning Kick block supports Double Burn +2.
- H Thunder Dash is -24 on block and therefore requires confirmation.
- aerial Burning Kick advantage changes with height.

Judgment: SUPPORTED.

## S0 identity gate

Accepted S0:
- 5MP Block +1 -> 2LP / throw.
- 2LP > 2LP > 5LK > H Thunder Dash > Tracer Combination.
- H Tracer +25..26 -> dash +4..5 -> 5MP / throw / 2MK.
- Year4 5MK > 5LK > M Thunder Dash meterless route.
- 2MK > HJC > M Thunder Dash > Tracer Combination as exactly one identity route.
- 5HK anti-air.

Judgment: PASS.

This is specifically C. Viper: HJC rewrites what 2MK can route into while the base turn remains ordinary SF6.
