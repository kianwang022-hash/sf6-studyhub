## Rule

A route is **not** promoted merely because its string is now complete.

A learner-facing survivor must buy a distinct practical job that is not already represented by a simpler route in the same opportunity:

- materially different Oki / next turn;
- meaningful carry / position / side switch;
- distinct character resource gain / spend;
- a real command-grab / state payoff;
- lower execution / lower resource for the same job;
- a true kill / Super cashout.

If two routes differ mainly by starter cosmetics or a small unclosed damage difference while ending in the same state, keep only one learner-facing representative.
