## 4. Current Game Plan evidence

The maintained current Game Plan is not “stand full screen and trade fireballs.”

Repeated structure:

High Tiger Shot -> read opponent movement / jump / crouch -> 5MP / 2MP / 5MK contact -> hit confirmation / corner progress -> H Tiger Knee Crush end-state -> safe-jump or plus-state -> 5MP +2 strike/throw -> punish mash / PC

This makes projectile control a **movement-shaping layer** whose value is realized by Sagat's long normals and high-value knockdown states.

## 7. Important curriculum correction

The frozen transfer map correctly places Sagat at the zoning-heavy end of the standard-character bridge, but “fireball zoning” is too coarse as final learner language.

Current evidence supports a more precise model:

> Tiger Shot changes how the opponent is allowed to move; Sagat then cashes that movement constraint out with long mediums, Step High Kick, Tiger Knee / Uppercut knockdowns, and safe-jump / strike-throw follow-ups.

This is the hypothesis for Phase B.
