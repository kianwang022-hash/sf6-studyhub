# Sagat Character Model v0.1

Status: **PROVISIONAL — must survive Route/Oki audit**  
Character: **SAGAT**  
Sources: SRC03 / SRC04 / SRC05

## essence_short

Sagat用Tiger Shot限制对手“怎么动”，再用长中拳脚和Step High Kick抓那个被迫的移动；真正的收益不是多发几颗波，而是把对手送进高价值击倒、safe jump和+2打投。

## essence_detail

Sagat确实比前面的标准角色更重视fireball，但如果把他理解成“站最远一直扔波”就会学歪。Tiger Shot的第一作用是改变对手的移动规则：High Tiger Shot逼他考虑跳、蹲、Perfect Parry、前走节奏和Drive；一旦对手为了处理火球改变位置，Sagat的5MP、2MP、5MK、6HK这些长而有价值的拳脚就更容易接住那个反应。当前Game Plan也反复把火球之后的收益接到medium normal、Tiger Knee / Uppercut击倒、+42 safe jump和5MP block +2的strike/throw上。Sagat真正要学的是“空间限制 -> 读反应 -> 地面兑现 -> 高价值下一轮”，而不是单独提高fireball数量。火球过量、被跳中一次，可能比少发一颗更亏；所以成熟Sagat会不断在继续发波、占长拳脚位置、准备升龙反空之间切换注意力。

## force_opponent_to

- 不能自由前走；High Tiger Shot要求他蹲、跳、PP、parry或改变节奏。
- 不敢随便跳过火球，因为Tiger Uppercut随时承担反空。
- 被逼到中距离后必须尊重5MP +2、6HK +4以及长拳脚的空间占位。

## create_respect_with

- High Tiger Shot：塑造对手的移动/跳跃时机。
- Tiger Uppercut：惩罚跳跃，让fireball真正能限制地面。
- 5MP / 2MP / 5MK：在对手被火球改变节奏后接住地面移动。
- 6HK Step High Kick：16F / Block +4，成为更重的近中距离respect工具。
- Tiger Knee：把确认转成较大Oki预算和位置推进。

## payoff_after_respect

- 更容易用长medium拿到稳定contact。
- Tiger Knee / Uppercut把接触换成+32、+36…49等不同Oki预算。
- H Tiger Knee特定airborne hit可进入+42 safe-jump family。
- 5MP block +2让strike / throw / shimmy真正成立。

## core_tradeoff

继续fireball塑造空间 vs 提前占normal位置准备抓移动/跳跃。次级取舍是end-state：Tiger Uppercut稳定，Tiger Knee可能买更大Oki/位置，但spacing和hit state更条件化。

## successful_round

1. Tiger Shot限制前走/跳跃节奏
2. 持续看跳，Tiger Uppercut保证fireball威胁可信
3. 对手改变移动后，用5MP / 2MP / 5MK抓contact
4. 选择Tiger Uppercut或Tiger Knee end-state
5. 用+2打投、safe jump或角落继续压力
6. 对手改变应对后，再决定继续发波还是站normal位置

## common_misplays

- 把“zoner”理解成一直发波，发波后不看跳。
- 对手已经在适合5MP/5MK的距离还继续机械Tiger Shot。
- 把Tiger Knee +36…49范围压成一个固定Oki数字。
- 看到H Tiger Knee +42就当成所有命中都能safe jump，忽略airborne-hit条件。

## unique_decision

相对Ryu/Ken/Luke/Terry，Sagat新增的核心是“projectile先改变对手的movement budget，再用长normal兑现”。你的注意力必须在继续发波、占地面按钮位置和准备Tiger Uppercut之间动态切换。

## transfer_in

- projectile / anti-air基本框架。
- strike / throw / shimmy。
- punish / DI / corner / SA。
- knockdown -> Oki。

## new_skill

- 用不同Tiger Shot节奏塑造移动，而不是只做chip/伤害。
- fireball后持续保留反空注意力。
- 长normal与projectile之间的空间接力。
- Tiger Knee不同hit state / spacing对应的Oki预算。
- +42 safe jump只在正确airborne-hit条件使用。

## unlearn

- zoning = 尽量多发fireball。
- 所有标准角色都应该把2MK DRC当同样的主低段入口。
- Tiger Knee的击倒数字可以脱离距离/命中状态背成固定值。
