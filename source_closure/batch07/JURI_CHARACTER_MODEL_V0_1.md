# Juri Character Model v0.1

Status: **PROVISIONAL — must survive Route/Oki audit**  
Character: **JURI**  
Sources: SRC03 / SRC04 / SRC05

## essence_short

Juri先用非常完整的地面确认拿M Fuhajin：这一条同时给你stock和下一轮；真正的角色决策发生在后面——这颗stock现在花掉放大opening，还是留着让未来选项更多。

## essence_detail

Juri不是“先攒满stock才开始玩”的角色。当前训练顺序最先要求的是5MP > 2MP > M Fuhajin、低段light > M Fuhajin，以及Fuhajin后的forward dash打/投/shimmy。也就是说，她的基础回合本身已经能一边拿稳定击倒/下一轮，一边把stock存起来。相对Jamie，“资源投资”没有那么强的当前回合牺牲感；Juri更常见的核心问题是：已经有stock以后，这次opening要不要马上把它换成Boosted Saihasho / Ankensatsu / Go Ohsatsu的伤害、carry或更复杂后续，还是保留stock让下一个回合更难防。她的速度和5MP block +2让普通地面压力本来就成立，所以stock应该放大已经成立的接触，而不是替代基础确认。到最后才进入Feng Shui Engine，因为SA2改变的是整套cancel/pressure规则，不应该反过来绑架最初的地面骨架。

## force_opponent_to

- 尊重5MP block +2和快速地面按钮，不敢每次近身都抢。
- 在M Fuhajin之后持续处理forward dash的strike / throw / shimmy。
- 一旦Juri有stock，对手必须考虑Boosted special让普通opening变成更长damage/carry。

## create_respect_with

- 5MP / 2MP：稳定近身contact。
- 2MK DRC：低段转近身回合。
- M Fuhajin：稳定ender + stock generation + forward-dash Oki。
- H Tensenrin：高价值ender；角落Year4可进入约+5 family。
- stock-spend specials：只在已有stock和实际opening成立时加入。

## payoff_after_respect

- throw / shimmy / low更容易成立。
- stock可以把下一次confirm升级成更高damage/carry。
- Go Ohsatsu等stock-spend路线能在花stock后通过L Fuhajin重新进入stock循环。
- 角落H Tensenrin让普通confirm继续滚成墙角压力。

## core_tradeoff

当前opening立刻花stock放大damage/carry vs 保留stock给未来option space。次级取舍是稳定M Fuhajin回合和更高资源/更高执行的OD Fuhajin、三stock、SA2路线之间怎么选。

## successful_round

1. 5MP / 2MP / light拿稳定contact
2. M Fuhajin收尾并获得stock
3. forward dash进入strike / throw / shimmy
4. 下一次opening判断要不要花stock
5. 用Boosted special把值得的机会放大到damage/carry/corner
6. 重新用Fuhajin/角落Oki把回合接回基础循环

## common_misplays

- 开局先想着攒满stock，基础地面确认和Oki反而没建立。
- 有stock就立刻花，不问这次花掉到底买到了什么。
- 把Boosted special当通用move，忘记stock condition。
- 太早沉迷Feng Shui Engine，普通5MP/2MP/2MK回合不稳。

## unique_decision

Juri真正新增的是“stock spending timing”：基础combo本身就能顺便生成stock，所以难点不是能不能攒，而是何时把这份future option space现金化。

## transfer_in

- Cammy/Ryu系的grounded contact、2MK DRC、strike/throw/shimmy。
- anti-air / punish / DI / corner / Oki。

## new_skill

- stock generation与stock-spend状态识别。
- 同一opening比较“稳定Oki vs 花stock damage/carry”。
- Boosted special只在stock条件满足时进入。
- SA2 Feng Shui Engine后置的cancel/pressure系统。

## unlearn

- 资源角色一定要先牺牲当前回合才能攒资源。
- 有stock就应该马上花。
- Boosted special可以脱离stock状态当普通招式背。
