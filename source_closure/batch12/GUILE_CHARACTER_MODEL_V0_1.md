# Guile Character Model v0.1

Status: **PROVISIONAL — must survive Route/Oki audit**  
Character: **GUILE**  
Sources: SRC03 / SRC04 / SRC05

## essence_short

Guile不是“蹲着等蓄力”。真正的核心是一边做普通SF6动作，一边让后/下蓄力持续存在；这样Sonic Boom限制地面，Somersault惩罚跳跃，普通按钮再把对手的犹豫吃掉。

## essence_detail

Charge对Guile来说不是一个需要单独停下来完成的动作，而是一种后台状态。你在蹲防、用兼容的蹲拳、保持后下方向、准备反空时，都应该同时思考“我现在还保留Boom / Flash Kick的资格吗”。Sonic Boom本身只是横向限制：对手被迫跳、Parry、走停节奏变化以后，Somersault Kick和5MP、2MP、4HP这些地面工具才真正兑现收益。换句话说，Guile的强项不是‘永远有波’，而是能在普通neutral里同时保留一个地面威胁和一个反空威胁。

当前路线也支持这个模型：最基础的light / medium confirm都以H Somersault收尾，之后中场可以接Sonic Blade重新塑造空间，角落可以用3HK whiff得到+4继续throw / strike / shimmy。Year 4的OD Sonic Blade block +1又增加了一层earned pressure，但这应该在基本charge discipline稳定以后再加入。成熟Guile会在“继续保charge / 放Boom / 用normal占位 / 立刻反空”之间不断切换，而不是因为怕丢charge就不敢走、不敢按。

## force_opponent_to

- Sonic Boom让对手不能无成本直线前进。
- Somersault Kick让“看到Boom就跳”不能成为免费答案。
- 当对手开始尊重Boom和Flash Kick时，5MP / 2MP / 4HP与throw更容易成立。
- 角落+4与OD Sonic Blade +1让对手继续处理strike / throw / shimmy。

## create_respect_with

- Sonic Boom：横向节奏与移动约束。
- Somersault Kick：跳跃惩罚与稳定ender。
- 5MP / 2MP：普通地面confirm。
- charge-preserving crouching / back-direction actions：维持special威胁。
- OD Sonic Blade：后期plus-pressure层。

## payoff_after_respect

- 对手犹豫跳跃后，ground normals更容易占位。
- H Somersault收尾直接进入稳定Oki。
- Sonic Blade把一次击倒重新变成空间控制。
- 角落+4让throw / strike / shimmy真正形成持续循环。

## core_tradeoff

立即移动/按键自由度 vs 保持charge威胁。成熟Guile不是永远保charge，而是知道什么时候值得放弃charge换位置，什么时候必须让Boom / Flash Kick继续可用。

## successful_round

1. 一边蹲防/移动一边存charge
2. Sonic Boom限制水平推进
3. 对手跳 -> Somersault；地面犹豫 -> normal/throw
4. confirm到H Somersault
5. 中场用Blade/空间重建，角落用+4打投shimmy
6. 对手改变节奏后重新决定保charge、发Boom还是走位

## common_misplays

- 为了保charge一直蹲着不动。
- 发Boom以后注意力结束，没准备Somersault。
- 因为有Somersault就完全不使用普通对空/ground normals。
- 把特定hit-height的+42当所有H Somersault都safe jump。
- 为了OD Sonic Blade +1过早增加pressure复杂度。

## unique_decision

相对前面的标准角色，Guile新增的是“charge availability management”：每个普通动作都要顺便判断自己是否还保留Boom / Somersault资格。

## transfer_in

- projectile / anti-air / strike-throw-shimmy。
- punish / corner / knockdown -> Oki。
- basic grounded spacing。

## new_skill

- 在普通动作里保存charge。
- 同时保留水平Boom与垂直Somersault威胁。
- 知道什么时候主动放弃charge换位置。
- Sonic Blade / Cross作为击倒后的空间层。
- +42仅按hit-height条件使用。

## unlearn

- charge = 原地等待。
- 有charge就绝不能走动。
- projectile character的回合结束在发波那一刻。
- 所有H Somersault都有同一个Oki数字。
