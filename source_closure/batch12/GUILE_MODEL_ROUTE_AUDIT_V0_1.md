# Guile Character Model ↔ Route Audit v0.1

Status: **PHASE H PRE-AUDIT PASS**

## Claim 1 — Guile is a charge-management character, not a passive-wait character

Evidence:

- the curriculum charge contract requires charge storage during other actions.
- core current routes use crouching normals, 4HP, DR routes and ordinary confirms before Somersault.
- current starter list includes DR, overhead and punish conversions, proving the character is not limited to static crouch waiting.

Judgment: **SUPPORTED**.

## Claim 2 — Boom and Somersault create a horizontal/vertical threat pair

Evidence:

- Sonic Boom is the horizontal projectile layer.
- Somersault is the stable anti-air/ender across most practical starters.
- current Game Plan explicitly moves through opponent jump -> Somersault -> combo -> corner +4 pressure.

Judgment: **SUPPORTED**.

## Claim 3 — Guile's reward continues after the anti-air/ender

Evidence:

- H Somersault -> Blade midscreen space-control packages.
- corner H Somersault -> 3HK whiff -> +4.
- M Somersault -> DR strike/overhead/throw.
- hit-height-specific +42 safe jump.
- OD Sonic Blade current +1.

Judgment: **SUPPORTED**.

## S0 identity gate

Proposed S0:

- store charge during ordinary defense/compatible actions;
- Sonic Boom;
- Somersault anti-air;
- light -> H Somersault;
- 5MP -> 2MP -> H Somersault;
- no Blade / no +42 requirement.

Question: does Guile remain Guile without Sonic Blade in S0?

Judgment: **YES**. The defining new skill is already visible: normal SF6 decisions performed while preserving a two-axis charge threat.

## Transfer check

Transfers in:
- projectile/anti-air concept;
- grounded spacing;
- strike / throw / shimmy;
- punish / corner / Oki.

New:
- charge availability as a background resource.
- preserving charge while doing normals/defense.
- choosing when to sacrifice charge for movement.
- Sonic Blade/Cross layered space control.
- hit-height-specific Somersault Oki.

Unlearn:
- charge means waiting.
- movement is always better than preserving charge.
- every projectile character can freely access special moves without state preparation.
- every H Somersault gives +42.

## Audit outcome

Character Model v0 survives current route/Oki evidence.

Proceed to learner assets with Blade/Cross entering after basic charge discipline and Solid Puncher fixed late.
