# Blanka Character Model v0.1

Status: **PROVISIONAL — must survive Route/Oki audit**
Character: **BLANKA**
Sources: SRC03 / SRC04 / SRC05

## essence_short

Blanka先用普通地面与Electric Thunder / Rolling拿击倒和角落；真正的角色特色是赢到角落以后放Blanka-chan Bomb，让“延迟爆炸”和本体高低投同时变成问题。

## essence_detail

Blanka不是“球来球去的charge怪角色”。他确实要学会在普通动作里保存Rolling / Vertical Rolling的charge，但当前最实用的早期回合其实很普通：5LK或2LK确认到Electric Thunder，4MK +2 / 2MP接Thunder或Rolling，命中后拿+39、+42等清楚Oki。真正属于Blanka的高层特色发生在角落：Wild Lift / corner route把Blanka-chan Bomb放到场上，Bomb需要Electric Thunder等攻击激活，于是对手不仅要防你本人，还要计算一个延迟的第二威胁。Current Game Plan正是ground contact -> corner -> Bomb -> OD Electric Thunder -> overhead / low / throw。成熟Blanka不是一直Roll，而是先用稳定contact赢位置，再在角落把Bomb、OD Thunder、高低投和safe jump叠成setplay。SA2 Lightning Beast最后再把Rolling家族变成持续系统层。

## force_opponent_to

- 尊重4MK block +2、Electric Thunder Oki和快light。
- 不敢把Rolling/Vertical charge威胁完全忽略。
- 到角落后同时处理Blanka本体和延迟Bomb。
- OD Electric Thunder后必须处理overhead / low / throw。
- SA2阶段还要处理Rolling Cannon follow-up。

## create_respect_with

- 4MK Wild Edge：9F / block +2，Year4强respect点。
- Electric Thunder：早期稳定ender / +39 Oki。
- M/H Vertical Rolling：+42 high-budget Oki。
- forward throw +30：简单corner/pressure入口。
- Bomb：后置角落第二威胁。

## payoff_after_respect

- throw / low / overhead更容易成立。
- +39/+42让Hop、dash、safe jump有清楚预算。
- Bomb把防守从“只看本体”变成“本体 + 延迟爆炸”。
- OD Thunder +4让高低/throw更可信。
- Lightning Beast进一步增加Rolling follow-up和screen pressure。

## core_tradeoff

稳定Thunder/Oki vs 更复杂Rolling/Bomb setplay。先赢角落，再问Bomb是否值得；没有位置/setup时硬放Bomb或硬Roll只是增加风险。

## successful_round

1. 5LK/2LK/4MK/2MP拿ground contact
2. Thunder或Rolling拿击倒
3. +39/+42跑简单Oki
4. 把对手推到corner
5. Bomb进入后叠加OD Thunder / high-low-throw
6. S4用Lightning Beast扩系统

## common_misplays

- 把Rolling当neutral自动突进，忽略巨大block风险。
- 没到角落就围着Bomb打。
- +42条件没确认就safe jump。
- 太早学Lightning Beast整套，基础Thunder/Oki没稳。
- 因为4MK +2就无限挥，忽略Year4 whiff recovery变大。

## unique_decision

相对Kimberly，Blanka的延迟物体不是“先carry再花库存”的同一资源逻辑；Blanka Bomb是一个需要激活的场上对象，本体要围绕它的时间轴组织高低投。

## transfer_in

- Charge存储基本功。
- grounded contact / strike / throw / shimmy。
- anti-air / punish / corner / Oki。

## new_skill

- Rolling/Vertical charge availability。
- Electric Thunder +39 Oki。
- +42 Vertical Rolling safe jump。
- Blanka-chan Bomb placement/activation timing。
- OD Thunder high/low/throw around delayed object。
- Lightning Beast late install.

## unlearn

- charge角色的主要任务是一直用charge move。
- mobility special可以被防也没关系。
- Bomb存在就自动产生mix。
- SA2应该尽早围着它练。
