# Terry Character Model v0.1

Status: **PROVISIONAL — must survive Route/Oki audit**  
Character: **TERRY**  
Sources: SRC03 / SRC04 / SRC05

## essence_short

Terry先用普通中近距离接触把人送进Burning Knuckle的运角/Oki，再让Round Wave、Power Charge、Quick Burn等强必杀一棒接一棒地延续回合；关键是知道哪一棒现在最值钱。

## essence_detail

Terry很像标准角色，但他的特色不是“也有飞道和升龙”，而是强必杀技之间能形成非常清楚的接力。基础层先靠2MP、2MK、5HP和Power Wave拿接触，命中后M Burning Knuckle常常同时买到运角和+30…42一类的起攻预算；到了角落，forward throw循环和Round Wave的+5 block状态继续逼对手站住。Year 4又强化了Round Wave的实战作用，并让OD Quick Burn在命中后留下+33，能直接制造shimmy。真正成熟的Terry不是见到特殊技就全部连起来，而是根据距离和位置决定这次应该用Burning Knuckle运角、Rising Tackle收伤害、Round Wave延长压力，还是用Power Charge / Quick Burn把已有机会继续放大。很多数字都受spacing和active-frame影响，所以“强必杀多”不是无脑连按的许可，而是更多明确职责可选。

## force_opponent_to

- 尊重5HP block +1与2MP / 2MK的普通近身接触。
- 被M Burning Knuckle不断推向角落时提前处理位置。
- 角落里不能只靠后走逃离，因为Year4 Round Wave block +5会抑制简单后退。
- 在OD Quick Burn +33和角落forward throw后必须处理shimmy / throw / strike。

## create_respect_with

- M Burning Knuckle：基础确认后的carry + Oki。
- 5HP：9F / Block +1，可取消，建立普通近身respect。
- Round Wave：29F / Hit +8 / Block +5，作为earned pressure extension。
- Rising Tackle：反空/伤害ender。
- Power Charge / Quick Burn：把已有opening继续转换成damage或下一轮。

## payoff_after_respect

- throw / 2MP / shimmy更容易成立。
- Burning Knuckle把一次小命中转成更好的屏幕位置。
- 角落forward throw与Round Wave meaty形成持续墙角问题。
- OD Quick Burn +33让对手投拆挥空，直接创造PC惩罚窗口。

## core_tradeoff

稳定special ender / carry / Oki vs 更长special relay带来的额外damage与资源投入。另一个关键取舍是spacing：Burning Knuckle的击倒预算不是固定值，距离和角落状态会改变后续。

## successful_round

1. 用Power Wave / normals控制中距离
2. 2MP / 2MK / light拿接触
3. M Burning Knuckle把人送向角落并拿Oki
4. dash后strike / throw / shimmy
5. 角落forward throw / Round Wave继续逼防守
6. 命中后用Power Charge / Quick Burn / SA2现金化

## common_misplays

- 把所有强必杀当成一条自动special chain，不看spacing和block状态。
- 看到Round Wave +5就中立裸放，忘记29F startup和它需要前面先赚到时间。
- 背M Burning Knuckle“固定+多少”，忽略+30…42随spacing变化。
- OD Quick Burn +33还没建立基础打投，就过早追Year4 shimmy花活。

## unique_decision

相对Ryu/Ken/Luke，Terry新增的高频问题是“这次contact要交给哪个special接棒”：Burning Knuckle买carry/Oki，Rising Tackle买稳定伤害，Round Wave买plus pressure，Power Charge / Quick Burn买更长转换。

## transfer_in

- projectile / anti-air / 2MK DRC。
- strike / throw / shimmy。
- knockdown -> Oki / corner / punish / DI / SA。

## new_skill

- special-role mapping：每个强必杀承担不同end-state职责。
- spacing-dependent Burning Knuckle Oki。
- earned Round Wave +5 pressure。
- OD Quick Burn +33 shimmy和Power Charge route extension。

## unlearn

- “有很多强必杀”就等于可以把它们机械连成一串。
- 正帧/击倒数字可以脱离spacing与setup条件单独背。
- 只看damage足以决定special ender。
