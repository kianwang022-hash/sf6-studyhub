# Rashid Character Model ↔ Route Audit v0.1

Status: **PHASE H PRE-AUDIT PASS**

## Claim 1 — Rashid is playable before Air Current complexity

Evidence:

- R01 M Mixer +31 gives a complete basic knockdown loop.
- R02/R03/R04 Eagle Spike routes provide carry/Oki without requiring Boosted state.
- 5MP and 2MP are 6F, block +1 and cancellable.
- current practical starter list begins with ordinary Mixer/Eagle Spike routes.

Judgment: **SUPPORTED**.

## Claim 2 — Rashid's unique delta is re-entry-angle expansion

Evidence:

- Arabian Cyclone opens Wing Stroke / Rolling Assault / Nail Assault.
- Air Current changes Mixer / Eagle Spike properties and creates +42 families.
- current Game Plan escalates from ordinary Oki to Air Current +42 jump-in, then Ysaar.
- movement branches create overhead / throw / low / aerial entries after an earned setup.

Judgment: **SUPPORTED**.

## Claim 3 — extra freedom should be staged, not dumped into S0

Evidence:

- basic routes and +31 Oki already form a stable current loop.
- +42 and Boosted properties are state-dependent.
- Ysaar is a separate late screen-control system.
- source repeatedly warns spacing / active-frame / corner conditions matter.

Judgment: **SUPPORTED**.

## S0 identity gate

- fast ground normals;
- light -> M Mixer +31;
- 2MP -> L Eagle Spike carry;
- +31 DR Oki;
- 5MP/2MP +1 strike/throw;
