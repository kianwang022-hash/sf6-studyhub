# Rashid Character Model v0.1

Status: **PROVISIONAL — must survive Route/Oki audit**
Character: **RASHID**
Sources: SRC03 / SRC04 / SRC05

## essence_short

Rashid先用很快、很正常的地面确认拿到击倒；真正的特色是用移动和Air Current把“下一次怎么回来”变成更多角度，而不是第一秒就靠花式移动硬闯。

## essence_detail

Rashid看起来像最应该一上来就学跑墙、旋风、空中变化的角色，但当前资料给出的基础路线非常朴素：2LK / 5LP确认到M Spinning Mixer，2MP接L Eagle Spike，2MK取消绿冲，再把M Mixer的+31或Eagle Spike的运角/Oki接回下一轮。这说明他的第一层仍然是普通SF6：快按钮拿接触、确认、击倒、打投。真正属于Rashid的第二层才是“重新进入的角度变多”。Arabian Cyclone、Wing Stroke、Rolling Assault、Arabian Skyhigh与Air Current会让Spinning Mixer / Eagle Spike等熟悉工具得到强化，+42、+44以及不同的空中进场开始出现。成熟的Rashid不是一直乱飞，而是先让对手适应普通地面和固定Oki，再用风和移动改变下一次接近的方向；如果这些变化没在针对真实防守，就应该退回稳定地面循环。最后的SA2 Ysaar更像把整个屏幕临时变成Rashid的系统层，不应该抢走入门主线。

## force_opponent_to

- 先尊重5MP / 2MP block +1和快速light，不敢近身每次都抢。
- 被M Mixer / Eagle Spike击倒后持续处理strike / throw / low。
- 基础Oki稳定后，还要处理Air Current强化后的+42 jump-in和Arabian Cyclone移动分支。
- SA2阶段需要同时处理Ysaar与Rashid本体的高/低/投。

## create_respect_with

- 5MP / 2MP：6F正帧接触。
- 2MK DRC：主要低段转近身回合。
- M Spinning Mixer：S0稳定ender，当前+31。
- Eagle Spike：carry与不同Oki预算。
- Arabian Cyclone / Air Current：S2/S3后把普通路线升级成多角度re-entry。

## payoff_after_respect

- 普通throw / delayed strike / low更容易成立。
- Eagle Spike把接触换成更强位置和Run Oki。
- Air Current Boosted Mixer把熟悉ender升级到+42 jump-in。
- Nail / Rolling Assault +44与Arabian Cyclone派生提供新的overhead/throw/low入口。
- Ysaar阶段进一步把屏幕控制和mix叠加。

## core_tradeoff

稳定地面/固定Oki vs 更高波动的移动与Air Current层。额外角度只有在它真的针对对手防守时才值得打开；不是移动越多越像Rashid。

## successful_round

1. 快light / 2MP / 2MK拿ground contact
2. M Mixer或Eagle Spike拿击倒/位置
3. 跑固定strike / throw / low
4. 对手开始适应固定Oki后加入Arabian Cyclone/Air Current
5. 用+42/+44和空中角度重新进入
6. S4才用Ysaar把整轮压力继续放大

## common_misplays

- 因为角色会跑会飞就第一天乱开移动，确认和Oki反而不稳。
- 把Air Current Boosted路线当普通状态路线。
- 把Eagle Spike的KD区间背成固定数字。
- 太早围着SA2 Ysaar练花式，基础ground loop没成立。

## unique_decision

相对Cammy，Rashid的新能力不是单纯更快re-entry，而是“用风与移动改变re-entry的角度和special性质”；学习重点是何时打开这层自由度，何时回到普通地面。

## transfer_in

- grounded contact / 2MK DRC / strike-throw-shimmy。
- anti-air / punish / DI / corner Oki。

## new_skill

- Air Current状态识别与Boosted special条件。
- Eagle Spike spacing-dependent Oki。
- Arabian Cyclone -> Wing Stroke / Rolling Assault分支。
- +42/+44作为条件化re-entry预算。
- Ysaar作为后期screen-control system。

## unlearn

- mobility character就应该一直移动。
- Air Current Boosted move可以脱离风状态背成普通招。
- 更复杂的re-entry总比固定Oki好。
