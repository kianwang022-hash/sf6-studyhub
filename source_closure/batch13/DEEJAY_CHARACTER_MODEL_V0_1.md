# Dee Jay Character Model v0.1

Status: **PROVISIONAL — must survive Route/Oki audit**  
Character: **DEE JAY**  
Sources: SRC03 / SRC04 / SRC05

## essence_short

Dee Jay会存charge，但真正强点不是“像Guile一样保charge”。他把真/假Air Slasher、正帧st.MP、Sobat和Jus Cool混在一起，让对手很难预测下一个节奏，再用高火力把一次猜错放大。

## essence_detail

Dee Jay和Guile共享“在普通动作里后台存charge”的基本功，但用途完全不同。Guile靠Boom/Somersault形成横纵双轴控制；Dee Jay则可以在有charge时选择真Air Slasher，也可以用L Air Slasher做fake，甚至完全不依赖charge，转而用Quick Sobat、Machine Gun Uppercut或Jus Cool继续回合。因此对手真正难处理的不是某一招，而是节奏：这次后退是在存Air Slasher，还是准备fake？5MP block +2以后会继续cr.LP、throw、walk-back shimmy，还是突然Jus Cool？当前Game Plan也从Drive Rush / st.MP接触一路进入H Jackknife或OD MGU，再回到strike / throw / shimmy / Jus Cool。Dee Jay成熟度不在“招式多”，而在于先用稳定+2/+6 contact让对手尊重，再在对手开始猜节奏时打开Jus Cool和fake层；猜对了再用H Jackknife +42或OD MGU +52把收益放大。

## force_opponent_to

- 尊重5MP block +2与DR 5MP +6。
- 不能把“后退蓄力”简单读成真实Air Slasher，因为L版可以fake。
- H Double Sobat命中后+2继续形成strike / throw / shimmy。
- Jus Cool一旦进入，必须处理low / overhead / combo-starter三个不同后续。

## create_respect_with

- 5MP：7F / block +2，最干净的pressure starter。
- Air Slasher真/假节奏。
- Jackknife：反空与+42 end-state。
- Quick / Double Sobat：不需要charge的稳定route/pressure。
- Jus Cool：earned timing mix，不是S0 autopilot。

## payoff_after_respect

- throw与walk-back shimmy更容易成立。
- H Double Sobat +2让普通hit继续成为下一次猜。
- H Jackknife +42直接进入safe jump。
- OD MGU +52双dash后+14，给很大的Oki预算。
- Jus Cool让对手难以用单一防守节奏处理。

## core_tradeoff

保charge维持Air Slasher/Jackknife威胁 vs 主动打破charge节奏，用non-charge Sobat/Jus Cool抢节奏。成熟Dee Jay不是永远charge，也不是永远fake，而是让对手无法稳定预测哪一类动作下一拍出现。

## successful_round

1. 在普通防守/移动里存charge
2. 真/假Air Slasher或DR 5MP制造节奏不确定
3. 5MP +2 / Sobat hit +2建立respect
4. 对手开始站住或拆投后加入Jus Cool
5. 命中后用H Jackknife +42或OD MGU +52放大回合
6. 再回到真/假/throw/shimmy节奏

## common_misplays

- 把Dee Jay打成Guile，只会后退发真Air Slasher。
- 一有Jus Cool就乱猜，不先用st.MP +2建立respect。
- 没有down charge时还假装随时有Jackknife。
- 把H Jackknife +42当任何命中都成立。
- 太早练SA2节奏系统，基础Sobat/Oki没稳。

## unique_decision

Dee Jay新增的是“rhythm deception”：charge本身既是special资格，也是让对手猜真假/停顿/突然前进的节奏资源。

## transfer_in

- Guile的charge storage基本功。
- projectile / anti-air / strike-throw-shimmy。
- punish / corner / knockdown -> Oki。

## new_skill

- L Air Slasher fake与real Air Slasher节奏区分。
- charge与non-charge route交替。
- 5MP +2 / DR 5MP +6后的pressure节奏。
- Jus Cool low / overhead / starter分支。
- +42 Jackknife与+52 OD MGU高预算Oki。

## unlearn

- charge角色一定主要靠charge move输出。
- fake越多越难猜，所以越多越好。
- Jus Cool是单一mix招。
- 所有Jackknife命中都等于+42。
