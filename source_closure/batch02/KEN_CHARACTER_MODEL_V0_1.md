# Ken Character Model v0.1

Status: **PROVISIONAL — must survive Character Model ↔ Route/Oki audit**
Character: **KEN**
Sources: SRC03 / SRC04 / SRC05 / SRC06 / SRC07 / SRC08

## essence_short

肯把一次普通确认当成推进器：碰到你以后不只拿伤害，还要决定把你送多远、用什么击倒进入下一轮，最后把普通打投一路压到墙边。

## essence_detail

从隆转到肯，波动拳、升龙反空、2MK 取消绿冲、打/投/骗拆这些基础都能直接继承；真正新增的不是另一套完全不同的游戏，而是“接触以后怎么把这一回合继续向前推”。肯在中距离可以用 5HK、波动拳和 KK 奋迅脚派生去逼对手处理空间，一旦靠 2MP、2MK 绿冲或绿冲 5MP 真正贴到人，路线就经常不只比较伤害，而是比较角落搬运、击倒后的 +6 起攻、角落 setplay 和资源。对手开始尊重这些按钮和推进后，低段、投、骗拆才越来越值钱。肯最容易玩歪的地方，是把所有奮迅脚/迅雷脚都当成自动续压，或每次命中都只选最高伤害；他的强项更像是把一次普通机会不断换成更好的屏幕位置和下一次选择，而不是无条件不停按。

## force_opponent_to

- 尊重 5HK / Hadoken / Quick Dash Forward Step Kick 对中远距离的占位和推进。
- 近身后不要每次都抢按，尤其要重新认识 Year 4 的 2MP +5 on hit 和 Drive Rush 5MP 入口。
- 在被逐步推向角落时提前花 Drive / 位置去逃，而不是等到墙边才处理完整打投。

## create_respect_with

- 5HK / Hadoken：先建立普通 shoto 的中距离存在感。
- 2MK -> Cancel Drive Rush：把低段接触转换成真正近身回合。
- 2MP：Year 4 命中 +5，普通命中即可接 5LK，贴身还能接更高价值路线。
- KK | Quick Dash：用于路线搬运和条件式空间推进；不是无脑中立跳过。
- 236K | Jinrai Kick：为近身/角落的分支压力和路线优化提供额外选择。

## payoff_after_respect

- 低段 / 普通投 / shimmy 的基础三角变得更可信。
- 用 Quick Dash Tatsu 一类路线把普通 starter 转成明显 corner carry。
- 用 H / Quick-Dash Shoryuken 一类击倒进入 +25 -> dash +6 的稳定下一轮。
- 到角落后把同一个 opening 继续分成 throw loop、meaty、shimmy、damage / Oki 分流。

## core_tradeoff

首要取舍不是“进不进攻”，而是同一个 opening 到底换成什么 end-state：伤害、搬运、Oki、角落 setplay、SA。次级取舍是 Quick Dash / Jinrai 这种角色专属分支带来的额外收益，是否值得承担更强的条件性和被针对风险。

## successful_round

1. 用普通 shoto 工具控制中距离
2. 用 2MP / 2MK DRC / DR 5MP 拿到可靠接触
3. 根据屏幕位置选 damage / carry / knockdown
4. 用 dash +6 或角落 setplay 继续打/投/shimmy
5. 对手开始为了逃角落和压力提前花资源
6. 再把新的防守答案转成下一次推进

## common_misplays

- 每次命中都选最高伤害，白白放弃 Ken 最值钱的 carry / corner state。
- 看到 H Dragonlash +1 on block 就把它当万能进场；28F startup 和实际距离仍需要对手行为配合。
- 把 Quick Dash / Jinrai 派生当自动 blockstring，忽略中断点、spacing 和对手的 DI / reversal / interrupt。
- 把 Ken 当“更快的 Ryu”一直停在波动升龙，不主动利用命中后位置转换。

## unique_decision

相对标准 shoto，Ken 真正多出来的高频决策是：普通 starter 命中后，怎样利用 Quick Dash / ender 体系把这次接触换成更好的屏幕位置和下一轮，而不是只比较 combo damage。

## transfer_in

- Hadoken / Shoryuken 的 projectile-antiair 基座。
- 2MK -> Cancel Drive Rush。
- strike / throw / shimmy。
- punish、DI、corner、SA conversion。
- knockdown -> Oki 的通用理解。

## new_skill

- 把 corner carry 当成路线价值，而不是 combo 的副产品。
- 用 Quick Dash / Jinrai 分支改变 end-state，同时知道哪些分支只是 conditioned。
- 同一机会在 damage / carry / Oki / SA 之间做位置化选择。

## unlearn

- 每个 shoto 都应该用同样的中距离节奏打完整一局。
- combo 只看伤害就是最佳。
- 看到 plus 或角色专属推进技就等于可以无脑续压。
