# Luke Character Model v0.1

Status: **PROVISIONAL — must survive Route/Oki audit**  
Character: **LUKE**  
Sources: SRC03 / SRC04 / SRC05

## essence_short

Luke先用很稳定的中近距离确认把机会变成清楚的Oki；真正的角色增量，是在基础路线稳定后，用Flash Knuckle的蓄力/Perfect timing把同一个opening换成更高的伤害、位置或setplay。

## essence_detail

Luke并不是“先把Perfect Flash Knuckle练会才能开始玩”的角色。当前资料反而把学习顺序写得很清楚：先会L Flash Knuckle收尾后的+36起攻、2MK取消绿冲、稳定PC惩罚、角落L Rising Uppercut和DDT硬倒地，再把Perfect Flash Knuckle加进来。也就是说，他的第一层是非常实用的中近距离转换角色：2MP被防+1、2MK可以DRC，拿到接触后用Flash Knuckle / Rising Uppercut / DDT把这一轮结算成明确的下一轮。第二层才是“执行质量换路线质量”：更好的Flash Knuckle timing会让伤害、运角或setplay更强。成熟的Luke不是每次都追Perfect，而是知道什么时候稳定路线已经够好，什么时候值得用更高执行成本去买更好的结果。

## force_opponent_to

- 尊重2MP +1与中近距离可取消按钮，不敢每次近身都抢。
- 处理2MK DRC带来的低段/投/shimmy。
- 在L Flash +36、DDT +12和角落Rising Uppercut后持续处理不同的下一轮。

## create_respect_with

- 2MP：6F、block +1的稳定近身接触。
- 2MK：低段DRC入口。
- L Flash Knuckle：低认知负担的稳定ender和+36 Oki。
- Rising Uppercut：反空与角落ender。
- DDT：明确hard knockdown和简单throw/shimmy。

## payoff_after_respect

- throw / shimmy / cr.MP active-frame pressure。
- 更高执行的Flash Knuckle路线开始变得值得。
- 角落forward throw loop与L Rising Uppercut Oki把位置价值放大。

## core_tradeoff

稳定确认与低执行成本 vs Perfect Flash Knuckle等更高执行路线带来的额外伤害、carry和setplay。不是“能Perfect就必须Perfect”。

## successful_round

1. 中距离按钮 / Sand Blast控节奏
2. 2MP / 2MK / light拿接触
3. L Flash / Rising Uppercut / DDT稳定收尾
4. 用+36 / +12 / corner Oki继续strike-throw-shimmy
5. 当基础循环稳定后，再把Perfect timing加入高价值机会
6. 失误率上升时主动退回稳定路线

## common_misplays

- 开局就把Perfect Flash Knuckle当入门门槛，基础确认/Oki反而不稳。
- 每个opening都追高执行路线，掉combo比多出的收益更亏。
- 把+64 H Flash高级setplay提前塞进日常工作记忆。
- 只看Luke伤害高，不看ender后的Oki和位置差异。

## unique_decision

相对Ryu/Ken，Luke的高频新增决策是“这次接触需要多高的执行投资”。同一机会可以先选稳定Flash/Oki，也可以在值得时用Perfect timing把路线质量继续上提。

## transfer_in

- projectile / anti-air / 2MK DRC。
- strike / throw / shimmy与knockdown -> Oki。
- punish / DI / corner / SA。

## new_skill

- Flash Knuckle蓄力与Perfect timing分层。
- 按稳定性、Oki、damage、carry决定是否提高执行成本。
- DDT / No Chaser / Rising Uppercut不同end-state识别。

## unlearn

- 技巧更难就一定更应该优先学。
- Perfect timing是Luke能正常玩的前置条件。
- 只看damage足以决定路线优先级。
