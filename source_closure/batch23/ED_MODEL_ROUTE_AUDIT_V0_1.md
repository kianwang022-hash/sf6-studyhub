# Ed Character Model ↔ Route Audit v0.1

Status: PHASE H PASS

## Claim 1 — Ed's core is range-to-reentry, not charged-Flicker vortex

Evidence:
- current practical starter list begins with light / 5MP routes into M Blitz and 5MK -> L Flicker.
- current game-plan chain explicitly moves from contact / Drive Rush into strike / throw / shimmy, corner safe jump and 5HK +4 pressure.
- M/H Blitz provide +39/+40 knockdowns and Drive Rush re-entry packages.
- charged Flicker appears later as a Year4 spacing-specific pressure section.

Judgment: SUPPORTED.

## Claim 2 — charged Flicker must be taught as spacing-conditioned +4

Evidence:
- current frame data keeps charged L/M Flicker at Block +4.
- current Year4 guide explicitly says pull-in / spacing changed and lists strike / throw / shimmy based on spacing.
- older point-blank throw-loop assumptions are therefore misleading.

Judgment: SUPPORTED.

## Claim 3 — 5HK +4 is a stable close-pressure owner independent of Flicker

Evidence:
- current frame data: 5HK Block +4.
- current guide: 5HK Block +4 -> 5MP creates a 4F frame-trap family; throw / 5HP shimmy are alternatives.

Judgment: SUPPORTED.

This prevents the learner from treating Flicker as Ed's only pressure mechanic.

## Claim 4 — Kill Switch is a value branch after contact, not S0 input tax

Evidence:
- current routes use Kill Switch Break / Chaser for carry and punish conversions after 5HP / PC / Flicker states.
- stable Blitz routes already form a complete round without Kill Switch.
- therefore S0 can be playable before route-specific carry optimization.

Judgment: SUPPORTED.

## Claim 5 — Psycho Knuckle is not the minimum identity floor

Evidence:
- current starter / game-plan sections do not require Knuckle for the first complete loop.
- Knuckle has long 39F/69F charge levels with screen-position-specific block truth.
- it is better understood after the learner can already control midrange and re-enter from Blitz.

Judgment: SUPPORTED.
