# Akuma Character Model ↔ Route Audit v0.1

Status: **PHASE H PRE-AUDIT PASS**

## Claim 1 — stable shoto skeleton comes first

Evidence:

- R01/R04 stable H Gou Shoryuken confirms.
- 2MK DRC and ordinary punish routes exist without Demon Raid.
- H Gou Shoryuken +30 produces a simple repeatable next-turn package.

Judgment: **SUPPORTED**.

## Claim 2 — Akuma's extra identity is option density, not a separate resource meter

Evidence:

- charged Gou Hadoken changes frame state.
- Demon Raid exposes multiple height/follow-up branches.
- air projectile adds another approach/space-control angle.
- Adamant Flame / Ashura create distinct route/setplay states.
- no stock/install resource is required to unlock these tools.

Judgment: **SUPPORTED**.

## Claim 3 — extra options must be risk-budgeted

Evidence:

- current health is 9000.
- Demon Raid / Blade Kick / Guillotine outcomes vary by height / follow-up.
- charged fireball requires time / setplay.
- teleport has a large total duration and specific pass-through window.

Judgment: **SUPPORTED** as learner framing. This is a decision-cost explanation, not a claim that every Akuma option is inherently unsafe.

- lower health tolerance;
- richer end-state choice;
- later option-density expansion.
