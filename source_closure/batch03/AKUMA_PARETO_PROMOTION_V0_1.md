# Akuma Pareto Promotion v0.1

Status: **PHASE F CANDIDATE**

## S0 minimum playable

Keep:

1. R01 — light -> H Gou Shoryuken
   - role: stable low-load confirm.
   - result: +30 Oki budget.
2. R04 — 2MP > 2MP > H Gou Shoryuken
   - role: stable medium confirm.
3. R02 or R05 — L Tatsu > 2HK +37 family
   - role: first Akuma-specific end-state choice: same contact can buy a larger Oki budget instead of always taking H DP.
4. P01 — +30 -> 5MK whiff -> about +4
   - role: first strike / throw / shimmy loop.

S0 does **not** require Demon Raid, air fireball, teleport or charged fireball as main tools.

Why: Akuma remains recognizable through richer end-state choice while the learner first stabilizes ordinary shoto fundamentals.

## S1 fundamentals

Promote:

- R03 OD Tatsu -> M DP +32 only after 0-Drive confirms are stable.
- R09 5HK starter / H Tatsu +34 family.
- R13 blocked reversal punish.
- R15 / R16 fast punish.
- 5MP Block +1 as a concrete respect tool.
- 5HK Block +3 only with explicit multi-hit / spacing explanation.

Do not yet promote Demon Raid as primary approach.

## S2 structured match play

Promote:

- R07 2MK DRC stable H-DP ender.
- R08 2MK DRC Oki ender.
- R12 Year4 6HP PC.
- R17 DI wall splat.
- one corner OD Adamant route.
- choose among +30 / +32 / +34 / +37 based on resource and position.

Core lesson: same shoto starter now branches by Oki budget / meter / position.

## S3 mature choice

Add option-density layer:

- P15 charged Gou Hadoken meaty.
- P16 Demon Raid family, but only split by follow-up and height.
- P11 H Adamant +47 -> Demon Raid setplay.
- P12 OD Adamant +63 -> Ashura setplay.
- air Gou Hadoken as matchup/read-dependent neutral layer.
- Ashura as state/mobility tool, not default neutral bypass.

Core lesson: extra options are answers to opponent habits, not checklist buttons.

## S4 high-value optimization

Promote only after exact closure:

- active-frame 5HP meaty packages.
- Shun Goku Satsu combo / point-blank setplay.
- high-resource OD Adamant / OD Demon Raid / SA3 optimization.
- matchup-specific charged-fireball / Demon Raid routes.

## Backend-only

- route fragments whose ender is unspecified.
- approximate +35 DI family until exact practical condition is closed.
- Demon Raid claims without follow-up / height.
- legacy +42 shorthand.

## Pareto result

22 conversion candidates + 16 setplay packages do not become a 38-row learner dump.

The learner surface should start with:
- 2 stable confirms,
- 2 distinct end-state families (+30 and +37),
- one simple Oki package,
then expand only when those choices are stable.
