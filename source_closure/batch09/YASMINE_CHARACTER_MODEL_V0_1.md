# Yasmine Character Model v0.1

Status: **PROVISIONAL — must survive Route/Oki audit**  
Character: **YASMINE**  
Sources: SRC03 / SRC04 / SRC05

## essence_short

Yasmine先用普通Alon命中拿Bayani，再用下一次Boosted Alon把这份状态换成更安全、更高收益的回合；核心不是囤资源，而是不断完成“取得状态 -> 消耗状态 -> 再取得”的循环。

## essence_detail

Yasmine的Bayani不是Juri那种可以一直堆着等未来花的多stock资源。她更像是在做一个循环状态：普通Daloy ng Tubig接Alon命中后进入Bayani，下一次Alon就升级为Boosted Alon；普通Alon被防大约-12，而Boosted版本被防大多只剩-1到-3，命中时还能进入+42 safe jump或更高伤害。Boosted Alon通常会把Bayani消耗掉，于是Yasmine又要通过下一次Alon、Talim或其他取得方式把状态拿回来。真正的角色节奏因此是“普通回合拿状态 → 强化回合兑现状态 → 再进入普通回合重建状态”。她还有Mukha ng Langit的表里、Pangil sa Likuran和SA2长期Bayani，但这些都应该后置；S0先把+30/+44的普通Alon回合跑稳，S1再第一次完成Boosted Alon +42的完整状态循环。

## force_opponent_to

- 尊重2MP 0F和2MK DRC带来的近身接触。
- 普通Alon命中后，开始处理下一轮Bayani状态下更安全的Boosted Alon。
- 在+42 / +44击倒后持续处理throw / 2MP / 2LK / shimmy。
- 后期必须处理Mukha表里与SA2持续Bayani带来的option密度。

## create_respect_with

- 2MP：6F / Block 0 / cancellable，稳定近身接触。
- 2MK：8F可取消低段，主要DRC入口。
- M/H Daloy -> Alon：普通路线获得Bayani并给+30/+44 Oki。
- Boosted Alon：Bayani状态下把原本危险的Alon变成更安全/高收益版本。
- Talim：伤害/Oki与Bayani取得的另一条通道。

## payoff_after_respect

- Boosted Alon被防不再像normal Alon那样大负帧，能维持更安全的回合。
- L Daloy -> Boosted Alon可以进入+42 safe jump。
- H Daloy -> Alon +44可以双前冲后+6，继续throw / 2MP / low / shimmy。
- SA2开启后，约25秒持续Bayani把原本的状态循环变成连续强化Alon压力。

## core_tradeoff

普通回合取得Bayani vs 强化回合立即消耗Bayani兑现更安全/更高收益的Alon。后期再加入SA2“花SA换一段持续Bayani窗口”的资源决策。

## successful_round

1. light / 2MP / 2MK拿ground contact
2. normal Alon命中取得Bayani
3. 用+30/+44 Oki继续strike / throw / shimmy
4. 下一次opening用Boosted Alon兑现状态
5. +42 safe jump / high damage后重新取得Bayani
6. 后期用SA2把短循环临时变成长时间持续Bayani

## common_misplays

- 把Bayani当成三层stock一样囤着理解。
- 没Bayani时把normal Alon当安全pressure，忘记block约-12。
- 有Bayani就无脑Boosted Alon，不看这次状态消耗买到了什么。
- 太早用Mukha/Pangil/SA2花活，基础取得/消耗循环没稳定。

## unique_decision

Yasmine新增的是“状态循环管理”：Bayani不是单纯库存，而是把下一次Alon从高风险版本转换成强化版本；成熟度来自反复取得、兑现、再取得，而不是一直持有。

## transfer_in

- Juri/Cammy章里的grounded contact、2MK DRC、strike/throw/shimmy。
- anti-air / punish / DI / corner Oki。

## new_skill

- Bayani取得 / 消耗状态识别。
- normal vs Boosted Alon安全性差异。
- +30 / +42 / +44 end-state分流。
- Mukha Ulan/Kulog高度/表里判断。
- SA2 persistent Bayani作为后期install窗口。

## unlearn

- 所有资源都等价于可累计stock。
- normal Alon和Boosted Alon可以当同一招背。
- 强化状态有了就应该立即无脑消费。
