# A.K.I. Character Model v0.1

Status: PROVISIONAL — must survive Route/Oki audit  
Character: A.K.I.  
Primary evidence: SRC03 / SRC05 / SRC06

## essence_short

A.K.I.先用鞭子或毒弹给对手挂毒，再用H Serpent Lash拿+44击倒；真正的角色升级发生在“对手已经中毒”以后，同一个opening会变成毒爆、运角与毒池setplay。

## essence_detail

A.K.I.不是“每个状态都背一套combo”的角色。她的第一个完整回合其实很简单：用light、5MK或普通接触确认到H Serpent Lash，先把毒状态和+44击倒建立起来；+44后双dash大约还有+6，可以做低段、5HK、投、shimmy，也可以用Drive Rush展开中段/低段/投。真正的角色特异性从下一次接触开始：如果对手已经中毒，M/H/OD Serpent Lash会触发毒爆并改变击倒预算，例如M毒爆可到+69、H毒爆到+53、OD毒爆到+71；这时同一个opening不再只是“再打一次combo”，而是可以运角、拉长route或在角落转成Venomous Fang -> Orchid Spring的毒池setplay。Year4又增加了2HP PC上毒、OD Nightshade Chaser被普通防御也能挂毒等入口，所以成熟A.K.I.要管理的是“现在先挂毒、马上毒爆、还是把击倒换成位置/毒池”的状态转换，而不是无脑追最高伤害。

## force_opponent_to

- 先处理H Serpent Lash +44后的低段 / strike / throw / shimmy。
- 中毒后不能再把下一次Serpent Lash当成普通击倒，因为毒爆会改变route和Oki预算。
- 角落毒池存在时，不能只站着等；跳、前走、无敌技等逃生都会被针对。
- Year4 OD Nightshade Chaser被普通防御也能挂毒，迫使对手在防守与Drive Parry之间做额外判断。

## create_respect_with

- 2LP / 2LK基础确认 -> H Serpent Lash。
- 5MK -> 5MP -> H Serpent Lash。
- H Serpent Lash +44 -> double dash +6。
- DR 2LK / DR 3MP / DR 2MK的低段、overhead、plus contact。
- 6HP active-frame meaty at declared +18 states。

## payoff_after_respect

- 已中毒目标被M/H/OD Serpent Lash命中后触发毒爆，获得更大的击倒与route预算。
- 毒爆后可以运角或进入毒池route。
- Orchid Spring角落毒池约+38后可以继续DR strike / low / overhead / throw / shimmy。
- 对手为了逃毒池而jump / walk / reversal后，anti-air与whiff-punish价值上升。
- SA2可以把对手固定在长时间毒池里继续做strike / throw / overhead。

## core_tradeoff

当前稳定+44 Oki vs 立刻兑现毒爆的damage/route vs 把优势投资到角落位置与Orchid Spring毒池。毒是状态放大器，不是“看到有毒就必须马上引爆”。

## successful_round

1. 普通contact -> H Serpent Lash，挂毒并拿+44。
2. 双dash后做strike / low / throw / shimmy，逼对手暴露防守习惯。
3. 下一次opening若对手已中毒，根据位置选择毒爆、继续+44循环或运角。
4. 进角后用Venomous Fang -> Orchid Spring建立毒池。
5. 对手为了离开毒池跳/走/无敌时，改用anti-air、5MK、whiff punish。
6. 毒爆大route或SA在资源/回合价值值得时现金化。

## common_misplays

- S0就背“有毒/无毒”两套所有combo，基础+44 Oki反而不稳。
- 看到对手中毒就机械追毒爆，不看位置、Drive和当前Oki。
- 把M/H/OD毒爆的+69/+53/+71当成无毒也成立。
- 把毒池+38泛化到所有Orchid Spring。
- 把OD Nightshade Chaser“block可上毒”忘记Drive Parry例外。
- raw提交H Serpent Lash或Venomous Fang等高风险动作，只因为它们是角色招牌。

## unique_decision

A.K.I.新增的是poison-state conversion：同一个opening在未中毒时负责“建立状态”，在已中毒时则能变成毒爆、运角和setplay；你必须根据毒状态与位置重新选择route价值。

## transfer_in

- normal confirm / strike-throw-shimmy。
- knockdown -> Oki。
- projectile / anti-air / Drive Rush。
- Jamie的“当前回合 vs 未来状态”判断习惯。

## new_skill

- poisoned / unpoisoned二态识别。
- poison application vs poison burst的route切换。
- +44 Oki作为基础循环。
- corner Orchid Spring毒池作为位置投资。
- exact-state +18 / +38 / +42 / +53 / +69 / +71区分。

## unlearn

- “角色状态越复杂就越早背完整combo树”。
- “中毒以后必须立刻引爆”。
- “所有Serpent Lash都有同一个击倒帧数”。
- “毒池只是持续伤害，不改变对手移动行为”。
- “被防上毒没有Parry例外”。
