# A.K.I. Character Model ↔ Route Audit v0.1

Status: PHASE H PASS

## Claim 1 — poison application should precede poison-burst optimization

Evidence:
- the current practical starter list begins with ordinary light / low / 5MK routes into H Serpent Lash.
- ordinary H Serpent Lash produces +44 and immediately feeds the main Oki loop.
- poison-burst routes appear as state-specific upgrades after poisoned status already exists.

Judgment: SUPPORTED.

S0 should teach "create poison state + take +44 Oki", not two full combo books.

## Claim 2 — +44 Oki is the real bridge between poison and repeated offense

Evidence:
- current game-plan summary explicitly places H Serpent Lash +44 before overhead / low / throw / shimmy.
- two forward dashes leave about +6.
- Drive Rush from +44 provides strike / low / overhead / throw / shimmy branches.

Judgment: SUPPORTED.

The first A.K.I. round can be complete before puddle or SA2 appears.

## Claim 3 — poison is a state converter, not just damage-over-time

Evidence:
- poisoned M Lash creates about +69.
- poisoned H Lash changes to about +53.
- poisoned OD Lash changes to about +71.
- Qiong Qi changes from about +34 unpoisoned to +54 poisoned.
- current routes use burst state to extend, carry and build corner puddle setplay.

Judgment: SUPPORTED.

The learner-facing model should explain poisoned/unpoisoned as a routing-state change.

## Claim 4 — corner poison puddle is position investment, not an S0 resource task

Evidence:
- Orchid Spring appears after a longer poisoned M Lash corner route.
- puddle setup gives around +38 and explicitly changes opponent behavior: jump, walk forward, invincible reversal to escape.
- the current game-plan chain places corner carry and puddle after the initial +44 mix / poison burst.

Judgment: SUPPORTED.

## Claim 5 — current Year4 added new poison-entry routes but did not erase the base loop

Evidence:
- 2HP PC can now apply poison.
- OD Nightshade Chaser ordinary block can poison unless Drive Parried.
- Qiong Qi gained current-version utility.
- yet the published game-plan still starts from Lash/projectile poison -> knockdown -> H Lash +44.

Judgment: SUPPORTED.
