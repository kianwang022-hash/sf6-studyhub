# Ingrid Character Model ↔ Route Audit v0.1

Status: PHASE H PASS

## Claim 1 — zero-stock Ingrid is a complete character

Evidence:
- current starter routes begin with three ordinary M Sun Rise confirms.
- current game plan places M Sun Rise and ordinary high/low/throw/shimmy before stock escalation.
- zero-stock Sun Flare is not required to run the base knockdown loop.

Judgment: SUPPORTED.

## Claim 2 — one safe stock build belongs in the minimum identity floor

Evidence:
- current game plan explicitly moves from ordinary Oki into L Sun Flare stock build.
- stock build takes about 47F, so it is a genuine time/space investment rather than a passive meter.
- the first stock materially changes Sun Flare from negative to plus.

Judgment: SUPPORTED.

S0 may teach “when it is safe to take one stock”, but not require stock spend or two-stock farming.

## Claim 3 — stock changes future turn quality, not only damage

Evidence:
- Lv1 zero-stock Sun Flare is negative on block.
- one-stock Lv2 becomes Block +4 or more.
- two-stock Lv3 is still more plus.
- two-stock OD Lv3 can reach Block +9..+13 and Hit +87+.

Judgment: SUPPORTED.

The character model should explain future-turn amplification, not just resource-to-damage conversion.

## Claim 4 — Sun Rise Oki must remain route/height dependent

Evidence:
- current guide explicitly warns against fixed universal M Sun Rise +38/+40 claims.
- multiple setup sections use different declared states.
- airborne height / route changes aftermath.

Judgment: SUPPORTED.

Learner assets need named setup owners rather than one universal number.
