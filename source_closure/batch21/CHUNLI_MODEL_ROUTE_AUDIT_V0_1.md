# Chun-Li Character Model ↔ Route Audit v0.1

Status: PHASE H PASS

## Claim 1 — ordinary confirm / Oki must precede stance complexity

Evidence:
- current training order begins with 5MP > 2MP > M SBK and low-light > L SBK.
- the next explicit training step is M SBK +34 -> dash +15 -> throw / 5MP / shimmy.
- only after this does the current training order introduce 2MK CDR -> Hakkei -> Serenity Stream routes.

Judgment: SUPPORTED.

S0 should not be a stance-option dump.

## Claim 2 — Serenity Stream is a routing layer, not merely a mixup stance

Evidence:
- 2HP > Serenity Stream > Forward Strike > M SBK is a current practical route.
- 2MK CDR > 5MP > Hakkei > Serenity Stream > Forward Strike > M SBK is a current training-order route.
- current stance followups are cancelable into specials, which lets the stance route connect confirmed normals to SBK without requiring the learner to have continuously preserved the ordinary charge timing beforehand.

Judgment: SUPPORTED.

The “charge-bypass routing” explanation is a real character-specific teaching advantage, not archetype filler.

## Claim 3 — current Year4 makes exit discipline and stance pressure more important

Evidence:
- current stance supports Up exit.
- stance Lotus Fist is currently Block +1.
- Orchid Palm pressure from Hakkei / 2HP is a current guide route.
- current route/Oki evidence therefore supports both “continue branch” and “exit” as meaningful stance choices.

Judgment: SUPPORTED.

## Claim 4 — Chun-Li's base loop can be learned without the whole stance tree

Evidence:
- stable M SBK route gives +34 -> dash +15 strike/throw/shimmy.
- low confirm gives grounded +33.
- 5MP itself is +1 on block.
- Kikoken and Tensho provide ordinary ground-control / anti-air anchors.

Judgment: SUPPORTED.

The stance layer should add value to an already playable character, not be the price of admission.

## S0 identity gate

Accepted S0:

- 5MP > 2MP > M Spinning Bird Kick.
- 2LK > 2LP > L Spinning Bird Kick.
- M SBK +34 -> dash +15 -> 5MP / throw / shimmy.
- H Tensho Kicks anti-air.
- 2HP > Serenity Stream > Forward Strike > M Spinning Bird Kick.
- Serenity Stream -> Up exit awareness.

Judgment: PASS.

This cannot be copied to Jamie, Guile or another stance/charge character by renaming moves. The stance-to-charge-special route and its “enter or exit” decision are Chun-Li-specific.
