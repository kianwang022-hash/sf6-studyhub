# Chun-Li Character Model v0.1

Status: PROVISIONAL — must survive Route/Oki audit  
Character: CHUN-LI  
Primary evidence: SRC02 / SRC03 / SRC05 / SRC06

## essence_short

Chun-Li先用5MP +1、Kikoken和稳定击倒守住地面；接触后用Serenity Stream把“预先蓄力”变成路线选择，再靠+14/+15 Oki逐层打开高低、投与安全退出。

## essence_detail

Chun-Li不是“招式很多所以很复杂”。她真正新增的是把普通立回、蓄力和临时架势编译成同一个回合。没有开口时，她先靠快速步行、5MP被防+1、2MK和Kikoken让对手愿意留在地面；命中以后，5MP > 2MP > M Spinning Bird Kick已经能给出+34击倒，dash后+15，足够跑strike / throw / shimmy。Serenity Stream的价值不是让你一进身就猜完整高低，而是让可取消Normal在接触后切进一个临时路由层：例如2HP或Hakkei进入stance，再用Forward Strike接M Spinning Bird Kick，即使事前没有为了SBK一直存下蓄力。Year4又让stance可以用Up退出，并把Lotus Fist改成被防+1，所以架势既能承担combo routing，也能在对手已经学会尊重基础压力后提供overhead、low、plus strike或退出。Chun-Li真正的难点因此不是背更多招，而是判断这一拍该走最稳定的charged route，还是把已赚到的contact换成更深的stance分支；基础Oki不稳时，后者只会制造额外负担。

## force_opponent_to

- 尊重5MP Block +1，不把每次近身都当成自己的回合。
- 在Kikoken后处理Chun-Li的步行、低段和throw，而不是只跳过飞道。
- M Spinning Bird Kick击倒后处理dash +15的strike / throw / shimmy。
- 当Serenity Stream入口已经被赚到时，不能只押站防或蹲防一种答案。

## create_respect_with

- 5MP Block +1 -> 5LP frame trap。
- 5MP > 2MP > M Spinning Bird Kick稳定击倒。
- 2LK > 2LP > L Spinning Bird Kick低段确认。
- L Kikoken后的步行pressure。
- H Tensho Kicks anti-air / grounded knockdown。

## payoff_after_respect

- Serenity Stream Forward Strike可以把contact继续编译回M Spinning Bird Kick，不要求事前持续存SBK蓄力。
- Lotus Fist作为stance overhead当前Block +1，可以继续下一拍。
- Orchid Palm / Forward Strike等分支让stance既能pressure也能安全收束。
- 对手开始防stance high/low后，throw / walk-back / exit重新升值。
- 角落+45/+46 exact states可以进一步换safe jump与meaty。

## core_tradeoff

最稳定的普通confirm / charged ender vs 进入Serenity Stream获得charge-bypass与更丰富的高低/退出选择。更深分支只有在基础击倒、charge纪律和对手respect已经稳定时才值得增加。

## successful_round

1. 用5MP / 2MK / Kikoken把对手留在地面。
2. 命中后先用SBK稳定收尾，拿+14/+15 dash Oki。
3. 用5MP +1、strike / throw / shimmy让对手开始尊重。
4. 再从2HP、Hakkei、DRC等明确入口进入Serenity Stream。
5. 需要稳定时Forward Strike -> M SBK；对手防守固定后再加入Lotus Fist / low / exit。
6. 进角后把精确+45/+46 setplay作为后置放大，不替代基础循环。

## common_misplays

- 第一阶段就背完整stance树，基础confirm和Oki反而不稳定。
- 把Lotus Fist +1和3HP Water Lotus Fist -3混成同一个overhead。
- 以为所有SBK都不需要蓄力；实际上是特定stance follow-up路线改变了charge需求。
- 没确认就提交SBK，被防后承受-17/-18级风险。
- 把H Tensho grounded / airborne后续混在一起。
- 把+45/+46 safe jump泛化到所有击倒。

## unique_decision

Chun-Li新增的是charge-bypass routing：普通cancelable contact可以进入临时stance，再由stance follow-up接入原本需要预蓄力的SBK等路线；你要在“最稳路线”与“更深stance分支”之间按当前回合价值做选择。

## transfer_in

- Ryu/Guile等已经建立的projectile / anti-air / grounded spacing。
- 普通strike / throw / shimmy与2MK DRC。
- Jamie已经学过的“不要为了角色系统牺牲当前回合”原则。

## new_skill

- Serenity Stream作为temporary routing layer。
- stance follow-up对charge route的连接。
- 5MP +1 / Kikoken / SBK Oki与stance branch之间的层级关系。
- stance Up exit与不继续commit的纪律。
- grounded / airborne / corner exact-state Oki区分。

## unlearn

- “复杂角色就要先学全部招式”。
- “stance是neutral常驻模式”。
- “所有SBK路线都不需要charge”。
- “overhead看到+1就代表所有overhead都+1”。
- “一个safe-jump数字可以套所有击倒”。
