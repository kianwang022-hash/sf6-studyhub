## 1. Current-version boundary

The current Chun-Li learner model must be based on post-2026-08-03 data.

The current version materially changes Serenity Stream as a teaching object:

- Serenity Stream can be exited with Up, reducing the commitment cost of entering stance.
- Serenity Stream Lotus Fist is currently +1 on block.
- Medium / OD Hundred Lightning Kicks received forward-movement improvements before startup.
- Light Hazanshu is currently -4 on block.
- Medium Tensho Kicks received increased Drive-gauge reward and combo-limit utility.
- Heavy Tensho Kicks gained a throw-invulnerable window during the current version.

These changes make it especially misleading to teach Chun-Li only as “a charge character with many moves” or only as a static stance-mix character.

## 4. Required condition boundaries

The following must never be published as universal:

- Serenity Stream itself is not a free neutral mode; the useful learner entries are anchored to contact, cancel, projectile spacing or explicit setup.
- Lotus Fist +1 refers to the current Serenity Stream follow-up, not Water Lotus Fist (3HP), which remains -3 on block.
- Spinning Bird Kick is highly unsafe on block; learner routes must remain hit-confirmed.
- the stance route to Spinning Bird Kick is valuable partly because it bypasses the need to have pre-stored charge; do not imply every Spinning Bird Kick route is charge-free.
- H Tensho Kicks grounded and airborne hit states produce different Oki.
- +46 / +45 safe jumps belong to exact airborne route states; they are not generic Chun-Li knockdown values.
- +45 6F safe-jump language must retain the 5F reversal interaction / Training Mode verification boundary.
- corner forward-throw / corner meaty values remain corner-state truth.
