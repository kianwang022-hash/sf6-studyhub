# Kimberly Character Model v0.1

Status: **PROVISIONAL — must survive Route/Oki audit**
Character: **KIMBERLY**
Sources: SRC03 / SRC04 / SRC05

## essence_short

Kimberly先把普通接触变成角落位置；到了墙边以后，Sprint分支和Shuriken Bomb才真正把下一轮变复杂。她的核心不是“到处跑”，而是把位置优势变成setplay。

## essence_detail

Kimberly最容易被学成“跑得快、花活多、炸弹多”的角色，但当前Training Order反而把她拆得很清楚：先用light到L Vagabond Edge、2MP/medium到Sprint -> Shadow Slide，把普通contact稳定地换成corner carry；再学Shadow Slide后的strike / throw / shimmy；之后才加入5MK DRC与Sprint的overhead / low / Emergency Stop分支。真正属于Kimberly的高层特色发生在角落：Shadow Slide把人送到墙边后，Shuriken Bomb库存开始把一个普通击倒变成有延迟威胁的setplay，Year 4又把Bomb最大库存提升到3。她因此不是“移动越多越强”，而是先把移动用作位置转换，再用角落Bomb和Sprint读法让对手的防守选择越来越难。SA3的持续伤害/走速buff最后才进入，因为它改变的是已经稳定的角色循环，而不是入门前提。

## force_opponent_to

- 尊重2MP / 5MP的普通近身确认和5HK block +2。
- 被Sprint -> Shadow Slide不断送向角落时提前处理位置。
- 角落后必须同时处理Bomb延迟威胁、strike / throw / shimmy和Sprint高低。
- 高阶段还要处理+42 safe jump与SA3强化后的持续压力。

## create_respect_with

- 2MP / 5MP：普通ground contact。
- L Vagabond Edge：S0 light ender / +3。
- Sprint -> Shadow Slide：核心carry工具。
- 5MK CDR：S2主要Drive转换入口。
- Shuriken Bomb：角落setplay资源，后置。
- Sprint -> Neck Hunter / Shadow Slide / Emergency Stop：earned mix tree。

## payoff_after_respect

- Shadow Slide把普通确认直接换成corner access。
- 角落throw / strike / shimmy更容易成立。
- Bomb把对手的防守时间线变成“现在防本体，稍后还要处理爆炸”。
- +42 safe jump与SA3 buff进一步放大已经拿到的角落状态。

## core_tradeoff

稳定carry / simple Oki vs 更复杂Sprint/Bomb setplay。Bomb stock有限，所以要比较“现在花一颗扩大角落回合”与“保留给下一次更确定的setup”。

## successful_round

1. light / 2MP / 5MK拿普通contact
2. Sprint -> Shadow Slide把对手送向角落
3. dash后strike / throw / shimmy
4. 角落基础稳定后才加入Sprint overhead / low / stop
5. Bomb进入后把角落选择树延长
6. 高阶段用+42 safe jump和SA3 buff继续滚雪球

## common_misplays

- 一开始就一直Sprint/Arc Step，ground confirm反而不稳。
- 没到角落就强行围着Bomb打，浪费资源和注意力。
- 把2MK block +1误当成可取消DRC入口。
- SA3一有就机械开，不看当前round价值与资源。

## unique_decision

相对Rashid，Kimberly的移动重点不是“改变re-entry角度”，而是“把一次普通opening换成角落，并在角落把Bomb与Sprint组织成setplay”。

## transfer_in

- grounded contact / strike / throw / shimmy。
- anti-air / punish / DI / corner Oki。
- movement-after-contact discipline。

## new_skill

- Sprint follow-up职责分工。
- corner carry作为路线价值。
- Shuriken Bomb stock与延迟setplay。
- +42 safe jump与Bomb/Oki叠层。
- SA3持续buff下的round-long调整。

## unlearn

- mobility = neutral里一直跑。
- block +1的2MK就应该DRC。
- 有Bomb就应该马上用。
- setplay选项越多越应该S0全学。
