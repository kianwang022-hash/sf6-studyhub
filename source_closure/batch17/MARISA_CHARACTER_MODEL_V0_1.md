# Marisa Character Model v0.1

Status: **PROVISIONAL — must survive Route/Oki audit**
Character: **MARISA**
Sources: SRC03 / SRC04 / SRC05

## essence_short

Marisa先用高伤、armor和charged strike让对手真心想防；只有这份respect建立以后，5F Enfold command grab才变成高价值选择。

## essence_detail

Marisa很容易被简化成“大体型高伤所以一直猜”，但Current Training Priorities给出的学习顺序完全不是这样。第一步是st.MP target到M Gladius，第二步是M Dimachaerus +36 Oki，之后才是CDR、高伤、+42 safe jump；角落的fully charged 4HP vs Enfold甚至排在更后面。这意味着她的核心因果是先把strike变得足够可怕。charged st.HP block +5、charged 4HP block +4、charged Gladius block +4、Phalanx block +3和H Quadriga block +1都会逼对手更认真地站防；Dimachaerus +31/+36和Phalanx +42又把一次命中变成清楚Oki。等对手开始愿意block、少按、少跳时，Enfold才真正成为2500伤害的高价值答案。

所以Marisa成熟度不是“命中后伤害多高”，而是能否把strike、command grab、shimmy和armor read组织成一个反馈循环：strike让对手respect，respect让Enfold成立，Enfold恐惧让jump/backwalk增加，随后charged strike和anti-air/punish再次变强。

## force_opponent_to

- 尊重charged Gladius / charged heavy的armor与高伤。
- 在+31/+36/+42击倒后先处理meaty strike。
- 对手越愿意站防，Enfold越值钱。
- 对手开始跳/后走躲Enfold后，strike / shimmy / anti-air再次变强。

## create_respect_with

- st.MP target -> M Gladius：S0稳定高伤。
- M Dimachaerus +36：清楚Oki。
- L Dimachaerus +31 active-frame 6HK。
- charged Gladius / 4HP：plus + armor。
- Phalanx +42 safe jump。

## payoff_after_respect

- Enfold 5F / 2500成为可信command grab。
- walk-back / delay开始惩罚throw-tech与jump。
- +42 safe jump继续强迫对手先防。
- corner charged 4HP vs Enfold形成真正二层。
- Burnout时Quadriga进一步增加block pressure。

## core_tradeoff

稳定strike/Oki vs command-grab高收益read；以及立即释放普通版 vs 花时间charge换armor/plus/damage。不是每次都charge，也不是每次都Enfold。

## successful_round

1. light/st.MP/cr.MP拿contact
2. Gladius/Dimachaerus拿damage或+31/+36 Oki
3. meaty strike让对手开始respect
4. 对手站防后加入Enfold
5. 对手跳/退躲grab后回charged strike/shimmy
6. corner / +42后继续反馈循环

## common_misplays

- 第一轮就靠Enfold猜，不先建立strike respect。
- 看到charged版正帧就每次都蓄满，忽略启动时间。
- 把armor当无风险。
- 把+42 safe jump泛化到所有ender。
- 把cr.MK当2MK DRC入口。

## unique_decision

Marisa新增的是“damage-backed respect”：她不是靠command grab本身逼对手，而是先用极高strike损失让对手选择block，再把block行为换成Enfold收益。

## transfer_in

- Honda/Zangief式respect概念。
- strike / throw / shimmy。
- punish / corner / Oki。

## new_skill

- charged normal / charged Gladius时机。
- armor read与release timing。
- +31/+36/+42 Oki分层。
- strike -> respect -> Enfold反馈循环。
- Scutum/Quadriga late pressure。

## unlearn

- 大体型command-grab角色就应该先抓。
- charged版永远优于normal版。
- armor等于安全。
- 高伤route优先于Oki/position永远成立。
