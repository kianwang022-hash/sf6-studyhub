# Manon Character Model v0.1

Status: **PROVISIONAL — must survive Route/Oki audit**
Character: **MANON**
Sources: SRC03 / SRC04 / SRC05

## essence_short

Manon先用普通strike/throw/Oki赢回合；每拿到一次Medal，未来command grab和Renversé的收益就更高，对手因此更想跳、抢、逃，反过来让strike越来越值钱。

## essence_detail

Manon不是“开局就想办法升Medal”的角色。Current Training Priorities先教H Rond-point稳定收尾、st.MP/DR/Renversé、jump-in、DI和anti-air，再教H Rond-point后的dash Oki、普通throw后的strike/throw/shimmy，Medal Level甚至排在SA3之后。这说明她的基础必须先是普通SF6：拿contact、做Oki、观察对手block/mash/jump/tech。

Medal改变的是未来收益结构。Manège Doré从Lv1的2000一路升到Lv5的3700；Renversé与SA3也随Medal增加。于是每一层Medal都在改变对手下一次愿意承担的风险：低Medal时，对手可能更愿意block；高Medal时，为了不吃高伤command grab，对手会更多jump/mash/reversal。这个反应又让strike/meaty/anti-air更强。成熟Manon不是“Medal越高就越抓”，而是能读懂Medal如何改变对手的逃生倾向，并在strike与command grab之间重新定价。

## force_opponent_to

- 先尊重H Rond-point后的dash strike/throw。
- 普通throw后继续处理strike / throw / shimmy，而不是只防一个固定答案。
- Medal越高，Manège Doré的风险越难忽略。
- 对手为了躲高Medal throw跳/抢后，strike与anti-air获得更高收益。

## create_respect_with

- 2MP / st.MP普通contact。
- H Rond-point稳定ender。
- H Rond-point -> forward dash Oki。
- corner meaty strike。
- anti-air cr.HP / OD Rond-point。

## payoff_after_respect

- Manège Doré command grab更容易成立。
- 成功throw/Medal继续提高未来command-grab价值。
- 对手越怕高Medal，jump/mash越多，strike/anti-air越值钱。
- Renversé把combo路线和Medal成长结合起来。

## core_tradeoff

当前稳定damage/Oki vs 追求一次能提高未来回报的Medal interaction。Medal不是当前回合的唯一目标；位置、Oki和可靠damage仍然可能更重要。

## successful_round

1. 普通ground contact或anti-air
2. H Rond-point / Renversé拿稳定结果
3. dash Oki先用strike/throw/shimmy读人
4. 有respect/read时拿Manège Doré或Renversé Medal
5. Medal提高后观察对手是否更爱jump/mash
6. 用strike/anti-air惩罚逃grab行为
7. 再次利用respect拿更高价值throw

## common_misplays

- 开局就为了Medal牺牲所有position/Oki。
- Medal高以后反而更机械command grab。
- 普通throw后把dash当guaranteed throw。
- 把不同Medal Level damage写成固定数字。
- 2MK照抄前面角色做DRC。

## unique_decision

Manon新增的是“reward escalation feedback”：成功interaction会提高未来throw/route收益，而更高收益会改变对手防守行为；你要利用对手行为变化，不是只追数字。

## transfer_in

- Marisa/Lily/Honda的respect-command-grab框架。
- strike / throw / shimmy。
- anti-air / punish / corner / Oki。

## new_skill

- Medal Level future-value tracking。
- Medal对opponent escape behavior的影响。
- H Rond-point dash Oki。
- Renversé route / Medal growth。
- 高Medal下strike与command-grab重新定价。

## unlearn

- command-grab角色的资源应该优先于position。
- Medal越高越应该多抓。
- throw后dash自动等于继续throw。
- Medal Level只是伤害表，不影响决策。
