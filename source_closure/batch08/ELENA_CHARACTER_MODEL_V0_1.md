# Elena Character Model v0.1

Status: **PROVISIONAL — must survive Route/Oki audit**  
Character: **ELENA**  
Sources: SRC03 / SRC04 / SRC05

## essence_short

Elena先用快地面按钮和low拿到接触，再用Scythe/Rhino Horn买一段“起攻时间”；真正的角色特色，是把这段时间交给Lynx Song，长成overhead / low / throw / shimmy的第二层。

## essence_detail

Elena不是“机动性高所以一直乱动”的角色。她的第一层很扎实：5MK只有6F、被防+1，2MK是9F低段且Year4后被防-3，light和2MP也能稳定确认。命中以后，她经常不是马上追最长伤害，而是先决定要哪种end-state：L Spinning Scythe给约+34，M Spinning Scythe给+42，M Rhino Horn给+39，Harvest Circle给更大的+50预算。真正属于Elena的第二层，发生在这些击倒之后：Lynx Song / Lynx Whirl把已有时间换成Mallet Smash overhead、2MK low、throw或walk-back shimmy。也就是说，她不是靠一个资源条，而是靠“先赢到时间，再用移动状态把时间变成新的防守问题”。成熟的Elena会先确保地面接触和稳定ender成立，再逐步增加Lynx分支；如果没有先赚到时间，花哨移动只会增加自己的风险。

## force_opponent_to

- 尊重5MK block +1，不敢近身每次都抢。
- 处理2MK低段与普通throw，不能只站防。
- 被Scythe / Rhino Horn击倒后，必须区分Lynx后的overhead / low / throw / shimmy。
- 角落M Spinning Scythe +42状态下，要处理safe jump而不是随便无敌技。

## create_respect_with

- 5MK：6F / Block +1，第一层ground respect。
- 2MK：9F low / Block -3，逼站防习惯改变。
- L Spinning Scythe：简单+34 end-state。
- M Rhino Horn：+39，能接Lynx Song active-frame路线。
- M Spinning Scythe：+42，角落进入safe-jump family。
- Lynx Song / Whirl：只有已经拿到Oki时间后才打开的branch state。

## payoff_after_respect

- throw / walk-back shimmy更容易成立。
- Lynx Song可以把起攻时间变成Mallet Smash overhead / 2MK low。
- Harvest Circle / Leopard Snap等分支进一步买carry或更大Oki。
- 角落+42状态可以转safe jump。

## core_tradeoff

稳定简单ender / Oki vs 更大的时间预算和Lynx分支复杂度。另一个关键取舍是：这次opening是直接拿damage/carry，还是优先买+34/+39/+42/+50这种更值钱的下一轮。

## successful_round

1. 用5MK / 2MK / light拿ground contact
2. 选择Scythe / Rhino Horn等end-state
3. 用+34/+39等时间进入基础strike/throw
4. 对手开始固定防守后再引入Lynx Song
5. 用overhead / low / throw / shimmy针对
6. 角落再升级到+42 safe jump或SA价值选择

## common_misplays

- 把Elena当“移动角色”一直Lynx，不先赚Oki时间。
- 从Cammy/Juri复制2MK DRC习惯；Elena 2MK不可取消。
- 看到M Scythe +42就把safe jump当所有Scythe的通用结果。
- 一开始就背完整Lynx branch tree，基础5MK +1与简单ender不稳。

## unique_decision

Elena真正新增的是“如何花击倒后的时间预算”：同一次接触可以先选不同end-state，再决定是否用Lynx movement把这份时间转换成high / low / throw / shimmy的第二层。

## transfer_in

- grounded contact / strike-throw-shimmy。
- anti-air / punish / corner / Oki。
- Drive Rush与位置判断。

## new_skill

- 2MK非取消低段与2MP CDR的角色化分工。
- Scythe / Rhino / Harvest等end-state时间预算比较。
- Lynx Song/Whirl branch state。
- +42 safe jump只在正确M Spinning Scythe/corner状态使用。
- SA2后置的damage vs recovery-value选择。

## unlearn

- 快近身角色都应该用2MK DRC当核心低段。
- mobility越多越应该主动用越多。
- +42等于所有Spinning Scythe都能safe jump。
