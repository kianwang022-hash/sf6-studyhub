# Elena Character Model v0.1

Status: **PROVISIONAL — must survive Route/Oki audit**  
Character: **ELENA**  
Sources: SRC03 / SRC04 / SRC05

## essence_short

Elena先用快地面接触拿一个清楚的击倒，再把Lynx Song当成下一轮的选择中心：高、低、投、shimmy逐层打开；Healing只是后期“伤害还是恢复”的额外选择。

## essence_detail

Elena不是“有Healing所以先围着回血玩”的角色。当前资料最先给出的都是普通地面和稳定击倒：st.MK只有6F而且被防+1，cr.MK在Year 4变成被防-3，light / medium contact可以用Spinning Scythe或Rhino Horn收尾。真正属于Elena的第二层发生在击倒以后：Spinning Scythe、Rhino Horn、Harvest Circle等end state给她时间进入Lynx Song，再从Mallet Smash overhead、cr.MK low、throw、shimmy之间组织下一轮。也就是说，她的特色不是“更快地再次贴脸”，而是把一次击倒变成一个结构化mix hub。到更后面，SA2 Revival Dance才加入新的资源问题：这次Super更应该拿伤害/Oki，还是用Healing variation恢复生命并补Drive。Healing很特别，但它应该放大已经建立的角色循环，而不是替代地面确认、反空和Oki。

## force_opponent_to

- 尊重st.MK block +1和快地面按钮，不敢近身每次都抢。
- 被Spinning Scythe / Rhino Horn击倒后必须处理Elena下一轮的高 / 低 / 投 / shimmy。
- Lynx Song一旦进入有效setup，对手不能只按一种防守规则处理。

## create_respect_with

- st.MK：6F / block +1，稳定近身respect。
- cr.MK：9F / Hit +4 / Block -3，Year4后更适合作为低段选择。
- L Spinning Scythe：基础light/low ender，当前+34 family。
- M Rhino Horn：中等接触后当前+39 family。
- Lynx Song：击倒后结构化高低/投/骗拆的mix hub。

## payoff_after_respect

- Mallet Smash overhead与cr.MK low更容易成立。
- 普通throw / shimmy开始惩罚只会站着防或拆投的对手。
- 角落M Spinning Scythe +42可以进入safe jump。
- 后期SA2可以把已有优势换成伤害/Oki或恢复生命/Drive。

## core_tradeoff

稳定击倒与低认知负担 vs 更复杂的Lynx Song mix；后期再加入SA2“当前伤害/Oki vs 恢复生命/Drive”的资源选择。

## successful_round

1. st.MK / cr.MK / light拿ground contact
2. 用Spinning Scythe或Rhino Horn拿清楚击倒
3. 根据end state进入dash或Lynx Song
4. 从overhead / low / throw / shimmy读防守
5. 角落用+42 safe jump放大稳定机会
6. 有SA2时再比较伤害与Healing价值

## common_misplays

- 因为有Healing就过早围着SA2打，基础地面/Oki没建立。
- 一开始就把Lynx Song所有派生一起背，结果没学会什么时候才有setup。
- 把M Spinning Scythe +42当成任何位置都safe jump，忽略corner condition。
- 把Rhino Horn / Scratch Wheel后续数字当固定值，忽略hit height/spacing。

## unique_decision

相对Cammy/Juri，Elena新增的是“击倒后的mix hub组织”：Lynx Song把高、低、投、shimmy集中到同一个下一轮结构里；Healing只是更后面的生命/Drive恢复分支。

## transfer_in

- 快地面contact、strike / throw / shimmy。
- anti-air / punish / corner / DI / Oki。
- CDR / resource cashout基础。

## new_skill

- 识别哪些ender真正给Lynx Song setup时间。
- 在同一mix hub里组织overhead / low / throw / shimmy。
- +42 safe jump只在正确corner Spinning Scythe状态使用。
- SA2伤害/Oki vs Healing恢复的后期选择。

## unlearn

- mobility character = 一直重新突进。
- 有Healing的角色应该尽早围着回血打。
- mix选项越多越应该第一天全学。
