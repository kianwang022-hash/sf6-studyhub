# SF6 Beginner Onboarding Contract

Status: `FROZEN`  
Date: 2026-09-19

## Purpose

Preserve a true first-entry layer without turning every character LEARN page into a duplicate SF6 textbook.

## Product split

### Global Beginner layer

Owned once for the whole game.

It teaches common SF6 language and the minimum round model:

`Neutral -> Contact -> Hit / Block / Whiff -> Route -> KD -> Oki / Reset -> Next Round`

It also owns:
- numpad input notation
- basic frame language
- Confirm / Punish
- Throw / Shimmy / Meaty
- Drive / Drive Rush / DRC / DI / Parry / Drive Reversal / Burnout
- anti-air / Reversal
- common route vocabulary

The learner may skip this layer. It is an entry aid, not a gate.

### Character LEARN

Owned separately by every character.

It must answer:
- how this character wins
- what ordinary SF6 knowledge transfers in
- what is genuinely new
- what old habit must be corrected
- how S0 -> S4 adds character-specific complexity

Do not duplicate the global fundamentals course into 31 character pages.

## Terminology rule

Learner-facing Practical surfaces must not assume unexplained shorthand.

Common terms such as `KD`, `Oki`, `Shimmy`, `Drive Rush`, `DRC`, `PC`, `Meaty`, and `Whiff` must be discoverably explainable in context.

Accepted interaction:
- inline term affordance
- click/hover explanation without leaving the current Practical decision
- optional complete glossary

A glossary hidden only in Reference is insufficient.

## Legacy boundary

Historical StudyHub Fundamentals / Guide / PLAY assets are migration evidence and UX references.

They do not become Current Truth merely by being copied back. Current learner routes and character semantics continue to come from the accepted current repository assets.

## Acceptance

A frontend change fails beginner acceptance if:
- the global beginner entry disappears;
- the global layer is copied redundantly into character LEARN;
- Practical reintroduces unexplained high-frequency shorthand;
- the beginner page breaks the accepted 31-character Gold runtime;
- mobile width overflows.
