# Terry — LEARN

> 目标：第一次学 Terry，不是把所有强必杀连成一条，而是先知道每个 special 在什么时候负责什么。

## 1｜认识角色

### 一句话打法

**Power Wave负责控场，Rising Tackle负责反空/伤害，Burning Knuckle负责carry/Oki；先把这三件事跑通，再让Round Wave、Power Charge、Quick Burn一层一层接棒。**

### 深度角色模型

Terry看起来像标准角色，但真正的特色是“strong special relay”。普通地面先靠2MP、2MK、5HP和Power Wave拿接触；一旦命中，M Burning Knuckle往往不只是伤害，还会把人推向角落并留下+30…42一类的Oki预算。到了角落，forward throw循环和Year4强化后的Round Wave +5再把对手留在墙边。之后Power Charge、Quick Burn、Crack Shoot才把已经成立的机会继续放大。

所以不要把Terry学成“看到命中就把所有特殊技播一遍”。每个special都有职责：Burning Knuckle买位置，Rising Tackle买稳定伤害，Round Wave买plus pressure，Power Charge / Quick Burn买更长转换。真正的进步是知道**这次该把机会交给谁接棒**。

### S0｜最小可玩

先只跑通：

1. Power Wave控中距离，发波后继续看跳。
2. 对手跳，优先Rising Tackle。
3. 两条carry确认：
   - `2LK > 2LP > M Burning Knuckle`
   - `2MP > 5LK > M Burning Knuckle`
4. M Burning Knuckle命中后先只记：**会运角，KD优势受spacing影响，前冲后固定一个strike**。
5. 如果只想要简单伤害：`2LK > 2LP > H Rising Tackle`。

第一阶段只要理解：**同一个小机会，可以交给BK买位置，也可以交给RT买伤害。**

### S1｜基本功成型

加入：

- 5HP block +1的strike / throw / shimmy；
- 5HK PC和挡无敌技后的稳定punish；
- 角落forward throw +22 → dash +3；
- 第一条角落Power Charge → Round Wave → Rising Tackle。

这一层仍然不要求你频繁用Round Wave或OD Quick Burn。

### S2｜实战结构化 · 冲 Master

现在加入：

- 2MK DRC；
- Power Charge / Crack Shoot / Quick Burn relay；
- Round Wave作为**earned +5 pressure**；
- DI稳定路线。

Round Wave很强，但它是29F。你必须先赚到时间，再把+5兑现成2MP / throw / delayed strike / shimmy。

### S3｜选择成熟 · 1500 MR稳定

现在才加入Year4的二层：

- OD Quick Burn → +33 → shimmy；
- Burning Knuckle不同spacing的KD预算；
- 角落Round Wave / 2MP active-frame；
- H Crack Shoot +43 setplay。

你开始根据对手是否tech、是否后走、是否抢按来改变special频率，而不是照固定脚本。

### S4｜高分上探

最后才加入：

- SA2 → Twin Geyser → Triple Geyser；
- SA3 / CA end-state；
- active-frame 5HP / 2MP / Round Wave；
- 高资源角落relay。

高级优化必须回答：

**这条special relay到底多买到了什么？**

## 2｜工具地图

| 工具 | 第一用途 | 决策含义 |
|---|---|---|
| **Power Wave** | 中距离飞道 | 普通控场基座。 |
| **Rising Tackle** | 对空 / damage ender | 直接、稳定，和BK形成第一组分流。 |
| **M Burning Knuckle** | carry / Oki | KD约+30…42，spacing-dependent。 |
| **5HP** | 近身respect | Block +1，可取消。 |
| **2MK** | DRC低段 | S2才进入主线。 |
| **Round Wave** | earned plus pressure | 29F / Hit +8 / Block +5。 |
| **OD Quick Burn** | Year4 shimmy | 1600 / +33，基础打投稳定后再用。 |
| **Power Charge** | route extension | 已确认opening的接力器，不是被防后的自动续压。 |

## 3｜Core Loop

先只记：

**Power Wave / normals → 2MP或light确认 → M Burning Knuckle → 看spacing前冲 → 固定strike → 回中距离。**

然后只加一个分流：

**同一light命中 → H Rising Tackle → 直接伤害 / +27。**

等这两种结果稳定，再学Round Wave和OD Quick Burn。
