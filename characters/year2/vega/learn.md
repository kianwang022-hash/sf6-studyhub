# M. Bison — LEARN

> 目标：第一次学 Bison，不是背 Mine 最大伤害，也不是没 Mine 时乱 Psycho Crusher。先学“种 Mine”，再学 Mine 让同一个 special 变成另一种风险状态。

## 1｜角色本质

### 一句话

**普通 Backfist 命中把 Mine 种到对手身上；Mine 存在以后，Crusher / Backfist / Devil Reverse 的帧差和 Oki 会被重写。**

### S0｜最小可玩：只种 Mine，不要求马上爆

先学：

1. 2LP / 2LK > 5LK > L Backfist Combo。
2. 5MP > 2MP > M Backfist Combo。
3. 看到对手身上出现 Psycho Mine。
4. **不要自动继续爆 Mine。**
5. 一条 charge 路线：
   - 2LK > 2LP > 5LP > L Psycho Crusher。
6. 记住：
   - normal Backfist 被防不安全；
   - normal L/M Crusher 被防大约 -20。
7. 5HP / 4HK block +1 负责普通地面 respect。

S0 的目标是：

**contact → plant Mine → Mine stays active → 继续普通地面。**

### S1｜第一次 cash-in

现在才加入：

- Mine active -> L/M Backfist hit -> +42；
- +42 -> immediate forward jump HP safe jump；
- Mine active + back charge -> M Crusher block -> +6；
- H Backfist normal +31 -> DR Oki。

这一层只理解一个巨大变化：

**同一个 Crusher，没有 Mine 是 -20；有 Mine 可以 +6。**

Mine 改的是招式风险结构，不只是伤害。

### S2｜Hold vs Detonate

现在正式学决策：

#### 留着 Mine
- 不爆；
- 用 5HP / 4HK / throw / low 继续普通 pressure；
- 让对手一直顾忌下一次 Mine special。

#### 现在引爆
- Mine active + H Crusher；
- Mine H Backfist；
- 获得 +5 / +9 block advantage 或 +46/+49 Oki。

问题永远是：

**这次爆 Mine，买到了什么？**

如果只是因为“Mine 在”，那不是理由。

### S3｜OD Crusher / Air Mine Pressure

加入：

- Mine OD Crusher block +10；
- Mine OD Crusher hit up to +82；
- Shadow Rise > Devil Reverse；
- Mine Devil Reverse block +22~+28；
- OD Head Press；
- selected corner Mine replant/cash-in。

这一层必须同时追踪：
- Mine 是否 active；
- back/down charge 是否还在；
- landing height；
- Drive 是否够。

### S4｜Super / Max Cashout

最后加入：

- high-resource Mine + charge routes；
- SA1 / SA2 / SA3；
- corner Mine max；
- burnout Mine pressure；
- matchup-specific Mine timer / detonation timing。

## 2｜工具地图

| 工具 | 第一用途 | 记住什么 |
|---|---|---|
| Backfist Combo | 植 Mine / cash Mine | normal 与 Mine 版本必须分开记。 |
| Psycho Crusher | charge cash-in | normal 大负帧；Mine 版本可正帧。 |
| 5HP | 普通 pressure | Year4 Hit +5 / Block +1。 |
| 4HK Evil Knee | 正帧接触 | 10F / Block +1。 |
| Double Knee Press | non-charge route | 不想 cash Mine 时继续普通回合。 |
| Shadow Rise / Devil Reverse | 后期空中 pressure | Mine 与高度都会改帧差。 |
| Psycho Mine | 对手状态 | 可以留着，不要求马上爆。 |

## 3｜Core Loop

S0：

**ground contact → Backfist plant Mine → Mine active → simple pressure。**

S1：

**Mine active → selected Backfist / Crusher cash-in → +42 / plus pressure → Mine consumed → replant later。**

S2以后：

**Mine active → compare hold vs detonate → choose by current opponent behavior。**
