# Elena — LEARN

> 目标：第一次学 Elena，不是先背 Lynx Song 全家桶，也不是围着 Healing 打。先把 ground contact → stable knockdown → simple Oki 打成完整回合，再逐层打开 mix。

## 1｜角色本质

### 一句话

**Elena先用快地面接触拿稳定击倒；S1以后才把Lynx Song变成overhead / low / throw / shimmy的mix hub。Healing只在最后作为伤害与恢复之间的资源选择。**

### 详细理解

Elena 的基础并不花哨：5MK 只有 6F，而且 block +1；2MK 在 Year4 变成 block -3；light / medium contact 可以用 Spinning Scythe 或 Rhino Horn 收尾。先把这些稳定后，你已经能打完整回合。

真正的角色特色发生在击倒以后。L Spinning Scythe 给 +34，M Rhino Horn grounded hit 给 +39，后面才有足够时间进入 Lynx Song。等你真的赚到这个 setup，Lynx Song 才把 Mallet Smash overhead、2MK low、throw 和 shimmy 组织成同一个选择中心。

所以 Elena 的学习顺序是：

**稳定接触 → 稳定击倒 → 简单Oki → 第一次Lynx高/低/投 → 再加shimmy → 最后才Healing。**

### S0｜最小可玩

先只学：

1. 5MK block +1：2LP / throw 二选。
2. 2LP x2 > L Spinning Scythe。
3. 2MK > 2LP > L Spinning Scythe。
4. 5MP > MP > M Rhino Horn。
5. 2HP / Scratch Wheel 处理典型跳跃。
6. 击倒后只保留一个固定strike和一个throw。

目标：**不靠Lynx花活也能打完整一局。**

### S1｜第一次打开Lynx

只加三件事：

- M Rhino Horn grounded hit -> L Lynx Song -> Mallet Smash overhead；
- 同一个setup加 2MK low；
- 同一个setup加 throw。

先不要加shimmy。先让对手真的开始防高/低/投。

### S2｜完整mix hub

再加入：

- walk-back shimmy；
- 2MP Cancel Drive Rush；
- OD Spinning Scythe -> DR 2MP -> L Lynx Song -> Harvest Circle 的 +41 setplay；
- midscreen M Spinning Scythe +42 -> two dashes -> +2。

这时你开始学“simple Oki vs mix hub”分流。

### S3｜角落与safe jump

加入：

- corner M Spinning Scythe grounded +42 -> immediate forward jump HP safe jump；
- Harvest Circle +50；
- Leopard Snap +48；
- airborne Scythe -> Lynx Whirl 条件分支；
- active-frame Mallet / 5MK / 6MK。

所有数字都保留 corner / spacing / hit-height 条件。

### S4｜Healing 与高资源

最后才加入：

- SA2 normal：伤害 + Oki；
- SA2 Healing variation：恢复生命与 Drive；
- SA1 +42 safe jump；
- SA3 +24 DR setup；
- 高资源 OD Scythe / Rhino / SA 路线。

Healing 的问题不是“能不能回”，而是：

**这次回 1600 血 + Drive，值不值得放弃当前伤害/位置？**

## 2｜工具地图

| 工具 | 第一用途 | 你要记住什么 |
|---|---|---|
| 5MK | 近身respect | 6F / block +1，S0最重要普通按钮。 |
| 2MK | Year4低段 | 9F / block -3，不可取消。 |
| L Spinning Scythe | 基础击倒 | +34，S0默认end state。 |
| M Rhino Horn | medium ender | grounded +39，S1以后可接Lynx setup。 |
| Lynx Song | mix hub | 只有earned setup时才打开。 |
| Mallet Smash | overhead | 与2MK low / throw / shimmy互补。 |
| SA2 | 后期资源选择 | damage/Oki vs Healing/Drive。 |

## 3｜Core Loop

先只记：

**5MK / light / 2MK contact → Scythe / Rhino knockdown → fixed strike / throw → reset spacing。**

然后 S1 只加：

**Rhino +39 → L Lynx Song → overhead / low / throw。**

等这两个循环都稳定，再学 shimmy、+42 safe jump 和 Healing。
