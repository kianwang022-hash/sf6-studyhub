# Yasmine — LEARN

> 目标：第一次学 Yasmine，不是把 Bayani 当成 Juri stock，也不是一上来玩 Mukha / Pangil / SA2。先把 normal Alon 取得 Bayani → 简单 Oki 跑顺，再第一次完成 Boosted Alon 消费。

## 1｜角色本质

### 一句话

**普通 Alon 命中拿 Bayani；下一次 Boosted Alon 把这份状态换成更安全、更高收益的回合。核心是取得 → 消费 → 再取得。**

### 深度角色模型

Yasmine 的 Bayani 是一个循环状态，不是多层库存。普通 Daloy ng Tubig 接 Alon 命中后进入 Bayani；有 Bayani 时，下一次 Alon 会变成 Boosted Alon。normal Alon 被防很危险，大约 -12；Boosted 版本被防大多只剩 -1 到 -3，所以状态真正改变的是风险结构，而不只是伤害。

Boosted Alon 通常会消费 Bayani。于是你不能只想着“有了就花”，也不能一直憋着不用。真正的学习顺序是：

**normal Alon拿状态 → 用+30/+44继续Oki → 下一次opening决定是否Boosted → +42 safe jump/高伤害 → 再把Bayani拿回来。**

Mukha 的表里、Pangil 的setup、SA2持续Bayani都在后面。S0只要求你学会取得，S1才第一次消费。

### S0｜最小可玩：只取得，不消费

先学：

1. 2LP > 5LP/LP > M Daloy > Alon → +30，取得 Bayani。
2. 2MP > H Daloy > Alon → +44，取得 Bayani。
3. +30 后 forward dash → +11，只保留 throw / 2MP。
4. +44 后 two forward dashes → +6，只保留 throw / 2MP / low。
5. Lipad ng Agila 负责典型反空。
6. 屏幕里明确认识：**现在已经有 Bayani，但不要求你马上花。**

### S1｜第一次完成循环

现在才加：

- Bayani active → L Daloy > Boosted Alon → +42。
- +42 → forward jump attack safe jump。
- 2MP > M Talim → +2 point-blank throw。
- 5F punish → normal Alon，重新取得 Bayani。

这一层的重点是第一次完整理解：

**普通Alon取得 → Boosted Alon消费 → 再进入下一轮。**

### S2｜Hold vs Spend

加入 2MK DRC：

- 没Bayani / 想继续循环：走 H Daloy > normal Alon，继续取得。
- 有Bayani / 这次opening值得：Boosted Alon高伤路线。

你要开始回答：

**这次Bayani现在花，买到了什么？**

回答不出来，就先留着。

### S3｜表里和特殊移动

现在才加入：

- Mukha > Ulan cross-up；
- Mukha > Kulog 正面；
- OD Kulog 高度依赖plus；
- Pangil corner/setup；
- OD Boosted Alon hit 后再取得 Bayani。

这里的重点是落点和高度，不是背固定正帧。

### S4｜SA2 Persistent Bayani

最后加入：

- SA2 Nakatagong Lakas；
- 约25秒持续Bayani；
- SA2 OD Boosted Alon +47 setplay；
- Linya ng Liwanag；
- SA1 / SA3 / CA cashout。

SA2不是新的角色身份，它只是把原本“取得→消费”的短循环，临时改成持续强化窗口。

## 2｜工具地图

| 工具 | 第一用途 | 要记住什么 |
|---|---|---|
| 2MP | 近身contact | 6F / block 0 / cancellable。 |
| 2MK | 低段DRC | 8F / block -6 / cancellable。 |
| normal Alon | 取得Bayani | 命中拿状态；被防很危险。 |
| Boosted Alon | 消费Bayani | 安全性大幅提升，并可进入+42。 |
| M Talim | 贴脸状态 | hit +2 point-blank throw。 |
| H Talim | Oki ender | +37。 |
| Mukha | 表里/高度mix | S3再学。 |
| SA2 | persistent Bayani | S4 install。 |

## 3｜Core Loop

S0：

**ground contact → normal Alon → gain Bayani → +30/+44 simple Oki → next turn。**

S1再加：

**Bayani active → Boosted Alon → +42 safe jump → Bayani consumed → reacquire later。**

把这两个循环跑顺，才进入 Mukha / Pangil / SA2。
