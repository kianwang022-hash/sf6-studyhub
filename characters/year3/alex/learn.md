# Alex — LEARN

> 目标：第一次学 Alex，不是先背完整 Prowler 树，也不是一有正帧就猜 Power Bomb。先学会用普通 contact 和 +2 压力让对手真的愿意防，再把 respect 换成 Alex 独有的高低投分支。

## 1｜角色本质

### 一句话

**先用稳定 strike 和 +2 压力买到 respect，再用 Power Bomb 与 Prowler 多分支让对手无法只押一种防守。**

Alex 的强点不是“抓投伤害高”这么简单。Year4 把 5MP 命中变成 +4、4MK 被防变成 +2，又让 2HK 命中可以转 Prowler。它们都在告诉你同一件事：先用普通 SF6 的接触、确认和击倒拿住回合，再把对手逼进越来越难简化的防守题。

Prowler 也不是一个让你在 neutral 里长期蹲着等的模式。你最好从 M Flash Axe 命中、2HP、2HK 命中或其他明确 setup 赚到入口，再在里面选 Heavy Lariat、Air Stampede、低段或 throw。这样 stance 是“赢到一次接触后的奖励”，不是你主动把自己锁进不能 block 的状态。

## S0｜最小可玩：只学一条 Prowler 出口

先学五件事：

1. 低段基础确认：
   - 2LK > 2LP > L Flash Axe

2. 中拳稳定击倒：
   - 5MP > H Aerial Knee Smash
   - H Knee 常见结束状态 +29

3. 对手跳：
   - M Aerial Knee Smash

4. 4MK 被防：
   - 当前 +2
   - 第一反应先 5LP / strike
   - 不要立刻把 Power Bomb 当保证答案

5. 只学一个 Prowler 入口：
   - 2MP > M Flash Axe hit > Prowler > Heavy Lariat

S0 的核心不是“我会四种 Prowler 猜拳”。

而是：

**我知道什么时候是我赚到的 stance entry。**

## S1｜Respect → Power Bomb

现在才正式把 Power Bomb 放进主线。

4MK 被防 +2 后，先让对手见过：

- 5LP；
- 5MP；
- throw；
- block / read。

当对手开始愿意站着防，你才加：

- 63214P｜Power Bomb。

这里一定要记住：

**+2 给你下一拍优势，不等于 Power Bomb guaranteed。**

Power Bomb 命中后的 +15 也不是保证贴脸再抓。它更像一次高价值现金化，之后回到 spacing / read。

这一阶段再加入两个很具体的 Oki：

- OD Aerial Knee Smash +27 -> dash -> +5；
- forward throw +28 -> dash -> +6。

## S2｜完整 Prowler 树

到这里才把同一个 earned entry 展开：

- Heavy Lariat：plus strike，block +3；charged +5；
- Air Stampede：overhead，block +2；
- Sweep Combination：low，但 block -17 / -20，风险非常高；
- Hyper Takedown：stance throw，KD +32；
- Dangerous Armbar：特殊 projectile/read 工具，不是通用答案。

再加入 Year4 新桥：

- 2HK hit -> Prowler。

现在你问的不是“下一招是什么”，而是：

**对手现在在防什么，我该用 Prowler 的哪一种答案？**

## S3｜同一个 opening，买什么价值

现在开始比较：

- 继续 pressure；
- 进 stance；
- side switch；
- 伤害；
- 更大的 Oki。

两个重要 exact state：

- forward-input OD Power Drop -> +42；
- corner M Flash Axe > Prowler MP > j.MP > Flying Cross Chop -> point-blank +8。

它们都不是“Alex 所有类似路线都这样”。

必须保留 exact-state 条件。

## S4｜SA / Omega / Matchup

最后才加入：

- Omega Wing Buster；
- SA1 / SA2 / SA3 lethal；
- active-frame 细节；
- matchup Dangerous Armbar；
- character-specific spacing / hurtbox lab。

## 2｜工具地图

| 工具 | 第一用途 | 你要记住什么 |
|---|---|---|
| 5MP | 普通 contact | Year4 Hit +4；S0 直接接 H Knee。 |
| 4MK | +2 pressure bridge | 先 strike，Power Bomb 后置到 respect。 |
| 623K | anti-air / ender | 让 Alex 不靠猜抓也能稳定拿下一轮。 |
| 236MP | M Flash Axe | grounded hit 后进入 Prowler 的主要门。 |
| 2PP | Prowler | earned-entry stance，不是 neutral 常驻。 |
| 63214P | Power Bomb | respect/read 现金化；+15 不是保证续抓。 |

## 3｜Core Loop

S0：

**ground contact -> Knee/Axe稳定结果 -> 4MK +2继续strike -> earn respect -> one Prowler Lariat exit -> reset。**

S1：

**strike / +2 pressure -> opponent starts blocking -> Power Bomb becomes credible -> opponent jumps/backwalks -> strike/anti-air gets stronger。**

S2：

**earned Prowler entry -> plus strike / overhead / low / throw by opponent behavior -> next knockdown or reset。**
