# C. Viper — LEARN

> 目标：第一次学 Viper，不是先练一套看起来最炫的 HJC 长连。先让她作为一个普通 SF6 角色能打一整回合，再只学 **一条** High Jump Cancel，理解她真正特殊在哪里。

## 1｜角色本质

### 一句话

**先跑普通 +1 pressure 与稳定击倒；opening 值得时，再用 HJC 把 Normal 重写成 special route。**

Viper 的复杂不是“输入多”。

真正的新规则是：

**很多 Normal 虽然不能普通 special cancel，但可以先 High Jump Cancel，再在 pre-jump 取消 special。**

这会重写你对“这个按钮能接什么”的理解。

## S0｜最小可玩：先会打一局，再学一个 HJC

### 1. 普通 pressure

5MP：
- startup 8F
- Hit +6
- Block +1

被防以后先学：
- 2LP
- throw

对手开始 tech：
- walk-back shimmy

这已经是完整进攻，不需要 HJC。

### 2. 一条稳定击倒

2LP > 2LP > 5LK > H Thunder Dash > Tracer Combination

H Thunder Dash：
- Block -24

所以：

**只有确认命中才交。**

Tracer 会花 Drive。

结束大约：
- +25..26

forward dash 21F以后：
- 大约 +4..5

接：
- 5MP
- throw
- 2MK
- shimmy

### 3. 一条 meterless route

Year4：

5MK > 5LK > M Thunder Dash

5MK当前Hit +5。

这一条用来提醒自己：

**不是每次opening都必须花Drive。**

### 4. 只学一个 HJC

2MK hit  
-> High Jump Cancel  
-> M Thunder Dash  
-> Tracer Combination

这里的重点不是combo本身。

重点是：

2MK没有普通direct special cancel，
但它可以HJC。

所以Viper可以把它重新接到special。

HJC在SA1 install以外会花Drive；Tracer也会花Drive。

这是一条高成本identity route，不是默认每次使用。

### 5. Anti-air

S0先用：
- 5HK

先把跳压回地面。

## S1｜第一次打开Viper的分支逻辑

### Burning Kick：Hit和Block不是同一答案

Burning Kick **命中**：
- Knuckled Pursuit
- +23 knockdown family

Burning Kick **被防**：
- Double Burn
- Block +2

所以不要背：

“Burning Kick后按某个固定东西”。

你要先看：
**Hit还是Block？**

### Seismic Hammer

第一条只学：

2HP  
-> M Seismic Hammer  
-> High Jump j.MP  
-> H Burning Kick

现在你第一次把地面opening变成air conversion。

### L Thunder Dash -> Tracer

5MP > 2MP > L Thunder Dash > Tracer

结束约：
- +37

开始给你更大的setplay预算。

## S2｜HJC从一个技巧变成结构

现在才加入：

- 5MK -> HJC -> M Thunder Dash
- OD Seismic -> delayed HJC route
- DR 6MP overhead
- DR 2MK low
- corner H Tracer active meaty

这时每次问：

**花这些Drive和执行复杂度，我买到了什么？**

可能是：
- carry
- damage
- corner
- setplay

如果只是“看起来更Viper”，不值得。

## S3｜Exact state

现在再记数字：

### +45
Seismic -> delayed HJ j.MP -> immediate L Burning Kick  
-> +45

### +42
Seismic -> HJ j.MP -> immediate M Burning Kick  
-> +42

### +44
Seismic -> HJ j.MP -> H Burning Kick  
-> +44

它们是三个不同route state。

不是：

“Viper差不多都是+42左右”。

OD Thunder Dash自身也有+42，但又是另一个owner，而且**不能接Tracer**。

## S4｜SA1 Install

最后才正式打开：

SA1 Limit Decoupler

install期间：
- Super Jump / HJC不再吃普通Drive成本
- special follow-up也改变资源经济

这时你才能开始真正高密度的Viper route。

但必须记住：

**SA1 install里的免费，不代表普通回合HJC免费。**

## 2｜工具地图

| 工具 | 第一用途 | 你要记住什么 |
|---|---|---|
| 5MP | +1 pressure | Viper不用HJC也有正常进攻。 |
| H Thunder Dash | confirmed ender | Block -24，绝不裸交。 |
| Tracer | Drive follow-up / knockdown | 普通Dash才能接；不同强度不同Oki。 |
| HJC | cancel-routing grammar | 花Drive，把Normal重新路由到special。 |
| Burning Kick | conversion / pressure | hit→Knuckled；block→Double Burn。 |
| Seismic Hammer | launcher | 进入air route / exact setplay。 |

## 3｜Core Loop

S0：

**ground contact -> confirmed H Dash/Tracer -> dash +4..5 -> 5MP / throw / low -> next contact。**

Identity proof：

**2MK hit -> HJC -> M Thunder Dash -> Tracer。**

S1：

**contact -> decide ordinary / Burning / Seismic -> outcome-specific branch -> knockdown -> back to pressure。**

S2+：

**valuable opening -> spend Drive + execution -> HJC/air conversion -> carry/setplay -> exact state。**
