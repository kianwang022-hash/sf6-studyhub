# Sagat — LEARN

> 目标：第一次学 Sagat，不是站最远一直发 Tiger Shot，而是学会用火球改变对手怎么移动，然后用长拳脚和 Tiger Uppercut 把这个反应真正打到。

## 1｜认识角色

### 一句话打法

**Tiger Shot 先逼对手改变前走、跳跃、蹲和 Parry 节奏；你继续看跳，再用 5MP / 2MP / 5MK 接住地面反应，最后用 Uppercut / Knee 把 contact 换成高价值下一轮。**

### 深度角色模型

Sagat 确实比前面的标准角色更重 fireball，但如果把他理解成“站最远一直扔波”就会学歪。Tiger Shot 的第一作用是改变对手的移动规则：High Tiger Shot 逼他考虑跳、蹲、Perfect Parry、前走节奏和 Drive；一旦对手为了处理火球改变位置，Sagat 的 5MP、2MP、5MK、6HK 这些长而有价值的拳脚就更容易接住那个反应。

所以发波不是注意力结束点。你发完以后最重要的事情反而是继续看跳、看前走、看对手是否已经进入 5MP / 5MK 的工作区。Tiger Uppercut 让“看到火球就跳”不能成为免费答案；5MP block +2 则把对手被迫站住之后的收益继续转成 strike / throw / shimmy。

S0 先不要碰 +42 safe jump。先把 **shot → anti-air / long normal → Uppercut → Oki** 打成完整循环，再学 Tiger Knee 的 spacing 和 airborne-hit 条件。

### S0｜最小可玩

先只做这几件事：

1. M / H High Tiger Shot：用不同速度改变对手推进节奏。
2. 发波后继续看跳：典型跳跃优先 Tiger Uppercut。
3. Light 确认：2LK > 2LK > 5LP > M Tiger Uppercut。
4. 5MP 确认：5MP > 2LP > M Tiger Uppercut。
5. 第一套下一轮：H Tiger Uppercut 常见 +27，forward dash 23F 后约 +4；先只保留一个 5MP strike。
6. 被防后的近身：5MP block +2，只先练 strike / throw 两种。

目标不是“火球很多”，而是：

**Tiger Shot → 对手反应 → 反空或地面接触 → Uppercut → 下一 Turn。**

### S1｜基本功成型

加入：

- L Tiger Uppercut +32 → Drive Rush；
- 2MP → M Tiger Nexus → Mighty Tiger；
- 5MK → 6HK target combo 的 +38；
- 6HK PC 的稳定 punish；
- forward throw +21 的基础下一轮。

这时仍然不需要背完整 Tiger Knee 帧差树。

### S2｜实战结构化 · 冲 Master

现在才加入 2MP Cancel Drive Rush：

- Whiff：停；
- Block：DR 5MP 可以形成 +6 的强选择点；
- Hit：2MP > CDR > 5MP > 4HP > H Tiger Knee Crush > L Tiger Uppercut。

注意一个和前面角色很不一样的地方：

**Sagat 的 2MK 不是可取消 Normal。**

所以不要把 Ryu / Ken / Luke 的 2MK DRC 习惯直接复制过来。

当前来源里的 DI “简单路线”有字符串缺口，所以这一层宁可不补，也不凭记忆造一条。

### S3｜选择成熟 · 1500 MR稳定

现在才真正学 Tiger Knee：

- L / M / H Knee 的 KD 优势是范围，不是固定数字；
- H Tiger Knee 普通状态大约属于 +41…47 family；
- **只有特定 airborne hit 才是 +42 safe jump**：
  H Tiger Knee Crush airborne hit -> +42 -> forward jump HP。

这一层真正的学习目标是：

**说得出这次为什么是 +42，而不是只背“重 Knee = +42”。**

### S4｜高分上探

最后加入：

- charged H Tiger Uppercut；
- OD Tiger Knee；
- Greedy / Nova 高价值 Oki；
- active-frame meaty；
- SA1 / SA2 / SA3；
- matchup-specific projectile cadence 和 punish。

高分优化仍然围绕同一个问题：

**这颗 Tiger Shot 有没有真的改变对手？如果没有，下一颗可能就不该发。**

## 2｜工具地图

| 工具 | 第一用途 | 决策含义 |
|---|---|---|
| M High Tiger Shot | 空间塑形 | 16F / Block +3；较慢节奏逼对手改变移动。 |
| H High Tiger Shot | 快速 fireball 节奏 | 12F / Block -1；更快，但发完仍要看跳。 |
| Tiger Uppercut | 反空 / 稳定 ender | fireball 控场可信的必要条件。 |
| 5MP | 长 medium + respect | 6F / Hit +6 / Block +2；S0 核心地面兑现。 |
| 2MP | 可取消 medium | 7F / Hit +4 / Block -1；S2 CDR 主入口。 |
| 5MK | 长 poke / target combo | Year4 接 6HK 后进入 +38 family。 |
| 6HK | 强空间/PC工具 | 16F / Hit +7 / Block +4。 |
| Tiger Knee | 大 Oki / 位置 | KD 结果高度依赖 spacing / hit state；后置。 |

## 3｜Core Loop

先只记：

**High Tiger Shot → 继续看跳 → 对手跳就 Uppercut / 地面推进就 5MP → 确认到 Uppercut → dash / +2 打投 → 回到空间判断。**

等这条在真人里稳定，再把 Tiger Nexus、CDR、Tiger Knee 和 safe jump 一层层接进来。
