# Ed — LEARN

> 目标：第一次学 Ed，不是先蓄 Psycho Knuckle，也不是站在远处一直 Flicker。先学会把 **中距离 contact → Blitz 击倒 → Rush 重新贴近** 跑成一个完整回合。

## 1｜角色本质

### 一句话

**Ed 用更长的中距离触角拿到 contact，再用 Blitz 击倒和 Rush 把距离重新压回来；charged Flicker 只是后续 spacing 工具，不是自动投循环。**

Ed 看起来像“拳击角色”，但他的真正不同不在近身拳速，而在**接触距离和重新进身**。

## S0｜最小可玩：range → knockdown → re-entry

先学两条普通 confirm：

1. 2LP > 5LP > M Psycho Blitz
2. 5MP > 2LK > M Psycho Blitz

M Psycho Blitz：
- 常见结束 +39
- 被防 -12

所以必须确认。

### Ed 的中距离身份

再学：

- confirmed 5MK hit > L Psycho Flicker

L Flicker：
- hit +1
- block -6

所以：

**5MK 被防时不要自动接 Flicker。**

这条不是为了大伤害，而是让你第一次感受到 Ed 能在比普通拳脚更远的位置抓到人。

### 真正的 Core Loop

M Blitz +39 后：

- Drive Rush -> 约 +8
- 5HP
- 2MK
- throw
- 对手开始 tech 后 walk-back shimmy

这就是 Ed 第一阶段最重要的东西：

**远处摸到一次，不是结束；你要把它重新换成近身回合。**

对手跳：
- L Psycho Uppercut

## S1｜+4 pressure，但别把 Flicker 学歪

### 5HK +4

5HK 被防：
- +4

先学：
- 5MP frame trap
- throw
- 对手tech后 5HP shimmy

这说明 Ed 的近身pressure不需要依赖Flicker。

### Charged Flicker +4

charged L/M Psycho Flicker：
- block +4

但 Year4 的关键变化是：

**拉近距离变了。**

所以 +4 后不能自动按throw。

你要先看：
- 已经够近 -> throw
- 稍远 -> walk throw
- 对手爱按 -> 5MP
- 对手爱tech -> shimmy

### H Blitz

普通 H Blitz：
- +40
- DR 后约 +9

继续把同一个 re-entry loop 做得更强。

### Exact +42 Safe Jump

只有声明的：

5MP > 5HP > H Psycho Blitz  
在对应 Hitman Combination state 下：

- +42
- immediate forward jump HP safe jump

不要把所有 H Blitz 都记成 +42。

### Throw Year4 修正

- forward throw +24
- back throw **current +17**

旧 back throw +24 loop 不再成立。

## S2｜同一个 opening 买什么价值

现在加入：

### Kill Switch

需要运角：
- 5MP > 5HP > Kill Switch Break > M Psycho Uppercut

Punish Counter：
- 5HK PC > 5HP > Kill Switch Chaser > H Blitz

Kill Switch 的意义不是“Ed combo必须更长”。

而是：

**这次 opening 值不值得拿位置。**

### Psycho Spark / Shoot

现在才加入屏幕控制。

Psycho Spark：
- Hit +3
- Block -5

之后根据距离和版本选 Psycho Shoot。

Year4 的 OD Shoot 速度差更明显，可以理解成：
- 慢的：更适合走在后面
- 快的：更快形成pressure

它的目的仍然是让对手重新进入你的 5MK/Flicker contact range。

### Drive / DI

只先保留一条稳定 CDR 和一条 DI route，最后都回 H Blitz。

### 2HP Oki

普通：
- +30 -> dash -> 5HP active meaty

CH / PC：
- +47 -> double dash -> +9

这两个状态不能混。

## S3｜Psycho Knuckle 才进入主线

现在你已经会正常玩 Ed 了，才学 Knuckle。

### Lv1
- 39F
- block 大约 -2
- corner 可能改变 practical state

### Lv2
- 69F
- Block +4

它们都是大commitment空间工具。

不是“蓄得越久越高级”，而是：

**你愿意用多少时间去换空间威胁。**

### Exact corner Spark

exact corner +38：
- 2LP whiff
- Psycho Spark meaty
- about Hit +13 / Block +5

这不是“Spark本身+5”。

### OD Flicker

再加入高资源extension / carry。

## S4｜SA2 / High MR

最后加入：

- SA2 Psycho Cannon长route
- SA3 lethal
- matchup-specific Flicker charge frequency
- Psycho Shoot slow/fast cadence
- Knuckle / corner spacing lab

## 2｜工具地图

| 工具 | 第一用途 | 你要记住什么 |
|---|---|---|
| 5MK | 长中距离contact | confirm后才接L Flicker。 |
| L Flicker | midrange capture | ordinary Block -6；charged版本另算。 |
| M Blitz | S0稳定ender | +39 -> DR约+8。 |
| H Blitz | 更强Oki owner | ordinary +40；exact route才+42。 |
| 5HK | close plus pressure | Block +4。 |
| charged Flicker | spacing-conditioned +4 | Year4不是自动贴脸投。 |
| Kill Switch | carry / route branch | S2以后按位置选。 |
| Psycho Spark/Shoot | screen control | 服务于重新拿contact。 |
| Psycho Knuckle | charged space threat | S3后加入。 |

## 3｜Core Loop

S0：

**5MK / 5MP / light拿contact -> M Blitz +39 -> DR +8 -> strike / low / throw / shimmy -> 对手退出 -> 再回中距离抓。**

S1：

**re-entry -> 5HK +4 / charged Flicker +4 -> spacing/read -> 下一次close turn。**

S2：

**opening -> choose re-entry / carry / projectile position -> 再回同一个range loop。**
