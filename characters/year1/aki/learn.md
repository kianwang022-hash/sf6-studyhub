# A.K.I. — LEARN

> 目标：第一次学 A.K.I.，不要先背“有毒一套、无毒一套”的完整连段表。先把一个普通 opening 变成 **上毒 + H Serpent Lash +44 + 一次正常起攻**。

## 1｜角色本质

### 一句话

**先给毒并拿 +44 正常起攻；对手已经中毒以后，再把下一次 opening 升级成毒爆、运角和毒池 setplay。**

A.K.I. 的难点不是“毒会掉血”。

真正改变决策的是：

**对手有没有中毒，会改变你下一次命中后的路线价值。**

所以第一层不是“毒爆最大伤害”，而是先建立这个状态。

## S0｜最小可玩：只学上毒 +44

先学两条：

1. 低段：
   - 2LK > 2LP > 2LP > H Serpent Lash

2. 中距离：
   - 5MK > 5MP > H Serpent Lash

普通 H Serpent Lash：
- 结束约 +44
- A.K.I. forward dash 19F
- dash x2 后大约还有 +6

接下来只做：

- 2MK low
- 5HK strike
- slight-delay throw
- 对手开始 tech 后再 shimmy

注意：

H Serpent Lash 被防是 **-20**。

所以它是 confirm ender，不是 raw pressure。

### 对手已经中毒怎么办？

S0 只记一句：

**下一次 Serpent Lash 可能发生毒爆，路线会变。**

先不要优化。

你只要形成“出手前看毒状态”的习惯。

## S1｜第一次学 poison burst

现在才正式学状态差。

### Poisoned M Serpent Lash

对手已经中毒：

M Serpent Lash -> poison burst -> 大约 +69

可以接：
- 5HK
- Heel Strike
- L Serpent Lash

这时你第一次真正看到：

**同一招因为 poisoned state，变成了另一种 route。**

### Poisoned H Serpent Lash

也可以：

poisoned target -> light confirm -> H Serpent Lash burst -> DR 2MP -> H Serpent Lash

这样毒爆以后又回到你熟悉的 +44。

### Toxic Wreath

5MP > Toxic Wreath

结束大约 +40。

这给你第二个稳定 knockdown owner，不需要每次都走 H Lash。

### Drive Rush

从 +44 开始加：

- DR 2MK low
- DR 3MP overhead

别把 Drive Rush 单独学成另一套游戏。

## S2｜毒 + 位置

现在才开始问：

**这次毒爆能不能把人送进角落？**

### Corner poison puddle

典型思路：

poisoned M Lash burst  
-> 5HK  
-> Toxic Wreath  
-> DR 5HK  
-> Venomous Fang  
-> Orchid Spring

毒池建立后大约 +38 family。

这时对手会更想：

- jump
- walk forward
- invincible reversal

所以你不是只看持续伤害。

你要看：

**毒池正在改变对手怎么逃。**

### Year4 OD Chaser block-poison

当前版本：

OD Nightshade Pulse -> Nightshade Chaser 被普通防御  
可以给对手上毒。

但：

**Drive Parry 是例外。**

所以这个工具不是“贴脸强压”。

它更像：

**先把毒挂上，让对手不得不移动，再用 Lash / 5MK / anti-air / whiff punish 等他犯错。**

### Qiong Qi

5HP > HP

- unpoisoned：大约 +34
- poisoned burst：大约 +54

这是另一个很好的状态对照。

## S3｜Exact setplay

现在再加入数字密集层：

### +18 -> 6HP active meaty

例如：

H Lash +44  
-> 2LK whiff x2  
-> exact +18  
-> 6HP active meaty

当前 Year4 6HP active window增强，这类setup价值更高。

但 +18 必须带着前置route。

### OD Cruel Fate

Hit：
- +42
- jump-in budget

Block：
- +2
- 2LK / throw / delayed strike

绝对不要把 +42 套到 Block。

### OD Serpent Lash poisoned burst

只有 opponent poisoned：

OD Serpent Lash burst -> about +71

这已经是高资源value choice，不是基础角色定义。

## S4｜SA / High MR

最后加入：

- SA2 persistent poison field
- SA3 lethal
- max poison-burst routes
- matchup-specific poison cadence
- safe-jump / puddle / airborne hit Training Mode lab

## 2｜工具地图

| 工具 | 第一用途 | 你要记住什么 |
|---|---|---|
| H Serpent Lash | S0 confirm / anti-air | ordinary hit +44；Block -20。 |
| M Serpent Lash | S1 burst owner | poisoned target时可进入+69 family。 |
| Toxic Wreath | 第二个knockdown owner | +40；Block -4。 |
| Orchid Spring | corner poison field | S2以后才进入主线。 |
| OD Nightshade Chaser | Year4 poison entry | ordinary block上毒，Drive Parry例外。 |
| OD Cruel Fate | S3 value tool | Hit +42 / Block +2必须分开。 |

## 3｜Core Loop

S0：

**normal contact -> H Serpent Lash -> poison established +44 -> two dash -> low / strike / throw -> next contact。**

S1：

**check poisoned state -> poisoned opening -> burst route -> either cash out or return to +44。**

S2：

**poison burst -> carry corner -> Orchid Spring puddle -> punish escape -> next poisoned opening。**
