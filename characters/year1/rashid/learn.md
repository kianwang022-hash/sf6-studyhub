# Rashid — LEARN

> 目标：第一次学 Rashid，不是先学“怎么飞”，而是先让快地面确认、稳定击倒和下一 Turn 跑起来。移动和风是后面用来改变 re-entry 角度的扩展。

## 1｜角色本质

### 一句话

**先用普通地面拿 contact，再用 M Spinning Mixer 或 Eagle Spike 买 Oki / 位置；对手适应固定下一轮后，才逐层打开 Arabian Cyclone、Air Current 和 Ysaar。**

### S0｜最小可玩

先只学：

1. 5MP / 2MP block +1：strike / throw。
2. 2LK > 5LP > 5LP > M Spinning Mixer。
3. M Spinning Mixer 命中后 +31，Drive Rush 后先固定一个 strike。
4. 2MP > 5LK > L Eagle Spike，作为第一条 carry 分流。
5. 反空和 OD Mixer 的防守职责。

这一阶段目标是：**不靠风也能打完整 Rashid。**

### S1｜Run Oki

加入：

- M Eagle Spike > Run > active cr.MP。
- M Eagle Spike > Run > throw。
- 5HP PC > H Eagle Spike。
- 5HK PC > 6MP > L Eagle Spike。
- forward throw +27。

spacing 不对时不要硬跑。

### S2｜Arabian Cyclone

现在才加入：

- 2MK DRC；
- H Arabian Cyclone > Wing Stroke > L Arabian Skyhigh；
- DI carry / Oki 分流；
- Nail / Rolling Assault 的第一条高 Oki 分支。

学习目标不是“动作更多”，而是能解释：**为什么这次固定 Oki 不够，必须换一个 re-entry 角度。**

### S3｜Air Current

加入：

- Air Current Boosted M Mixer +42；
- Boosted L Mixer block +2；
- +42 forward jump；
- selected OD Arabian Cyclone active-frame setplay。

最重要规则：

**normal M Mixer = +31；Boosted M Mixer = +42。没有 Air Current 就不能偷换。**

### S4｜Ysaar

最后才学：

- SA2 Ysaar；
- Ysaar + overhead / low / throw；
- 高资源 Air Current；
- SA1 / SA3；
- charged Whirlwind / Rolling Assault 高阶分支。

Ysaar 是一段新的屏幕规则，不是“更长的 combo”。

## 2｜Core Loop

S0：

**ground contact → M Mixer +31 / Eagle Spike carry → fixed strike / throw → reset。**

S3 才变成：

**earned Air Current → Boosted +42 → jump-in / re-entry → 回 ground loop。**
