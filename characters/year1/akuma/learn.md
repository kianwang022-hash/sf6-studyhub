# 豪鬼 Akuma — LEARN

> 目标：第一次学豪鬼时，不是把空波、百鬼、蓄波、瞬移、SGS 一次全背，而是先打稳一套 shoto 整轮，再让额外 option 一层一层加入。

## 1｜认识角色

### 一句话打法

**先用火球、升龙、2MP / 2MK 和普通打投把对手逼出固定防守，再用空波、百鬼、蓄波和特殊移动去惩罚那个“已经学会”的防守。**

### 深度角色模型

豪鬼最容易被学歪成“招很多，所以每回合都要做更多事情”。其实他的第一层非常正常：Gou Hadoken 控空间，Gou Shoryuken 反空，2MK 取消绿冲，5MP 被防 +1，H Shoryuken 收尾能给 +30 的稳定起攻。

真正特别的是第二层：豪鬼可以用 air fireball、charged fireball、Demon Raid、Adamant Flame、Ashura 等方式改变对手必须处理的角度和时间。但这些 option 不应该同时打开。对手还没学会尊重你的普通地面时，百鬼和瞬移只会让你自己增加风险；尤其豪鬼当前只有 9000 体力，无理由的高承诺选择成本更高。

所以豪鬼的长期学习逻辑不是“把全部招式练熟”，而是：

**基础 shoto 稳定 → 观察对手防守习惯 → 只打开一个针对性 option → 看他怎么适应 → 再决定保留、降频或换另一层。**

### S0｜最小可玩

先只跑通：

1. Gou Hadoken 控中距离，发波后继续看跳。
2. 对手跳，优先 Gou Shoryuken。
3. 两条稳定确认：
   - `2LP > 2LP > 5LK > H Gou Shoryuken`
   - `2MP > 2MP > H Gou Shoryuken`
4. H Shoryuken 常见 +30：`5MK whiff` 后约 +4，先固定一个 strike。
5. 同样的 light / medium contact，再学一条：
   - `L Tatsu > 2HK` → 当前 +37 family。

S0 的豪鬼特色不是百鬼，而是**开始理解“同一个 opening 可以买不同的 Oki 时间预算”**。

### S1｜基本功成型

加入：

- 5MP block +1 的 strike / throw / shimmy；
- 5HK block +3，但必须带 multi-hit / spacing 条件理解；
- 4F / 6F punish；
- 挡无敌技后的稳定 H Adamant Flame；
- +30 起攻从单一 strike 长出 throw / shimmy / block。

这一阶段仍然不要求用百鬼当主接近。

### S2｜实战结构化 · 冲 Master

开始加入资源分流：

- `2MK DRC`；
- OD Tatsu → M Shoryuken 的 +32 family；
- DI wall splat；
- 角落 OD Adamant Flame；
- Year 4 的 6HP PC。

此时你要学的是：**+30 / +32 / +37 / 位置 / Drive，哪个 end-state 现在最值钱。**

### S3｜选择成熟 · 1500 MR稳定

现在才真正打开 option density：

- Demon Raid：Low Slash / Guillotine / Blade Kick 分开学；
- charged Gou Hadoken：只有有安全时间预算时才蓄；
- air fireball：只在它真的改变对空节奏时用；
- H Adamant +47 后只保留一两个经过验证的 setplay。

关键不是会多少，而是**额外 option 失败以后会主动降频**。

### S4｜高分上探

最后才加入：

- fully charged Gou Hadoken meaty；
- OD Adamant +63 → Ashura；
- active-frame 5HP；
- SA3 高资源优化；
- Shun Goku Satsu combo / point-blank setup。

这些必须和对手能怎么逃、什么时候能跳、什么时候能无敌一起学，不能只背口诀。

## 2｜工具地图

| 工具 | 第一用途 | 决策含义 |
|---|---|---|
| **5MP** | 近身正帧接触 | Block +1，先建立普通 respect。 |
| **5HK** | 强正帧接触 | Block +3，但多段 / spacing 不能省略。 |
| **2MP** | 稳定确认 | 6F / Hit +6 / C。 |
| **2MK** | 低段 DRC入口 | Block -6；不 DRC 就结束。 |
| **Gou Hadoken** | 标准火球 | 先学普通版，再学 charged。 |
| **Gou Shoryuken** | 反空 / ender | H 版 +30 是第一套 Oki 标尺。 |
| **Demon Raid** | 针对固定防守 | 每个 follow-up 单独判断。 |
| **Adamant Flame** | 路线 / setplay ender | H +47、OD更复杂，后置。 |

## 3｜Core Loop

**火球 / 地面 → 对空或确认 → H Gou Shoryuken +30 → 固定起攻 → 对手脱出后回中距离。**

然后只加一个分流：

**同一 opening → L Tatsu > 2HK +37 → 更大的 Oki 时间预算。**

等这两套都稳定，再打开百鬼和蓄波。
