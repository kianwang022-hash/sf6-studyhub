# Luke — LEARN

> 目标：第一次学 Luke 时，不把 Perfect Flash Knuckle 当入门门槛。先让稳定确认 → L Flash +36 → 下一轮完整跑起来，再决定哪些机会值得提高执行成本。

## 1｜认识角色

### 一句话打法

**Luke 的重点不是“连段更难”，而是决定这次机会值不值得增加执行投资：稳定 +36 已经很强，Perfect 只在它买到更好的伤害、位置或 setplay 时才值得。**

### 深度角色模型

Luke 的第一层非常实用：Sand Blast 控中距离，2MP 被防 +1，2MK 可以取消绿冲；命中后用 L Flash Knuckle、Rising Uppercut 或 DDT 把这轮结算成一个明确的下一轮。当前资料的训练顺序本身就把 L Flash +36、2MK DRC、punish、角落 Rising Uppercut 与 DDT 放在 Perfect Flash Knuckle 之前。

所以不要把 Luke 学成“先练 Perfect 的操作题”。真正成熟以后，Perfect timing 才承担第二层：同一个 opening，如果高执行路线确实买到了更好的 damage、carry 或 setplay，就值得提高执行；如果稳定路线已经够好，就不需要为了“理论最优”增加失误率。

### S0｜最小可玩

先只跑通：

1. Sand Blast 控中距离；发波后继续看跳。
2. 典型跳跃用 Rising Uppercut。
3. 两条基础确认：
   - `2MP > 2LP > L Flash Knuckle`
   - `2LK > 2LP > L Flash Knuckle`
4. L Flash Knuckle 常见 +36：立即 Parry Drive Rush，先固定一个 2MP strike。
5. 一条稳定 jump-in：`j.HK > 5LP > 5MP > 5HP > H Flash Knuckle`。

目标是：**不靠 Perfect，也能在真人里打出完整 Luke。**

### S1｜基本功成型

加入：

- 2MP block +1 的 strike / throw / shimmy；
- OD Flash Knuckle > DDT 的 +12 hard knockdown；
- 5HP PC 的稳定 punish；
- 角落 L Rising Uppercut 的 +28…31 family；
- corner forward throw +19 loop。

这一层结束时，你应该已经能靠稳定路线赢很多回合，而不是“会 Perfect 但基础掉”。

### S2｜实战结构化 · 冲 Master

现在加入 `2MK DRC`。

重点不是路线变长，而是 end-state 开始分流：

- L Flash +36；
- DDT +12；
- No Chaser whiff point-blank +7；
- corner L Rising Uppercut +28…31；
- 不同位置下的 punish / wall / carry。

你要能解释：**为什么这次要 +7，而不是继续用 +36。**

### S3｜选择成熟 · 1500 MR稳定

现在才把 Perfect timing 当主训练项：

- Year4 角落 fully charged L Flash 连接；
- 选 1–2 条 Perfect 路线，分别承担真正不同的 damage / carry / setplay；
- +64 family 只有在执行稳定、后续价值明确时使用；
- 掉 combo 率升高就主动退回 L Flash / DDT。

高执行不是身份认证，它只是可选投资。

### S4｜高分上探

最后才加入：

- +64 → No Chaser +15；
- three dash +7；
- corner safe jump；
- active-frame meaty；
- SA / 6 Drive lethal。

任何复杂路线都要回答一个问题：

**它比稳定答案多买到了什么？**

回答不出来，就不用学。

## 2｜工具地图

| 工具 | 第一用途 | 决策含义 |
|---|---|---|
| **2MP** | 近身正帧 / 确认 | 6F / Block +1，S0核心。 |
| **2MK** | 低段 DRC入口 | Block -6；S2才进入主线。 |
| **Sand Blast** | 中距离飞道 | 控节奏，不因为Luke近身强就忽略Neutral。 |
| **L Flash Knuckle** | 稳定 ender | +36 是第一套Oki标尺。 |
| **OD Flash > DDT** | 资源换简单hard KD | +12，throw / shimmy简单明确。 |
| **Rising Uppercut** | 对空 / 角落ender | L版角落 +28…31，受hit height影响。 |
| **Perfect Flash Knuckle** | 高执行优化 | 只有买到独立价值时才提高优先级。 |

## 3｜Core Loop

先只记：

**Sand Blast / 地面接触 → 2MP 或 light确认 → L Flash +36 → PDR → 2MP固定打击 → 对手脱出后回中距离。**

然后只加一个资源分支：

**light → OD Flash > DDT +12 → throw / shimmy。**

等这两套稳定，再学 DRC 与 Perfect。
