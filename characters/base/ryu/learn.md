# 隆 Ryu — LEARN

> 目标：第一次学隆时，不是按章节把所有知识读完，而是先形成一条**能在实战完整跑起来的最小套路**；哪里卡住就只拆哪里练，稳定后再给同一个节点增加一个新分支。详细帧数和完整路线放在 `reference.md`；Hit / Block / Whiff 的细分跳转由 `play.yaml` 管。

## 1｜认识角色

### 一句话打法

**用 236P 和中距离拳脚逼对手更冒险地接近，跳就 623P；一旦用 5MP / 轻攻击取得确认，就先稳定收尾到 623HP，再用一套固定起攻接回下一轮。先把最小 Loop 跑起来，再经历“基本功成型 → 实战结构化 → 选择成熟 → 高分优化”，而不是一开始横向背完所有路线。**

### 深度角色模型

隆不是“发波角色”或“升龙角色”这么简单。他的强点是：**每一层都有一个够可靠的答案，而且这些答案能互相逼出下一层机会。**

- **赢法**：236P 和 5MK 让对手不能只往前走；2MK 抓走路、5HP 抓大动作；对手开始跳以后，用 623P 把跳跃收益压下去。对手被迫更多留在地面后，隆的中距离接触才真正变强。
- **输法**：最常见不是“招式不够强”，而是自己破坏结构——固定节奏发波被跳、2MK 每次都机械交 3 格、5HP/5HK 乱挥、被防后继续提交危险必杀、击倒后为了追人把 Drive 全烧光。
- **舒服距离**：远距离以 236P 和观察为主；中距离是 5MK / 2MK / 5HP 的工作区；近距离才轮到 5MP / 2MP / 轻攻击和打投。
- **伤害与运版**：同一次接触往往能在“省资源稳定”“花 Drive 推版”“继续 Oki”“直接伤害/斩杀”之间选；真正的进阶是逐渐知道**什么时候选哪一个**，不是单纯多背几条连段。
- **起攻（Oki）**：623HP、214LK、214MK、OD 236K 空中龙卷尾段会给出不同的起攻距离和时序。**先把一种击倒后的固定下一步练成自动动作，再扩展选择树。**
- **资源**：Drive 最值钱的用途之一是把 2MK 等接触转成确认时间或把中拳确认转成运版/Oki；Denjin 是把下一次 236P / 214P 威胁抬高的角色资源。资源低时隆完全可以回到波动 + 对空 + 走位，不必强行维持回合。
- **防守**：4F 轻拳是基础打断；普通 623P 是主要对空；OD 623P 是有成本的全无敌反击。防守成功后同样要回到 Neutral / 位置优势，而不是“防住了就乱按”。

### 真正的学习方式｜同一套 Loop 逐层长分支

学习顺序按 **Whole → Part → Whole**：先打一条完整最小 Loop；某一环不稳定，就只练那一环；练稳以后立即回整局。阶段不是五套打法，而是**同一套隆从固定答案，逐渐长成选择树**。

#### S0｜最小可玩

先只让一整轮能打出来：

1. 地面：236P / 5MK 控地面，发波后继续看跳。
2. 对空：对手正常跳就优先 623P；来不及时用 2HP / 空对空兜底。
3. 两条基础确认：`5MP > 2MP xx 623HP`；`2LK > 5LP > 5LP xx 623HP`。
4. 击倒后先固定一套：`623HP > 66 > 6HP meaty`。

这一阶段的目标不是“懂完隆”，而是**真人里反复出现完整循环**：控地面 → 接触 → 623HP → 固定起攻 → 对手脱出后回中距离。

#### S1｜基本功成型

先把高频的免费价值补齐，减少“明明知道但比赛一直漏”：

- 跳入只先保留一条稳定收尾，不按深度背整本连段库。
- 挡住大无敌技 / 明显大破绽会走够得到的稳定确反。
- DI、墙撞与角落先认真实状态，再拿稳定结果。
- 5MP / 轻攻击被防时默认允许停手，不播放命中路线。
- `623HP > 66 > 6HP` 稳定以后，才加入已经验证 spacing / timing 的基础投 / shimmy。

这一层结束时，主要损失不应该再来自**漏对空、漏确认、漏大确反、DI 不处理、固定 Oki 做不出来**。

#### S2｜实战结构化 · 冲 Master

这一级是“基本功”到“会跟对手打”的桥梁。开始给常见结果建立结构：

- `2MK xx DRC > 5HP > 4HP xx 623HP` 接回原来的 623HP → Oki Loop。
- 2MK 的 Hit / Block / Whiff 正确分流，不看到接触就自动花 3 格。
- 5MP 被防继续保留“停手”这个默认答案；214LP 最速 / 延迟和 DRC 只在有读法或资源理由时加入。
- 对手 mash / tech / jump / reversal 时不再用同一个 Oki 答案。
- 位置和 Drive 开始真正改变“继续 / 停 / 运版 / 回 Neutral”的选择。

真正的进步是：**你开始根据正在发生的比赛选下一步，而不是只运行自己的脚本。**

#### S3｜选择成熟 · 1500 MR 稳定

到这里，同一个机会不再只有一个正确答案：

- 命中以后会按位置、Drive、血量与对手选择稳定 / 运版 / Oki / 伤害 / 斩杀。
- Denjin / Hashogeki 进入已有 Loop，但没有安全窗口就不强蓄、不为了角色机制放弃 Neutral。
- 角落维持、投拆、shimmy、防凹和资源压力形成真正的选择树。
- 复盘开始问“**为什么这次选它**”，而不是只问“这条连招怎么打”。

**1500 MR 是持续的 Reality evidence，不是能力定义。** 单次到达、初始落点或短期掉分都不能单独证明或否定这一阶段。

#### S4｜高分上探

最后才把窄条件和高价值优化接进已经成熟的选择树：

- +42 safe jump、OD 236K 运版、PC 高收益、SA / 斩杀与角落高价值分支。
- spacing / active-frame / 空中高度等 conditioned 路线按真实条件区分，不背成通用口诀。
- Burnout / Drive、角色专属 punish / 脱出 / setplay 按真实高频 Matchup 加入。
- 回放里的主要问题从“我漏了基础答案”变成“**同一个已经赢到的机会，有没有更优兑现；旧节奏是否已被对手适应**”。

具体高分 MR 不在这里硬编码；等有明确目标，再把持续表现作为 Reality evidence。

### 暂时后置原则

任何阶段都不因为 Reference 里“有这条路线”就自动加入当前训练。最大伤害多次 DRC、Denjin 浮空优化、极限安全跳、角色专属冷门 punish、精确高度路线等，只在当前阶段或真实对局反复需要时进入前台。

## 3｜Neutral Map

### `N01｜远距离：让对手先表态`

**目标不是靠波直接打死，而是逼对手选择：走、防/Parry、跳、自己发波、DR 接近。**

- 主工具：L/M/H 236P、走位、少量 5MK。
- 发波以后第一件事：重新看跳跃轨道。
- 对手开始跳 → `D01｜对空决策`。
- 对手稳定走/Parry靠近 → 让距离进入 `N02`，不要继续原地固定节奏发波。
- 对手也发波 → `C07｜对手用飞道控场`。

### `N02｜中距离：隆最重要的决策区`

这里同时存在三类威胁：

- **5MK**：低成本挡前走。
- **2MK**：抓走路；**S2 以后**才稳定接 DRC 主分支。
- **5HP**：预判大动作、打挥空、抓拆投后高回报。

规则很简单：**不知道对手要做什么时，先选低承诺；看见他开始走或按，再增加 2MK / 5HP 权重。**

- 2MK碰到 → `T03`。
- 5HP/5HK 抓到明显空档 → `T04`。
- 对手不断前走并进入近身 → `N03`。
- 对手不断后退 → `C05`。
- 对手跳 → `D01`。
- 对手爱 DI → `C04`。

### `N03｜近距离：确认优先于花哨`

主轴只有：

- 轻攻击：最快接触 → `T01`
- 5MP / 2MP：确认枢纽 → `T02`
- 对手只防：投 / 6HP / 走位制造下一次接触 → `C06`

近身不是“轮到隆就必须一直按”。5MP被防 -1、轻拳被防 -1，读不到对手就允许结束回合。

### `N04｜角落：不要自己把人放出去`

对手背墙后，隆的价值来自：

- DI 墙撞 → `T10`
- 前投循环 → `O06`
- Shimmy 抓拆 → `T04`
- 继续对空，避免为了投而让对手免费跳出。

## 4｜Core Loop

### 当前最小 Loop｜先只跑这一条

**236P/5MK控地面 → 跳就623P → 走到5MP/轻攻击距离取得接触 → 命中走稳定确认 → 623HP收尾 → 66→6HP meaty → 对手脱出就回 N02。**

这一层故意不要求你同时掌握所有打投分支。

- 5MP确认：`5MP > 2MP xx 623HP`。
- 轻确认：`2LK > 5LP > 5LP xx 623HP`。
- 基础起攻：`623HP > 66 > 6HP meaty`。
- 2MK DRC、投/shimmy、Denjin、运版、+42、SA 都是**后续给这个 Loop 加枝条**。

### 什么时候展开下一条分支？

只在当前 Loop 已经能跑，或者真实实战暴露出明确瓶颈时展开：

- `623HP` 后老是压不到起身 → 只练 Oki，不去学 Denjin。
- 5MP/轻确认稳定，但中距离 2MK 命中没收益 → 到 S2 加 2MK DRC。
- 对手开始大量拆投 → 加 shimmy。
- 对手开始大量无敌反击 → 加停手防凹与大确反。
- 基础路线稳定、资源经常富余 → 才加运版 / Denjin / SA。

这就是隆的学习闭环：**整轮实战 → 找第一个真实断点 → 最小训练 → 回整轮 → 再决定下一条分支。**

## 5｜对策入口

这里不做 31×31 Matchup 百科，只先处理会直接改变隆打法的行为：

- **爱跳** → `C01`：降低发波和大按钮频率，切 `D01`。
- **爱按** → `C02`：在真正正帧/起攻节点用打击抓抢，不要靠假压力硬续。
- **爱拆投** → `C03`：先进入 `T14` 观察；确认拆投挥空后才 `T04` PC兑现。
- **爱DI** → `C04`：中距离减少不可取消大承诺，优先能反DI的节奏。
- **爱后退** → `C05`：2MK和前走接管空间。
- **一直龟** → `C06`：投、6HP、蓄电/资源优势，不靠更长打击串解决。
- **飞道控场** → `C07`：走/Parry/自己的波动节奏，先争位置再谈接触。
