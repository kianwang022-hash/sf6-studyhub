# E. Honda — LEARN

> 目标：第一次学 Honda，不是“蓄力好就Headbutt”，也不是“击倒就Oicho”。先学 charge + stable knockdown + strike；对手开始尊重以后，command grab 才真正进入角色循环。

## 1｜角色本质

### 一句话

**Charge帮你保留Headbutt / Smash威胁；真正的Honda是先用strike/meaty让对手站着防，再用6F Oicho把这份respect变成高收益。**

### S0｜最小可玩：先strike，不抓

先学：

1. 普通防守 / normal 里存 back / down charge。
2. 2LP > 2LP > L Hundred Hand Slap。
3. 5MP > Sumo Dash > Teppo Triple Slap。
4. H Sumo Smash grounded hit -> +23。
5. +23 -> forward dash -> +4。
6. dash后只先用 2LP / 5MP。

S0不要求Oicho。

你先让真人对手学会：

**“Honda击倒我以后，我得先防。”**

### S1｜Respect -> Oicho

现在才加入：

- Sumo Smash +23 -> dash +4 -> Oicho；
- Sumo Smash -> 2LP whiff -> +7 -> 5HK / walk-back；
- 6HK PC -> M Headbutt -> dash +4；
- 大确反。

真正的循环：

**strike强 -> 对手站防 -> Oicho强 -> 对手跳/后退 -> strike/shimmy又变强。**

如果对手根本不防，你不需要command grab。

### S2｜Taiho / +42

加入：

- 5MP CDR -> Taiho Cannon Lift；
- Taiho -> Sumo Smash；
- Teppo first hit +42 -> immediate forward jump safe jump；
- DI routes；
- DR 5MK block +4。

这时同一个opening才开始比较：

**+23 command-grab loop / +42 safe jump / +64 launcher state。**

### S3｜Sumo Spirit / OD pressure

加入：

- Sumo Spirit；
- Spirit L Hands block 0；
- Spirit OD Hands block +1；
- OD Teppo first hit block +3 point-blank；
- selected +40 / +41 corner setplay。

所有plus都必须带state。

### S4｜Super / high resource

最后加入：

- cr.HP -> SA1 / SA2 / SA3；
- Spirit high-resource route；
- high-resource corner / DI；
- matchup-specific Headbutt / Smash / Oicho frequency。

## 2｜Core Loop

S0：

**charge -> contact -> Smash/Teppo knockdown -> strike -> opponent learns to block。**

S1：

**respect established -> Oicho -> opponent escapes command grab -> strike/shimmy gets stronger。**

把这个因果跑起来，Honda才真正成立。
