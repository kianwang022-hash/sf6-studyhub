# Blanka — LEARN

> 目标：第一次学 Blanka，不是先背 Bomb，也不是把 Rolling 当成 neutral 自动突进。先把 Electric Thunder +39 和 charge 基础跑成完整回合，再用角落 Bomb 把防守变成“本体 + 延迟对象”两条时间线。

## 1｜角色本质

### 一句话

**先用普通地面和 Electric Thunder / Rolling 拿击倒；赢到角落以后，再用 Blanka-chan Bomb 把下一轮变成 delayed object + high/low/throw。**

### S0｜最小可玩

先只学：

1. 保存 back / down-back charge，但不因为 charge 停止正常地面。
2. 5LK > 2LP > Electric Thunder。
3. 2LK > 2LP > Electric Thunder。
4. 4MK block +2；命中接 5MK > Electric Thunder。
5. 2MP > Electric Thunder。
6. 有 back charge 时，2MP > M Rolling Attack 作为 damage/travel 替代。
7. Vertical Rolling 负责 charge anti-air / ender。

第一阶段只要会：

**ground contact -> Electric Thunder +39 -> simple Oki -> reset。**

Bomb 完全不用管。

### S1｜+42 与普通 Oki

加入：

- Electric Thunder +39 的 dash / two-dash / Hop Oki；
- M Vertical Rolling exact hit -> +42 -> forward jump HK；
- forward throw +30 -> Surprise Forward Hop -> +3；
- Amazon River Run grounded / airborne 的基础差异；
- stable punish。

最重要：

**不是所有 Vertical Rolling 都自动 +42。**

### S2｜Bomb 第一次进入

现在才加入：

- 2MP CDR；
- corner Wild Lift -> Blanka-chan Bomb；
- Bomb setup -> OD Electric Thunder block +4；
- OD Thunder 后 overhead / low / throw；
- DI / corner routes。

学习逻辑：

**先赢 corner，再放 Bomb。**

Bomb 不负责帮你拿到角落，它负责把已经赢到的角落放大。

### S3｜更深对象与移动

加入：

- OD Wild Hunt +64；
- selected Backstep Rolling；
- Bomb activation timing / Perfect Parry read；
- Amazon grounded vs airborne Oki；
- deeper Bomb branches；
- selected SA3 +50 Oki。

复杂 movement 只有在它真正改变对手防守时才保留。

### S4｜Lightning Beast

最后才加入：

- SA2 Lightning Beast；
- Rolling Cannon follow-up；
- SA2 corner Bomb routes；
- high-resource SA1 / SA3；
- matchup-specific Hop / Roll / Bomb timing。

Lightning Beast 是一段新的 Rolling system，不是 S0 角色身份。

## 2｜工具地图

| 工具 | 第一用途 | 要记住什么 |
|---|---|---|
| Electric Thunder | S0 默认 ender | 当前 +39，是基础 Oki 发动机。 |
| 4MK Wild Edge | 地面 respect | 9F / block +2；Year 4 whiff recovery 更大。 |
| Rolling Attack | charge travel / damage | 被防很危险，主要从 confirm / read 使用。 |
| Vertical Rolling | anti-air / ender | M/H 可进入 +42 family，但要看 exact state。 |
| Blanka-chan Bomb | corner object setplay | S2 才进主线，需要 placement + activation。 |
| OD Electric Thunder | object mix 放大 | block +4，围绕 Bomb 做 high/low/throw。 |
| SA2 Lightning Beast | late install | S4。 |

## 3｜Core Loop

S0：

**ground contact -> Electric Thunder +39 -> dash/Hop pressure -> reset。**

S2 以后：

**corner won -> Bomb placed -> Bomb activated -> body high/low/throw -> back to Thunder / corner Oki。**

先把第一条打稳，第二条才有意义。
