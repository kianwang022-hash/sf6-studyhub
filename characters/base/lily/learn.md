# Lily — LEARN

> 目标：第一次学 Lily，不是先学 command grab，也不是把 Windclad 攒满。先学“用一个安全窗口拿 1 层资源”，再看懂 Windclad 如何把 Condor Spire 从危险进场变成正帧进场。

## 1｜角色本质

### 一句话

**先投资 Windclad，把 Condor Spire 变成正帧进场；对手开始尊重这次 plus entry 后，Mexican Typhoon 才真正值钱。**

### S0｜最小可玩：只学 1 层 Wind

先学：

1. 普通 light：
   - 2LK > 2LP > M Tomahawk Buster

2. 找一个真实安全窗口：
   - hold Condor Wind
   - 只拿 1 层 Windclad

3. 有 Windclad 后：
   - 2LK > 2LP > 2LP > Windclad M Condor Spire

4. 记住最重要的对比：
   - normal Condor Spire 被防：-8
   - Windclad L/M/H Spire 被防：+1
   - Windclad OD：+2

S0 不要求 Mexican Typhoon。

你只需要真正理解：

**Windclad 买到的不是“多一点伤害”，而是让进场风险改变。**

### S1｜Respect → Mexican Typhoon

现在才加 command grab。

Windclad H Spire 进场以后，先做：

- 2HP / strike；
- throw；
- block / read。

等对手真的愿意站着防，再加：

- Mexican Typhoon。

反馈循环：

**plus strike -> 对手 respect -> Mexican Typhoon -> 对手 jump/backwalk -> strike / anti-air 变强。**

如果对手一直抢，你继续 strike，不需要抓。

### S2｜+52 与 Hold vs Spend

加入：

- heavy starter CDR -> Windclad H Spire；
- H Windclad Spire -> +52；
- two forward dashes -> +10；
- delayed forward jump safe jump；
- 正式学习：
  - 现在花 stock；
  - 还是保留 stock 给下一次 plus entry。

关键问题：

**这层 Windclad 现在花，买到了什么？**

### S3｜Multi-stock / Corner

现在才加入：

- 2-stock Condor Wind；
- 3-stock Condor Wind；
- spacing OD Condor Spire；
- Condor Dive；
- corner Mexican Typhoon -> Windclad OD Spire；
- deeper Windclad Tomahawk routes。

多 stock 只在真正长安全窗口里做。

### S4｜SA / High Resource

最后加入：

- SA1 / SA2 / SA3；
- high-resource Windclad routes；
- multi-stock lethal / corner；
- matchup-specific resource frequency。

## 2｜工具地图

| 工具 | 第一用途 | 你要记住什么 |
|---|---|---|
| Condor Wind | 建 Windclad | 有真实时间成本。 |
| normal Spire | 普通进场/route | block -8，不安全。 |
| Windclad Spire | 资源进场 | block +1，OD +2。 |
| Tomahawk Buster | anti-air / route | Windclad版本更快。 |
| Mexican Typhoon | command grab | S1以后，建立在respect上。 |
| H Windclad Spire | 大Oki | +52 exact-state。 |

## 3｜Core Loop

S0：

**safe Wind window -> gain 1 stock -> Windclad Spire -> plus entry -> strike -> reset。**

S1：

**plus entry -> strike creates respect -> Mexican Typhoon -> opponent escapes grab -> strike/anti-air gets stronger。**

S2：

**Windclad active -> hold stock or spend now -> choose by current value。**
