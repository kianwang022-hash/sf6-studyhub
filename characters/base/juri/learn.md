# Juri — LEARN

> 目标：第一次学 Juri，不是先攒满 stock，也不是先学 Feng Shui Engine。先让一条正常地面回合自己生出 stock，再学什么时候值得把它花掉。

## 1｜认识角色

### 一句话打法

**先用 5MP / 2MP / light 拿接触，M Fuhajin 收尾同时 stock +1 并继续下一轮；真正的角色判断是下一次 opening 这颗 stock 现在花不花。**

### 深度角色模型

Juri 不是“先攒资源才开始玩”的角色。当前训练顺序最先要求的是 5MP > 2MP > M Fuhajin、低段 light > M Fuhajin，以及 Fuhajin 后 forward dash 的打 / 投 / shimmy。这意味着她最基础的正常回合，本来就会一边生成 stock，一边保留下一轮。

所以 Juri 和 Jamie 的资源逻辑不一样。Jamie 经常要在当前压力和喝酒投资未来之间做交换；Juri 更常见的是：**当前回合已经成立，同时 stock 也自然长出来了。** 真正的问题出现在下一次 opening：现在把 stock 换成 Boosted Saihasho / Ankensatsu / Go Ohsatsu 的伤害、carry 或更复杂后续，还是把 stock 留着，让未来的 option space 更大。

S0 完全不要求花 stock。先证明没有 Boosted special 你也能正常打完整一局。

### S0｜最小可玩

只做：

1. 5MP / 2MP / light 拿 grounded contact。
2. 跳跃用 Tensenrin。
3. 两条基础确认：
   - 5MP > 2MP > M Fuhajin
   - 2LK > 2LP > 2LP > M Fuhajin
4. M Fuhajin 后 forward dash，先固定一个 5MP strike。
5. 5MP 被防 +2，只先练 strike / throw。

你要看到的是：

**打中 → M Fuhajin → stock +1 → dash → 下一 Turn。**

而不是：

**我有 stock 了，赶紧想办法花。**

### S1｜基本功成型

加入：

- 5MP +2 后的 shimmy / block；
- 挡无敌技后的稳定 punish；
- Drive Reversal punish；
- 角落 H Tensenrin → 5MP 的 current +5 family；
- corner forward throw。

到这里仍然把“保留 stock”当默认。

### S2｜实战结构化 · 冲 Master

现在第一次真正学习 stock spending：

- 2MK DRC 加入原 Loop；
- Hit 默认仍可以回 M Fuhajin；
- 有 stock 时，5MP > 2MP > Go Ohsatsu 作为第一条 spend route；
- 只有这次 opening 的 damage / carry 值得，才花；
- 某些路线花完以后可以接 L Fuhajin，把 stock 再生回来。

这一层最重要的问题只有一句：

**“我为什么这次要花？”**

如果答不出来，就先保留。

### S3｜选择成熟 · 1500 MR稳定

现在加入：

- OD Fuhajin；
- selected 3-stock routes；
- Boosted Saihasho / Ankensatsu / Go Ohsatsu；
- midscreen / corner H Tensenrin 的 spacing / hit-height 条件。

重点不是把三颗 stock 全串成最长 Combo，而是把路线按结果压缩成少数几类：

- 当前 damage；
- carry / corner；
- 回 M Fuhajin 再生 stock；
- 保留 stock 给下一轮。

### S4｜高分上探

最后才加入：

- SA3 cashout；
- SA1 exact route 闭合后再进；
- SA2 Feng Shui Engine；
- FSE 专属 cancel / pressure tree；
- 高资源 OD + stock + SA 优化。

Feng Shui Engine 是一套新的系统，不是“Juri 第一课”。

## 2｜工具地图

| 工具 | 第一用途 | 决策含义 |
|---|---|---|
| 5MP | 近身 respect / confirm | 6F / Block +2，普通地面本来就很强。 |
| 2MP | 稳定连接 | 6F / C，基础确认核心。 |
| 2MK | 低段 DRC | S2 才进入主线。 |
| M Fuhajin | stock +1 / 基础 ender | 当前回合与未来资源同时做大。 |
| Tensenrin | 反空 / ender | 角落 current Oki 很值钱。 |
| Go Ohsatsu | 第一条 stock spend | 有 stock 不等于必须用。 |
| Saihasho / Ankensatsu | Boosted route family | 必须和 stock 状态一起学。 |
| Feng Shui Engine | SA2 系统层 | S4 单独学习 cancel / pressure。 |

## 3｜Core Loop

先只记：

**ground contact → M Fuhajin → stock +1 → forward dash → 5MP / throw → 对手脱出后回 grounded contact。**

等这条在真人里稳定，再加：

**下一次 opening → 判断保留 stock 还是花 1 stock。**

不要反过来。
