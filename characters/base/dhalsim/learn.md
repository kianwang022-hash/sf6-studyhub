# Dhalsim — LEARN

> 目标：第一次学 Dhalsim，不是学“永远站远处按长手”，也不是先学 Teleport / Float 花活。先学会 **塑造接近路线 → 处理接近 → 拿到击倒 → 决定要不要进场现金化**。

## 1｜角色本质

### 一句话

**先用长肢与火球几何逼对手从可预测路线接近；拿到击倒以后，再用覆盖住的 Teleport / Float 把远距离优势换成近身回合。**

Current Year4 的实战指南有一个很关键的提醒：

只靠一直把对手赶回去很难赢。

你反空 100 次，对手可能还会跳第 101 次；
你返 DI 100 次，对手可能还会继续 DI。

所以 Dhalsim 不是：

**离得越远越好。**

而是：

**先让对手的接近方式可预测，再把一次成功防守/控制变成进攻。**

## S0｜最小可玩：先学“远 → 近”的一次转换

### 1. Ground geometry

先认两个远距离工具：

- 5MP：长距离 mid probe
- 2MK：长 active 的低位slide

这里有一个非常重要的反直觉：

**Dhalsim 的长肢实际 frame 会受接触时机影响。**

2MK baseline 被防是负的，
但如果很远、很晚的 active frame 才碰到对手，
实战优势会明显改善。

所以不要死背：

“2MK = 永远 -10”。

也不要反过来以为：

“很远 = 一定安全”。

### 2. Yoga Fire

Yoga Fire 的任务不是：

原地无限发波。

它要问对手：

- 你跳吗？
- 你往前走吗？
- 你等吗？
- 你 DI 吗？

接着你用另一条 lane 回答。

### 3. Anti-air 有两条 lane

近、比较陡的 jump：
- 4MP Yoga Uppercut

更远的 jump：
- 5HK

不要强迫自己用一个万能反空键解决所有角度。

### 4. Close confirm

4MK Divine Kick > M Yoga Flame

M Yoga Flame：
- knockdown +33

这是一条很普通、很稳定的 close route。

它证明 Dhalsim 不是离近了就“没招”。

### 5. 只学一次 earned Teleport

这一条是 S0 的角色身份：

2LP  
-> CDR  
-> 5LP  
-> 4MP  
-> M Yoga Blast  
-> immediate P Yoga Teleport (Forward)

M Yoga Blast：
- +42

紧接 forward P Teleport：
- point-blank 大约 +3

注意：

**+3 不是 Teleport 本体的 frame。**

它属于：

**M Blast +42 覆盖住 Teleport recovery 的这个 exact route。**

raw Teleport 不拥有这个 +3。

现在你第一次真正理解 Dhalsim：

**远距离/中距离拿到的结果，可以直接转换成贴身 turn。**

## S1｜加入第二个几何维度

### Yoga Arch

Yoga Arch raw frame 看起来并不夸张。

但在非 point-blank 距离：

Dhalsim 已经恢复，
projectile 还在空中继续走。

所以当它后来碰到对手时，
你可能已经提前行动很久。

Current data 的典型有效预算大约：

- Hit +29
- Block +27

这不是 move 本体突然 +27。

而是：

**projectile 晚到。**

### Forward throw

forward throw：
- +31

可以：
- Drive Rush > 2MK
- 继续 close strike / throw

这让你知道：

近身赢到 turn 后，
不需要每次都靠 Teleport 才能继续。

### 第一条 Yoga Float

Aerial Yoga Float  
-> j.HP  
-> 1HP Nirvana Punch  
-> M Yoga Flame

只学这一条。

S1 不学完整 Float cross-up tree。

### H Yoga Flame

2MP  
-> CDR  
-> 4MK  
-> H Yoga Flame

H Flame：
- +45

这是用 Drive 换更大的 Oki budget。

## S2｜把 geometry + position + resource 合起来

现在才加入 Year4 projectile chain：

- OD Yoga Fire -> Yoga Arch -> Yoga Comet
- OD Yoga Arch -> Yoga Fire -> Yoga Comet

这时你不是“多学两个连段”。

你是在让：

- 直线 projectile
- 弧线 projectile
- 空中 projectile

同时控制不同空间。

### Corner +37

corner：

4MK  
-> H Yoga Blast  
-> L Yoga Blast

结束：
- +37

到这里才正式打开 corner setplay。

### OD Yoga Flame

OD Yoga Flame：
- +51

它和 H Flame +45 是两个独立 state。

不要写成：

“反正都差不多 +50”。

## S3｜正式优化 spacing / active frame

现在才把 Dhalsim 最反直觉的一层当学习目标：

### late contact

2MK / 2HK 很长，
active frames 也很长。

如果晚 active 才碰到对手，
实战 frame 会改变。

这时才正式训练：

- early contact
- late contact
- spacing
- whiff risk

### Corner +37 setplay

+37 后可以分成：

- point-blank close action
- 2MK whiff timing -> shimmy
- 5LP whiff -> L Yoga Fire cover

### Active H Yoga Flame

某些 corner setup 中，
H Yoga Flame 可以通过 active meaty 变成很大的 plus。

但 raw H Yoga Flame 本身：
- Block -4

所以：

**plus 来自 setup timing，不是招式标签。**

## S4｜Matchup geometry

最后才系统加入：

- SA
- advanced Float / Drill / Comet heights
- Teleport cross-up / side switch
- Burnout corner sequences
- matchup-specific Yoga Fire / Arch cadence
- character-specific hurtbox / DI lab

## 2｜工具地图

| 工具 | 第一用途 | 你要记住什么 |
|---|---|---|
| 5MP / 2MK | long-range geometry | reach 不等于 safety；late contact 会改实际 frame。 |
| Yoga Fire | 逼接近选择 | 看 jump / walk / wait / DI。 |
| 4MP / 5HK | anti-air lanes | 近角度和远角度分工。 |
| 4MK > M Flame | close confirm | +33，最简单的近身结果。 |
| M Yoga Blast | knockdown / anti-air route | +42，能覆盖 forward Teleport。 |
| Forward Teleport | state conversion | raw 不自带 +3；earned route才有。 |
| Yoga Arch | delayed geometry | plus 来自 projectile 晚到。 |
| Yoga Float | aerial geometry | S1以后再展开。 |

## 3｜Core Loop

S0：

**long limb / Fire -> force predictable approach -> lane anti-air or close hit -> knockdown -> decide stay far or cash out。**

Character-specific S0：

**M Yoga Blast +42 -> immediate forward P Teleport -> point-blank +3 -> strike / throw -> opponent escapes -> rebuild range。**

S2+：

**range geometry -> knockdown -> Teleport/Float/corner setplay -> close turn -> opponent escapes -> rebuild geometry。**
