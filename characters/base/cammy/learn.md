# 嘉米 Cammy — LEARN

> 目标：第一次学嘉米时，不是把 Cannon Strike、Hooligan、角落与资源路线一起背完，而是先形成一条**能在实战完整跑起来的地面接触→Spiral Arrow→下一 Turn**。哪里卡住就只拆哪里练，稳定后再给同一个节点增加一个新分支。详细帧数和完整路线见 `reference.md`；Hit / Block / Whiff 与状态跳转由 `play.yaml` 管。

## 1｜认识角色

### 一句话打法

**用快速地面接触拿到 Spiral Arrow 击倒，前冲后把打 / 投 / 骗拆逐层加进同一个 Loop；Cannon Strike 与 Hooligan 只在基础循环稳定后作为条件化扩展。**

### 深度角色模型

- **赢法**：靠 2MK、5HP、轻攻击和步行把对手固定在中近距离；一旦命中就用 Spiral Arrow 运角，随后继续组织打投。
- **最常见的输法**：把 Cannon Strike 当无条件正帧、Spiral Arrow 被防还继续、Hooligan 乱飞，都会把原本稳定的速度优势变成高风险。
- **舒服距离**：远距离先走位和观察；中距离是 2MK / 5HP / 5MK 的工作区；近距离才轮到轻攻击 / 5MP / 投。
- **伤害与运版**：同一次接触可以在省资源稳定、运版、Oki、伤害、斩杀之间选；进阶不是多背，而是知道什么时候选哪一个。
- **起攻**：M Spiral Arrow 是第一套核心击倒；先把“Arrow→前冲→一个固定打击”练成自动动作，再加入投、shimmy、防凹。
- **资源**：Drive / SA 用来放大已经成立的接触，不为了“把系统玩出来”牺牲稳定击倒和位置。
- **防守**：普通 Cannon Spike / 2HP 负责典型反空；OD Cannon Spike 才承担全无敌地面反击。防守成功后要回 Neutral 或明确 punish。

### 真正的学习方式｜同一套 Loop 逐层长分支

学习顺序按 **Whole → Part → Whole**：先打一条完整最小 Loop；某一环不稳定，只练那一环；练稳以后立即回整局。S0–S4 不是五套嘉米，而是**同一套嘉米从固定答案长成选择树**。

#### S0｜最小可玩

先只让一整轮能打出来：

1. 地面：2MK / 5HP / 轻攻击负责接触，不靠 Hooligan 硬进。
2. 对空：典型跳跃优先 Cannon Spike / 2HP。
3. 两条基础确认：`2LK > 2LP > 5LK > M Spiral Arrow`；`2LP > 2LP > 5LK > M Spiral Arrow`。
4. 击倒后先固定一套：`M Spiral Arrow → forward dash → 一个稳定打击`。

目标不是“懂完嘉米”，而是**真人反复出现完整循环**：地面接触 → M Arrow → 前冲固定打击 → 对手脱出后回中距离。

#### S1｜基本功成型

把高频免费价值补齐：

- M Arrow 前冲固定打击稳定以后，才逐个加入普通投与后走 shimmy。
- 5HP / 轻攻击被防时默认允许停手，不播放命中路线。
- 挡住明显大无敌技 / 大破绽会走够得到的稳定 PC punish。
- DI / 墙撞先认真实状态，再拿稳定结果。
- 对空、确认、Arrow Oki、确反和 DI 先做到比赛里少漏，再增加花式接近。

这一层结束时，主要损失不应该再来自**漏对空、漏确认、漏大确反、DI 不处理、基础 Arrow Oki 做不出来**。

#### S2｜实战结构化 · 冲 Master

开始让常见结果有不同答案：

- `2MK xx DRC` 加入原 Loop；Hit / Block / Whiff 正确分流，不看到接触就自动花 3 格。
- Arrow Oki 里对 mash / tech / jump / reversal 分别调整 meaty / throw / shimmy / block。
- H Cannon Spike、角落和资源路线按目的加入，不把高伤路线当默认答案。
- 位置和 Drive 开始改变继续、停手、运版或回 Neutral 的选择。

真正的进步是：**开始根据正在发生的比赛选下一步，而不是只运行自己的脚本。**

#### S3｜选择成熟 · 1500 MR稳定

到这里，Cannon Strike 才真正进入主选择树：

- Cannon Strike 的正负帧必须绑定实际高度 / 距离；高位或坏间距被防时会停。
- 同一次机会按对手、位置、Drive 和血量选择稳定 / 运版 / Oki / 伤害 / 斩杀。
- 角落 strike / throw / shimmy 与防凹形成真正选择树；同一种读法失败会主动降频。
- 复盘开始问“**为什么这次选它**”，而不是只问连段有没有完成。

**1500 MR 是持续 Reality evidence，不是能力定义。** 单次达到、初始落点或短期掉分都不能单独证明或否定这一阶段。

#### S4｜高分上探

最后才加入窄条件与高收益优化：

- Hooligan、角落 Cannon Spike、SA / 高资源路线与角色特定 setplay。
- Cannon Strike 高度/距离、角落、active-frame 等条件继续显式 conditioned。
- 回放里的主要问题从“我漏了基础答案”变成“同一个已经赢到的机会有没有更优兑现；旧节奏是否已被适应”。

具体高分 MR 不硬编码；等有明确目标，再用持续表现作为 Reality evidence。

### 暂时后置原则

任何阶段都不因为 Reference 里“有这条路线”就自动加入当前训练。低频 Hooligan 花式、极限 spacing、多次 DRC、高资源最大伤害、角色专属窄 setplay，只在当前阶段或真实对局反复需要时进入前台。

## 2｜工具地图

| 工具 | 第一用途 | 决策含义 / 风险 |
|---|---|---|
| **2MK** | 低段抓走路 + DRC入口 | 命中可转 DRC；被防 -5，本体不要自动续必杀。 |
| **5HP** | 中近距离高回报确认 | 8F，可取消；被防 -3，未确认就收手。 |
| **轻攻击链** | 4F LP + 低段起手 | 2LK/2LP→5LK→M Spiral Arrow 是最小可玩确认。 |
| **M Spiral Arrow** | 核心击倒 / 运角 | 基础路线收尾；被防很不安全，只从确认里提交。 |
| **Cannon Spike** | 对空 / 连段收尾 / OD反击 | 普通版优先承担对空；OD版才是全无敌防守工具。 |
| **Cannon Strike** | 条件化空中接触 | 帧差随命中高度/距离变化，只有低位/合适间距才可能正帧。 |

## 3｜Neutral Map

### 远
主要走位/观察，不主动用高风险 Hooligan 代替推进。

### 中
2MK / 5HP / 5MK 控距离；2MK 可取消，5HP 用于高回报确认。

### 近
轻攻击 / 5MP / 投；命中尽快回 M Spiral Arrow 核心击倒。

### 对手跳
→ `D01`。优先稳定反空；成功后明确回 Oki 或 Neutral，不让反空成为死节点。

### 对手一直防
→ `C06` 或 `T02`。先用普通投/正帧接触迫使对手改变，不直接升级高风险 gimmick。

### 对手爱按 / 拆投 / 凹
分别进入 `C01 / C02 / C04`；这些行为改变下一次 Turn，而不是只记“对策招式”。

## 4｜Core Loop

**只先记这一条：**

`N02 → T01 → R01 → E01 → O01 → T02 → N02`

中文展开：

**快速地面接触 → 确认到 M Spiral Arrow → 前冲固定打击 → 再逐步长出打 / 投 / shimmy / block → 对手脱出后回中距离。**

核心 Loop 的约束：
1. Starter 必须先确认 Hit / Block / Whiff。
2. 命中优先选择“稳定”路线；不是默认最大伤害。
3. Ender 必须声明真实 `oki_advantage / reset_read / neutral_reset / kill` 等结果。
4. 对手逃出后回 Neutral；不强行把每一次击倒写成我的回合。

## 5｜Lv0–Lv4 与 S0–S4 的关系

`Lv0–Lv4` 是底层内容解锁语义；`S0–S4` 是 learner-facing 长期学习阶段。Lv3 的招牌机制不会因为“已经存在于资料库”就自动成为当前训练主线。
