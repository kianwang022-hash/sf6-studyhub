Spinning Bird Kick是charge special。

Block：
- L -18
- M -17
- H -18
- OD -12

所以：

**learner route必须保持hit-confirm。**

- +34

- 5MP / throw / shimmy

## 5｜Serenity Stream

Command：
- 214P

Current Year4：
- follow-up window from stance state
- Up exit available
- stance can be used as route / pressure layer

### S0 route

2HP hit > Serenity Stream > Forward Strike > M Spinning Bird Kick  
End state：+34 -> dash +15

Learner truth：

这条route展示的是：

**confirmed normal -> temporary stance -> follow-up -> charge special**

它不等于“所有SBK都不需要charge”。
