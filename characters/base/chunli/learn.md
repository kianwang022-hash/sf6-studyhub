# Chun-Li — LEARN

> 目标：第一次学 Chun-Li，不是先背六种 Serenity Stream follow-up。先把“普通 Chun-Li”玩完整，再只学一条 stance route，亲眼看到她怎样把 charge 管理变成路线选择。

## 1｜角色本质

### 一句话

**先用 5MP +1 与稳定 SBK 拿住回合；接触后用 Serenity Stream 重组 charge 路线，再逐步加入高低与退出。**

Chun-Li 的复杂不在“按钮数量多”。

她真正新增的能力是：

**已经拿到 contact 以后，可以临时进入 Serenity Stream，把这次 contact 重新编译成另一套 route。**

这和 raw 进 stance 等对手不是一回事。

## S0｜最小可玩：一条 stance route 就够

先学：

1. 中拳确认：
   - 5MP > 2MP > M Spinning Bird Kick
   - 结束 +34

2. 低段确认：
   - 2LK > 2LP > L Spinning Bird Kick

3. M SBK 后：
   - +34
   - forward dash -> +15
   - 5MP
   - throw
   - walk-back shimmy

4. 对手跳：
   - H Tensho Kicks

5. 只学一条 Serenity Stream：
   - 2HP hit > Serenity Stream > Forward Strike > M Spinning Bird Kick

6. 进入 stance 后发现不值得继续：
   - Up exit

这里最重要的理解不是“Forward Strike 是低段”。

而是：

**stance 让已经确认的 contact 可以换一条 route；它不是 neutral 常驻模式。**

普通 SBK 依然是 charge special。不要把这条 stance route 错记成“Chun-Li 的 SBK 不需要蓄力”。

## S1｜把地面循环补完整

现在加入：

### 5MP +1

5MP 被防：
- +1
- 先用 5LP frame trap
- 对手开始等以后再 throw / walk-back

### Kikoken

L Kikoken 后不是停下来观察：

- walk forward；
- 5MP；
- throw；
- walk-back 2MP。

### 2MK CDR

加入：

2MK > CDR > 5MP > Hakkei > Serenity Stream > Forward Strike > M Spinning Bird Kick

你已经会 stance route 了，现在只是把它接到通用的低段 Drive opening。

### Grounded H Tensho

H Tensho grounded hit：
- +37
- dash 后 +18
- 或 PDR 继续 pressure

先只学 grounded 版本。

## S2｜现在才打开完整 stance tree

Serenity Stream 进入以后开始问：

### 对手一直蹲防
- Lotus Fist
- current Block +1

注意：

**这是 stance Lotus Fist。**

3HP Water Lotus Fist 仍然 Block -3，不是同一个东西。

### 对手一直站防
- Forward Strike low
- 或其他已验证 low branch

### 对手总是 4F mash
- Hakkei / 2HP -> Serenity Stream -> Orchid Palm
- current guide 是明确 frame-trap family

### 没必要继续
- Up exit

这才是 Chun-Li 的 stance 学习方式：

**先问对手在防什么，再选 continue；没有价值就 exit。**

## S3｜开始管理 exact state

现在再加入：

- OD SBK 后选择 Oki/carry 或 damage；
- corner H Tensho airborne +35 的 high / low / throw；
- exact +46 -> 5F safe jump；
- exact +45 -> 6F safe-jump family。

必须记：

**+45 / +46 是 route state，不是“Chun-Li 的击倒优势”。**

H Tensho grounded +37 和 corner airborne +35 也绝不能混在一起。

## S4｜SA2 Air / High-MR

最后加入：

- SA2 -> forward jump -> j.MP -> Yoso Kick x2 -> Soaring Eagle Punches；
- SA3 / lethal；
- advanced Kikoken + PDR；
- matchup-specific stance feint / exit；
- +45 与 5F reversal 的训练场复核。

## 2｜工具地图

| 工具 | 第一用途 | 你要记住什么 |
|---|---|---|
| 5MP | ordinary contact / pressure | 5F，Block +1。 |
| Kikoken | 控地 / 掩护步行 | 后面接 walk、low、throw，而不是只发波。 |
| M SBK | 稳定 combo ender | +34 -> dash +15；raw block 很危险。 |
| H Tensho | anti-air / Oki owner | grounded +37 与 airborne state 分开。 |
| Serenity Stream | temporary routing layer | S0 只学 route + exit。 |
| stance Forward Strike | route bridge | 把 earned stance contact 接回 M SBK。 |
| stance Lotus Fist | S2 overhead pressure | current Block +1；不是 3HP。 |

## 3｜Core Loop

S0：

**ground contact -> SBK stable knockdown -> dash +15 -> strike / throw / shimmy -> reset。**

Character-specific S0：

**confirmed 2HP -> Serenity Stream -> Forward Strike -> M SBK -> same +15 Oki。**

S2：

**earned stance entry -> read defense -> overhead / low / frame trap / exit -> back to stable knockdown or neutral。**
