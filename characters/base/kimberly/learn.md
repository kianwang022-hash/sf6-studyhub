# Kimberly — LEARN

> 目标：第一次学 Kimberly，不是先背炸弹，也不是一直 Sprint。先把普通 contact 变成角落，再让 Sprint 和 Bomb 一层层放大已经赢到的位置。

## 1｜角色本质

### 一句话

**先用普通confirm把人送进角落；角落基础稳定后，再用Sprint分支和Shuriken Bomb把下一轮变成真正的setplay。**

### S0｜最小可玩

先只学：

1. 2LP x3 > L Vagabond Edge，命中后 +3。
2. 2MP > 5MP > 5HP > Sprint > Shadow Slide，负责corner carry。
3. Shadow Slide后双dash，只保留一个strike和throw。
4. 2MK block +1：只当ground respect，**它不可取消**。
5. 主要反空 / Bushin Senpukyaku职责。

第一阶段目标：

**普通contact → corner carry → simple Oki。**

Bomb完全不用管。

### S1｜第一次打开Sprint mix

加入：

- Sprint > Neck Hunter overhead；
- Sprint > Shadow Slide low；
- Sprint > Emergency Stop -> throw / shimmy；
- H Bushin Senpukyaku +20 Oki；
- 大确反。

这时你仍然不需要Bomb。

### S2｜Bomb第一次进入

加入：

- 5MK Cancel Drive Rush；
- corner DI -> Bomb setplay；
- OD Sprint > Bushin Hojin Kick > L Bomb；
- 库存判断：这次花Bomb值不值。

要记住：

**Bomb负责放大角落，不负责把你送进角落。**

### S3｜+42与多Bomb

加入：

- OD Sprint > Hojin > Hisen -> +42 safe jump；
- selected Arc Step；
- 2-stock / 3-stock Bomb setplay；
- Bomb vs no-Bomb corner Oki。

### S4｜SA3持续buff

最后才加入：

- SA3 111% damage modifier；
- increased walk speed；
- SA1 / SA2；
- 3-Bomb lethal / Burnout。

SA3不是新的Kimberly，而是把你已经会的Kimberly整轮放大。

## 2｜Core Loop

S0：

**ground contact → Shadow Slide carry → corner/simple Oki → strike/throw → reset。**

S2以后：

**corner won → Bomb stock decision → delayed setplay → 回到strike/throw/read。**
