# Guile — LEARN

> 目标：第一次学 Guile，不是蹲着等蓄力，而是学会在普通防守、normal 和 spacing 里让 charge 一直存在。

## 1｜角色本质

### 一句话

**一边做普通SF6动作，一边保留Boom / Somersault资格；Boom限制地面，Somersault惩罚跳，normal再吃掉对手的犹豫。**

### S0｜最小可玩

先学五件事：

1. **down-back 是后台状态**
   - 蹲防时存；
   - 2LP / 2MP 等兼容动作时继续存；
   - 不要把“蓄力”理解成单独等待。

2. **Sonic Boom**
   - 横向限制；
   - 发完立刻继续看跳。

3. **Somersault**
   - 对手跳：有down charge就反空；
   - 没charge就不要假装有Flash Kick。

4. **两条确认**
   - 2LK > 2LP > H Somersault Kick
   - 5MP > 2MP > H Somersault Kick

5. **Block 0不是你的回合**
   - 5MP被防0F，重新读人。

S0目标：

**Boom → 看跳 / 地面 → Somersault或normal contact → knockdown → 重新存charge。**

### S1｜角落 +4

加入：

- 5MP > 4HP > H Somersault；
- corner H Somersault > 3HK whiff -> +4；
- throw / strike / walk-back shimmy；
- 6HP block +3；
- 学会为了位置主动放弃一次charge。

这里真正的新技能不是combo，而是：

**有时候charge比位置重要，有时候位置比charge重要。**

### S2｜Drive和Year4 OD Blade

加入：

- 4HP > CDR > 5MP block -> +4；
- DR > 5MP > 2HP > H Somersault；
- DR > 6MP > 2MP > H Somersault；
- OD Sonic Blade block +1。

注意：

**Drive Rush以后也要重新建立charge，不是高优势结束就变成普通无special角色。**

### S3｜Blade / Cross 与 +42

现在才加入：

- H Somersault > Sonic Blade；
- Sonic Cross / anti-air / space reset；
- 特定hit-height的H Somersault -> about +42 -> safe jump；
- Perfect Sonic Boom作为节奏/伤害优化。

禁止背：

**“H Somersault = +42”。**

正确说法是：

**只有匹配的hit-height / route state才进入+42 family。**

### S4｜Solid Puncher / SA

最后加入：

- SA2 Solid Puncher；
- HP-version SA1 +70 setplay；
- SA3 lethal；
- Perfect Boom / Somersault高阶执行；
- matchup-specific Boom cadence。

## 2｜工具地图

| 工具 | 第一用途 | 要记住什么 |
|---|---|---|
| Sonic Boom | 水平空间 | 发完继续看跳。 |
| Somersault | 反空 / ender | availability来自down charge。 |
| 5MP | medium confirm | 7F / Block 0。 |
| 2MP | charge-friendly confirm | 6F / Block -2。 |
| 4HP | back-direction route normal | 帮你把normal与charge管理接起来。 |
| Sonic Blade | 后置空间层 | S2/S3才系统学。 |
| OD Sonic Blade | Year4 plus layer | Block +1。 |
| Solid Puncher | 后期projectile system | S4。 |

## 3｜Core Loop

先只记：

**存charge → Boom → 看跳 → Somersault / normal confirm → knockdown → 重新存charge。**

角落以后：

**H Somersault → 3HK whiff → +4 → throw / strike / shimmy。**

把这两个循环跑顺，再学Blade / Cross / +42 / SA2。
