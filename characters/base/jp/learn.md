# JP — LEARN

> 目标：第一次学 JP，不是先背 portal 机关树，也不是站在最远处随机轮远程招。先学会让对手在远处也必须一直回答你的选择。

## 1｜角色本质

### 一句话

**先用 Stribog、Triglav、Torbalan 控制“现在的屏幕”；空间真的赚到后，再放 Departure，给“未来的屏幕”增加一个 portal 节点。**

JP 的核心不是“射程远”。

而是：

**对手离你很远，仍然不能安心。**

## S0｜最小可玩：没有 portal 也要能打一整局

先学三条稳定 confirm：

1. 2LP > 5LP > L Stribog
   - L Stribog 常见 +38

2. 5MK > M Stribog
   - grounded M Stribog 常见 +42

3. 2MP > 5LK > L Stribog

注意：

- L Stribog Block -10
- M Stribog Block -8

所以它们是 confirm ender，不是 raw pressure。

### Triglav

对手：
- 站着等
- 固定走地
- 在远处不愿意主动

你用：
- Triglav

命中常见 +44。

它的职责是：

**让“远处不动”也成为需要付代价的选择。**

### Torbalan

先只学一条明确branch：

- 5HP hit -> L Torbalan

grounded / spacing正确时可形成 +42 或更大budget。

不要把它和 M Stribog +42 混成一个“JP +42”。

### 对手跳

- 2HP anti-air

### 被贴近

5HK 被防：
- +2
- 先 2LP
- 对手开始等以后再 throw-read / walk-back 2MP

JP 不是一被贴就只能逃。

## S1｜现在才学 Departure

Departure 不是：

“有空就放一个portal。”

它更像：

**我已经赚到时间，所以把这段时间投资成未来的第二攻击点。**

第一条只学：

- 5HP airborne hit -> Departure
- 大约得到 +15 portal budget

然后问：

- 继续portal strike？
- low？
- throw？
- Window换位置？
- 还是根本不值得继续？

S1 里更重要的一条其实是：

**空间没赚到，就不要放 Departure。**

### Exact +42

grounded M Stribog +42：

- immediate forward jump HK
- safe-jump owner

或者：

- exact +42
- 2MK whiff
- 5HK active meaty
- 大约 Hit +10 / Block +5 family

数字必须和前置state绑在一起。

### Corner throw

当前 corner forward throw：
- +23
- dash 22F
- 剩 +1

只在corner成立。

## S2｜Portal 双位置状态机

现在才完整打开 portal。

Departure active以后，你同时看两个点：

1. JP 本体在哪里
2. portal 在哪里

### Shadow

portal attack继续让对手远程应答。

### Low

用portal-enabled 2LK / 2MK分支打只盯远程/站防的人。

### Throw

对手被remote威胁钉住以后，再加入throw。

### Window

不是“portal一亮就传送”。

你只有在：
- 换边值钱
- 能改变spacing
- 对手注意力被portal牵走

时才Window。

### Triglav -> OD Departure

更深一层：

5HP airborne hit  
-> Triglav  
-> OD Departure

大约形成 +4..+6 hybrid state。

这是“远程hit + portal + 近身”叠在一起，S2以后再学。

### Amnesia

当前 Year4 已经改变 aftermath。

所以只记：

**成功以后按 current state 重新判断。**

不要套旧版自动throw/follow-up。

## S3｜高预算空间状态

现在加入：

### OD Torbalan

Block：
- +25

这是 OD / Drive 资源状态。

普通 Torbalan 不是 +25。

### Embrace

只有对手已经被remote/portal威胁钉住时，command grab才值钱。

### Corner / exact setplay

再加入：
- corner Torbalan / Stribog active meaty
- deeper Shadow / Window side choice
- SA3 +23
- CA +44 exact meaty owner

## S4｜Lovushka

最后才学 SA2 Lovushka。

它本质上是：

**把 JP 已经会的 remote + portal 状态机持续更久、叠更多层。**

如果基础remote ordering和portal investment还不稳，Lovushka只会变成背脚本。

## 2｜工具地图

| 工具 | 第一用途 | 你要记住什么 |
|---|---|---|
| L Stribog | S0稳定ender | +38；Block -10。 |
| M Stribog | +42 exact owner | grounded hit +42；safe jump要绑state。 |
| Triglav | 远程地刺 | 打静止/走地；hit约+44。 |
| L Torbalan | remote projectile branch | grounded/spacing决定+42状态。 |
| 5HK | 近身plus | Block +2。 |
| Departure | future-space investment | S1以后，只在earned space。 |
| Departure: Window | teleport/换边 | portal state的一种选择，不是必按。 |
| Amnesia | defensive counter | current Year4 aftermath。 |
| OD Torbalan | high-budget pressure | Block +25，S3以后。 |

## 3｜Core Loop

S0：

**confirm -> Stribog knockdown -> Triglav / Torbalan remote answer -> opponent moves -> catch movement / anti-air -> repeat。**

S1：

**remote control earns time -> place Departure -> first portal decision -> return to remote control。**

S2：

**portal active -> Shadow / low / throw / Window by behavior -> portal expires -> rebuild screen control。**
