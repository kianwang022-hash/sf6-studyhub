# 杰米 Jamie — LEARN

> 目标：第一次学杰米时，不把“赶紧喝到 Lv4”当整局目标，而是先形成一条**正常地面接触→稳定 Arrow Kick 击倒→下一 Turn**的完整回合。安全喝酒是这条回合里的收益选择；每个 Drink Level 只增加当前真正需要的一层工具。完整路线、帧数与条件见 `reference.md`，状态跳转见 `play.yaml`。

## 1｜认识角色

### 一句话打法

**先用正常地面确认拿稳定击倒；击倒后判断这轮是继续压还是安全喝酒，再让每个 Drink Level 只增加一个新工具，避免等级系统绑架整场。**

### 深度角色模型

- **赢法**：5MP +2 与轻确认帮助你贴身；H Arrow Kick / L Arrow Kick / L Bakkai 给稳定 Oki。Drink Level 提升是奖励，让原来的击倒循环更强，不是开局任务。
- **最常见的输法**：为了喝酒放弃位置、等级一变就换整套打法、没确认就提交负帧特殊技、把 Lv3/Lv4 工具塞进最初学习。
- **资源原则**：Drive / SA / Drink 都只放大已经成立的接触。Drink Level 不是必须尽快填满的进度条。
- **防守原则**：先用通用防守、反空和明确的无敌资源解决真实威胁；防守成功后回中距离或明确 punish。
- **角色区别**：真正的 Jamie 学习不是“记四套角色”，而是同一个 Core Loop 随 Drink Level 增加少数新分支。

### 真正的学习方式｜先会不喝，再学什么时候喝

学习顺序按 **Whole → Part → Whole**：先打一条完全不依赖 Drink 的完整 Loop；哪一环断掉就只练那一环；修稳再回实战。S0–S4 是**同一套 Jamie 的击倒循环逐层增加 Drink 决策**。

#### S0｜最小可玩

先完全不追 Drink Level：

1. 5MP / 轻攻击和正常走位负责接触，典型跳跃先有稳定反空。
2. 轻确认 / 5MP→H Arrow Kick 先稳定。
3. H Arrow Kick 击倒后先固定一个打击答案。
4. 只有出现明显安全窗口，Drink 才作为可选奖励；不喝也必须能继续打完整局。

目标是**真人能反复出现完整 Loop**：地面接触 → 稳定击倒 → 固定下一 Turn → 对手脱出后回中距离。

#### S1｜基本功成型

开始学习“压还是喝”的第一层判断：

- 学 +42 L Arrow Kick 与 Bitter Strikes 等稳定击倒语义，先固定一套 Oki。
- 每次击倒先问：继续压的价值更高，还是现在真的安全喝酒？
- 被防允许停手，不播放命中路线。
- 挡明显大无敌 / 大破绽会稳定 punish；DI / 墙撞先认真实状态再兑现。

这一层结束时，主要损失不应该再反复来自**漏反空、漏确认、为了喝酒丢位置、漏确反、DI 不处理**。

#### S2｜实战结构化 · 冲 Master

让 Drink Level 只增加有限的新选择：

- Bakkai 解锁后仍从已确认接触进入，不因为“有新招”重写 neutral。
- +42 起攻对 mash / jump / tech / reversal 分别调整 strike / throw / shimmy / block。
- Hit / Block / Whiff 与资源决定是否进 Drive 路线，不自动烧槽。
- 每升一个 Drink Level 只新增当前真正有价值的一类工具，其余后置。

真正的进步是：**等级变化以后，你仍然知道这一轮为什么压、为什么喝、为什么停。**

#### S3｜选择成熟 · 1500 MR稳定

现在才把 Tenshin 与 Drink Level 差异系统化接进尊重树：

- Tenshin 只从已经建立尊重的近身回合使用；对手跳 / mash 多时回 strike。
- 同一次击倒按位置、等级、Drive 与血量选择继续压、喝、运版、伤害或斩杀。
- 等级变化后只调整受影响的工具 / 路线，不把 Jamie 重新学一遍。
- 复盘开始问“**这一杯酒换来了什么真实收益，是否值得放弃这次位置 / Turn**”。

**1500 MR 是持续 Reality evidence，不是能力定义。** 单次达到或短期掉分不能单独定义这一阶段。

#### S4｜高分上探

最后才加入高等级与高资源优化：

- Swagger Hermit Punch、Lv4 帧差变化、SA2 临时 Lv4 与资源最大化。
- Drink Level、位置、资源与具体帧差条件继续显式 conditioned。
- 回放重点转向：该喝、该压、该杀时有没有选到更高价值答案，而不是有没有尽快升到 Lv4。

具体高分 MR 不硬编码；由后续真实目标和持续表现决定。

### 暂时后置原则

Reference 里已经有完整 Drink 高等级工具，不代表早期就要全部进入训练。**先会不喝也能打一整局，再把喝酒变成回合价值判断。**

## 2｜工具地图

| 工具 | 第一用途 | 决策含义 / 风险 |
|---|---|---|
| **5MP** | 近身尊重枢纽 | 8F / hit +6 / block +2；先 strike/throw，再谈高级等级工具。 |
| **轻攻击链** | S0 最小确认 | 2LP 4F；2LP×2→5LK→H Arrow Kick。 |
| **H Arrow Kick** | 核心击倒 | +39；前冲后约 +16，能进入下一 Turn。 |
| **The Devil Inside** | Drink Level 资源动作 | 总时长 50F；只有安全窗口才喝，Lv4 后转 Drive 恢复。 |
| **L Arrow Kick / L Bakkai** | +42 Oki ender | S1/S2 后分别获得；中场双前冲 +4~5，角落 safe jump。 |
| **Tenshin / Swagger Hermit Punch** | S3/S4 扩展 | 最后才加，不改变核心地面语法。 |

## 3｜Neutral Map

### 远
没有必须做的事；走位 / Parry 靠近，只有安全窗口才单独 The Devil Inside。

### 中
2MK / 5MK / 5MP 找接触；2MK DRC 是资源型入口。

### 近
5MP +2、轻攻击、投；命中优先稳定 H Arrow Kick。

### 对手跳
→ `D01`。优先稳定反空；成功后明确回 Oki 或 Neutral，不让反空成为死节点。

### 对手一直防
→ `C06` 或 `T02`。先用普通投 / 正帧接触迫使对手改变，不因为 Drink Level 高就乱扩展。

### 对手爱按 / 拆投 / 凹
分别进入 `C01 / C02 / C04`；这些行为改变下一次 Turn，而不是只记“对策招式”。

## 4｜Core Loop

`N02 → T01 → R01 → E01 → O01 → T02 → N02`

中文展开：**正常地面接触 → H Arrow Kick 稳定击倒 → 先完成下一 Turn → 真有安全窗口再决定喝酒 → 等级只逐步增加新工具 → 对手逃出后回 Neutral。**

核心 Loop 的约束：Starter 先分 Hit / Block / Whiff；命中优先稳定；Ender 声明真实结果；Drink 不能把“下一 Turn”偷换成“每次击倒都喝”。

## 5｜Lv0–Lv4 与 S0–S4 的关系

`Lv0–Lv4` 是底层内容解锁语义；`S0–S4` 是 learner-facing 长期学习阶段。高 Drink Level、Tenshin、Swagger、SA2 即使已经在资料库，也不会越级成为当前训练主线。
