# 肯 Ken — LEARN

> 目标：第一次学肯时，不是把 Quick Dash、Jinrai、Dragonlash、角落和 SA 一次背完，而是先建立一条**普通 shoto 接触 → 稳定击倒 → +6 下一轮**，同时尽早加入一条真正属于 Ken 的 carry 路线。详细帧数、完整路线和条件见 `reference.md`。

## 1｜认识角色

### 一句话打法

**肯不是“更快的隆”。他把普通接触不断换成更好的屏幕位置和下一轮：伤害、运角、击倒、角落状态和 SA，核心是选对 end-state。**

### 深度角色模型

从隆转到肯，Hadoken、Shoryuken、2MK 取消绿冲、strike / throw / shimmy 都可以直接继承。真正新增的能力发生在命中以后：肯经常可以把同一个 opening 换成 **稳定 +6 起攻、Quick Dash Tatsu 运角、角落 +5 setplay、更多伤害或 SA**。

这意味着你不能只问“哪条 Combo 伤害最高”。如果一次普通命中能把对手送到墙边，让下一轮投 / shimmy / meaty 都更值钱，那么少一点眼前伤害可能反而更强。反过来，如果已经在角落，继续追求 carry 就没有意义，应该开始比较稳定 Oki、damage 或资源现金化。

Quick Dash、Jinrai 和 H Dragonlash 都是肯的特色，但它们不是“按了就继续我的回合”的按钮。Quick Dash 主要改变路线和距离；Jinrai 每个 follow-up 的风险不同；H Dragonlash 虽然被防 +1，但发生 28F。肯成熟以后会用这些工具逼对手改变防守，而不是机械地一直向前。

### S0｜最小可玩

先只跑通这一整轮：

1. **中距离**：Hadoken / 5HK / 2MK 控位置；发波后继续看跳。
2. **反空**：典型跳跃优先 Shoryuken，来不及用 2HP。
3. **两条稳定确认**：
   - `2MP > 5LK > H Shoryuken`
   - `2LK > 2LP > 5LK > H Shoryuken`
4. **固定下一轮**：H Shoryuken 命中常见 `+25 → forward dash → 约 +6`，先只保留一个 strike。
5. **一条 Ken carry**：`j.HP > 5MP > 5HP > Quick Dash > Tatsu`。

你第一阶段的目标不是“会 Quick Dash”，而是**真人里能主动出现完整循环，并开始意识到有些命中应该换位置，而不是换最大伤害。**

### S1｜基本功成型

当 +6 固定 strike 稳定后，再逐个加入：

- 普通投；
- 后走 shimmy；
- 挡无敌技后的 PC punish；
- 第一套角落 +5 frame-kill family；
- 2MP 被防 0、2MK 被防 -6 时的停手纪律。

这一阶段结束时，主要损失不应该再来自漏对空、漏确认、漏大确反、基础 Oki 或墙角稳定路线。

### S2｜实战结构化 · 冲 Master

现在才把 `2MK DRC` 加进主循环。

核心不是多一条 Combo，而是开始分流：

- Hit：Easy carry；
- Block：已经 DRC 才进入 strike / throw / shimmy；
- Whiff：不补票，不白花 3 Drive。

DI 也开始按位置拆：

- 版中：优先 carry；
- 墙撞：保墙；
- 自己背墙：先修位置。

这时你应该开始说得清：**为什么这次选 carry，而不是 damage。**

### S3｜选择成熟 · 1500 MR稳定

到这里，Ken 的角色专属工具才真正进入选择树：

- Quick Dash Forward Step Kick：Year 4 更快，但 block -4，命中也只是 +1；
- H Dragonlash：block +1，但 28F startup；
- Jinrai：每个 follow-up 按具体 hit/block 状态学，不背成万能字符串；
- 同一个 starter 开始在 +6 / carry / corner +5 / damage / stop 之间真正分流。

1500 MR 只作为持续 Reality evidence，不替代行为证据。

### S4｜高分上探

最后才加入：

- SA1 / SA2 / SA3 现金化；
- 角落 active-frame meaty；
- 特定 spacing 的 Forward Step Kick / Dragonlash；
- matchup-specific Jinrai / Quick Dash 频率优化。

任何窄条件 setplay 在 Training Mode 没闭合前，都只留 Reference / backend，不变成你的固定口诀。

## 2｜工具地图

| 工具 | 第一用途 | 决策含义 |
|---|---|---|
| **5HK** | 中距离占位 / PC | 不是 combo starter 自动机，先承担空间控制。 |
| **2MP** | 近身主确认 | 6F，Hit +5，Block 0；Year 4 后很稳定。 |
| **2MK** | 低段 + DRC入口 | Block -6；没有 DRC 就不要假装还在压。 |
| **Hadoken** | 中距离飞道 | 发波后继续看跳与 Drive。 |
| **Shoryuken** | 反空 / 稳定 ender | +25 → dash +6 是第一套 Oki 标尺。 |
| **Quick Dash** | 路线 / 距离转换 | 用来买 carry / end-state，不是万能进场。 |
| **Jinrai Kick** | 分支压力 / 角落路线 | 每个 follow-up 单独学，不视为一条安全字符串。 |
| **H Dragonlash** | 条件化推进 | Block +1 但 28F startup；只看 +1 会误判。 |

## 3｜Core Loop

先只记：

**控中距离 → 对空 / 2MP / Light 拿接触 → H Shoryuken → dash +6 → strike → 对手脱出后回中距离。**

然后只多加一个 Ken 分支：

**大接触 → Quick Dash Tatsu → 看是否到角落 → 到角落开始墙角循环。**

这两条能在真人里反复跑起来，才继续长 DRC、Jinrai 和 SA。
