# Manon — LEARN

> 目标：第一次学 Manon，不是背 Medal 五档伤害，也不是开局就追 command grab。先把普通 strike / throw / Oki 打稳，再让 Medal 慢慢改变未来回报。

## 1｜角色本质

### 一句话

**先用普通 Rond-point / Renversé / dash Oki 赢回合；拿到 Medal 以后，未来 throw 变得更痛，对手更想跳/抢，strike 也因此越来越值钱。**

### S0｜最小可玩：先当普通角色打

先学：

1. 2LP > 2LP > H Rond-point
2. 5MP > Drive Rush > 2MP > 4HP > M Renversé
3. jump-in > 4HP > M Renversé
4. 2HP anti-air
5. H Rond-point 结束后：
   - forward dash > strike
   - forward dash > normal throw
   - forward dash > shimmy
   - forward dash > block vs reversal

S0 不要求背 Medal 表。

你只要知道：

**Renversé / Manège Doré 成功以后，会提高未来收益。**

### S1｜第一次 Medal

等普通 Oki 稳定以后，才主动找一次 Medal interaction：

- 对手开始 respect / point-blank：
  - H Manège Doré
- 对手 jump / mash：
  - strike / anti-air
- 对手 throw-tech：
  - shimmy

普通 throw 或 Manège Doré 之后的 forward dash **不是 guaranteed throw**。

继续读人。

### S2｜Medal 开始改变对手行为

Lv2–3 以后，不要只看“我现在抓多痛”。

开始看：

- 对手是不是更爱 jump？
- 是不是更爱 mash？
- 是不是更爱 reversal？
- 是不是宁可吃 strike 也不想被抓？

如果答案是“是”，那 strike / anti-air 的价值已经被 Medal 提高了。

### S3｜高 Medal

Lv4–5 时：

- command grab 很痛；
- 对手逃 grab 的意愿也更强。

所以高 Medal 的正确理解不是：

**“我现在更应该抓。”**

而是：

**“我现在的 grab 威胁更大，所以对手更容易暴露给 strike。”**

这一层才需要熟悉详细 Medal damage table。

### S4｜SA / Lethal

最后加入：

- SA3 / CA Medal scaling；
- high-resource anti-air route；
- corner / Burnout；
- lethal calculation；
- matchup-specific grab frequency。

## 2｜工具地图

| 工具 | 第一用途 | 要记住什么 |
|---|---|---|
| H Rond-point | S0 stable ender | 后接 dash Oki；不编固定KD数字。 |
| M Renversé | route / Medal growth | 伤害随 Medal 变化。 |
| H Manège Doré | command grab | 5F；S1以后尊重/read下使用。 |
| 2MP | ground confirm | 7F / Hit +6 / C。 |
| Révérence | pressure normal | Block +1。 |
| Medal Level | future reward | 不花掉；改变未来投技/route/SA收益。 |

## 3｜Core Loop

S0：

**contact → Rond-point / Renversé → dash strike/throw/shimmy → reset。**

S1：

**respect → one Medal interaction → future grab reward rises。**

S2以后：

**higher Medal → opponent escapes grab more → strike/anti-air gets stronger → respect returns → command grab becomes credible again。**
