# Marisa — LEARN

> 目标：第一次学 Marisa，不是“高伤所以一直蓄力”，也不是“有 command grab 就一直抓”。先用 strike 真正建立 respect，再让 Enfold 变值钱。

## 1｜角色本质

### 一句话

**先用高伤、armor 和稳定 meaty 让对手愿意站着防；只有这时，5F Enfold command grab 才进入主循环。**

### S0｜最小可玩：只练 strike / Oki

先学：

1. 2LK or 2LP > 2LP > L Dimachaerus > 6P
   - end state：+31

2. 5MP > MP > M Gladius
   - stable damage

3. 5MP > MP > M Dimachaerus > 6P
   - end state：+36

4. 2MP > M Gladius

5. 先认识 normal / charged 的差别：
   - charged 5HP / 4HP / Gladius 更慢，但换来更高 damage / plus / armor。
   - S0 不要求你每次都蓄满。

S0 完全不需要 Enfold。

目标是：

**contact → damage 或 +31/+36 Oki → meaty strike → 对手开始 respect。**

### S1｜Respect → Enfold

现在才加入：

- L Dimachaerus +31 -> frame kill -> 6HK active meaty；
- M Dimachaerus +36 -> DR 6HK；
- 对手开始站防以后：
  - immediate Enfold；
  - normal throw；
  - walk-back / shimmy。

真正循环：

**strike 很痛 → 对手想 block → Enfold 变强 → 对手 jump/backwalk → strike/shimmy 又变强。**

如果对手根本不 block，就继续 strike，不需要 command grab。

### S2｜CDR / +42 Safe Jump

加入：

- 2MP CDR damage route；
- 2MP CDR -> H Phalanx +42；
- 5MP route -> H Phalanx +42；
- +42 -> immediate forward jump HP/HK safe jump；
- DR overhead。

开始比较三种结果：

1. 当前 damage；
2. +31/+36 Oki；
3. +42 safe jump。

### S3｜Charged / Scutum

现在才系统加入：

- fully charged 5HP block +5；
- fully charged 4HP block +4；
- charged Gladius block +4；
- corner charged 4HP vs Enfold；
- Scutum -> delayed Enfold / reversal bait；
- H Quadriga block +1。

关键：

**plus / armor 都来自真实的 charge commitment。**

charged 不是免费升级。

### S4｜Max Punish / Burnout / SA

最后加入：

- fully charged 5HP PC max punish；
- OD Quadriga corner route；
- Burnout Quadriga；
- SA cashout；
- matchup-specific armor / Enfold frequency。

## 2｜工具地图

| 工具 | 第一用途 | 你要记住什么 |
|---|---|---|
| M Gladius | S0 damage | normal版更快，charged版后置。 |
| L/M Dimachaerus | Oki | +31 / +36 是前两层核心。 |
| H Phalanx | safe jump | +42 属于明确 Phalanx ender。 |
| charged 5HP / 4HP | plus strike | S3 才系统学。 |
| Enfold | command grab | S1 起，必须建立在 respect 上。 |
| Scutum | read hub | S3 后置。 |
| H Quadriga | pressure | Year4 block +1。 |

## 3｜Core Loop

S0：

**ground contact → Gladius / Dimachaerus → +31/+36 → meaty strike → reset。**

S1：

**strike creates respect → Enfold → opponent escapes grab → strike / shimmy gets stronger。**

把这两个循环跑顺，再学 +42 和 charged / Scutum。
