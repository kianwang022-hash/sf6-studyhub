# 桑吉尔夫 Zangief — LEARN

> 目标：第一次学桑吉时，不把角色缩成“找机会猜 SPD”，而是先形成一条**走近→稳定接触→Lariat 击倒→追到下一次接触**的完整回合；等对手真的开始尊重你的打击，再把 SPD 接进同一棵选择树。详细路线与条件见 `reference.md`；Hit / Block / Whiff 与状态跳转由 `play.yaml` 管。

## 1｜认识角色

### 一句话打法

**先靠走位、DR 与正帧重拳把距离收近；用 Headbutt 等正帧工具建立“对手必须防”的尊重，再按防 / 按 / 跳 / 凹去选择 strike、SPD 或 block。**

### 深度角色模型

- **赢法**：不是靠猜一次 SPD，而是让对手在 6HP +4、DR 接触等状态里不断做防守决定；他们越怕投，strike 越赚钱，越怕打，SPD 才真正有价值。
- **最常见的输法**：远距离硬走不观察、没有正帧就裸 SPD、SPD 后默认仍是自动回合、追人过度耗 Drive。
- **舒服距离**：远距离任务是安全缩短距离；中距离用长按钮与 DR 取得接触；近距离才进入 6HP / 3MP / strike / SPD 的尊重游戏。
- **伤害与位置**：桑吉的高伤不等于每次都应该追最大数字；能否继续贴住、是否要保 Drive、是否已到角落都会改变兑现方式。
- **起攻 / reset**：Lariat 等击倒可以给追击机会；command grab 后续必须按实际距离与时序重建，**不是所有 SPD 命中都自动 Oki**。
- **防守**：先用通用防守、反空和明确 punish 解决真实威胁；防守成功后回到接近计划，不把“血厚”当作可以随便吃风险。

### 真正的学习方式｜同一套 Loop 逐层长分支

学习顺序按 **Whole → Part → Whole**：先让一整轮能跑；哪一环断了就只修哪一环；修稳马上回真人。S0–S4 不是五套桑吉，而是**同一套“接近→建立尊重→分流”的游戏逐渐长出 SPD 与高价值优化**。

#### S0｜最小可玩

先完全不要求“会读 SPD”：

1. 走位 / Parry / DR 缩短距离，不无脑烧 Drive。
2. 用 3MP / 可靠地面接触完成基础确认到 Lariat。
3. 典型跳跃用角色主对空稳定处理。
4. Lariat 击倒后先只保留一个 DR 追击后的稳定打击。

目标是**真人能反复出现完整 Loop**：走近 → 接触 → 稳定击倒 → 追到下一 Turn → 对手脱出后重新接近。

#### S1｜基本功成型

把高频免费价值补齐：

- 3MP 单发被防 -3，不把确认组件误当持续压力。
- Lariat 后 DR 追击先稳定一个打击答案，再逐个加入投 / 停手。
- 挡住明显大无敌技 / 大破绽会稳定 punish。
- DI / 墙撞先认真实状态，再拿稳定结果。
- 远距离不因急着贴身就连续烧 Drive 或乱跳。

这一层结束时，主要损失不应该再反复来自**进不去、漏反空、漏确认、漏确反、DI 不处理、Lariat 后续做不出来**。

#### S2｜实战结构化 · 冲 Master

开始建立“尊重”而不是直接猜：

- 6HP +4 / DR 正帧接触后，看对手是防、mash、jump 还是 reversal。
- 对 mash 提高可靠 strike；对 jump 保留覆盖 / 反空；对 reversal 加停手。
- 位置和 Drive 开始改变继续追、停、回 Neutral 的选择。
- SPD 仍然不是默认按钮，只是下一阶段准备加入的收益分支。

真正的进步是：**你开始知道为什么这一次对手应该尊重你，而不是单纯“我离得近所以转一圈”。**

#### S3｜选择成熟 · 1500 MR稳定

现在才把 SPD 接进已经建立的尊重树：

- 对手愿意防时增加 SPD；跳 / mash 多时回 strike；爱凹就增加 block。
- SPD 命中后按实际距离重新判断，不把 command grab 后续写成保证回合。
- 同一次机会按位置、Drive 与血量选择稳定 / 运版 / Oki / 伤害 / 斩杀。
- 复盘开始问“**我有没有先建立尊重，为什么这次 SPD 值得按**”。

**1500 MR 是持续 Reality evidence，不是能力定义。** 单次达到或短期掉分都不能单独定义这一阶段。

#### S4｜高分上探

最后才加入窄条件和高价值优化：

- OD Lariat +38、角落循环、SA1 anti-jump、SA2 / SA3 斩杀。
- 距离、投距、起身时序、角落与资源条件继续显式 conditioned。
- 回放重点从“有没有猜中 SPD”转向“已经逼出尊重后有没有拿到更高价值、对手适应后有没有及时换频率”。

具体高分 MR 不硬编码；由后续真实目标和持续表现决定。

### 暂时后置原则

Reference 里有 command grab、高资源、角落路线，不代表第一天就都要练。**SPD 是建立尊重后的收益放大器，不是最小可玩前置。**

## 2｜工具地图

| 工具 | 第一用途 | 决策含义 / 风险 |
|---|---|---|
| **6HP Headbutt** | 近身正帧枢纽 | 命中 +8 / 被防 +4；进入一次清晰下一选择。 |
| **3MP Hellstab** | 7F 可取消确认 | 命中接 Double Lariat；单发被防 -3，不当压力终点。 |
| **Double Lariat** | 稳定收尾 / 对空 | 普通 15F，OD 12F；击倒后进入距离条件化追击。 |
| **Screw Piledriver** | 尊重后的高收益投 | 全强度 5F；不是无正帧时的裸猜主线。 |
| **DR 6MK active** | 移动 + 正帧接触 | active hit 可 +7 / block +2，进入 strike / SPD / block 分流。 |
| **5HK / charged 5HP** | 地面大威胁 | 高回报也高承诺，不当无条件前进按钮。 |

## 3｜Neutral Map

### 远
走 / Parry / DR 缩短距离；保留跳跃和飞道应对。

### 中
5MP / 2MP / 6MK / 6HP 建立接触，目标是拿正帧或确认。

### 近
先 strike 建尊重，再 SPD；对手跳 / 按越多，越应提高打击比例。

### 对手跳
→ `D01`。优先稳定反空；成功后明确回 Oki / reset / Neutral，不让反空成为死节点。

### 对手一直防
→ `C06` 或 `T02`。先确认真正的正帧 / 投距，再逐步增加 SPD，不把“他挡着”直接翻译成必投。

### 对手爱按 / 跳 / 凹
分别进入对应 Counterplay；这些行为改变下一次 Turn，而不是只记一个克制招式。

## 4｜Core Loop

`N01 → N02 → T01 → R01 → E01 → O01 → T02 → N02`

**安全缩短距离 → 稳定接触 / Lariat 击倒 → 追到下一次正帧接触 → strike 建尊重 → 再逐步长出 SPD / block → 对手脱出后重新接近。**

核心 Loop 的约束：Starter 先分 Hit / Block / Whiff；命中优先稳定；Ender 声明真实 outcome；SPD 后续按实际距离 reset，不把 command grab 伪装成自动 Oki。

## 5｜Lv0–Lv4 与 S0–S4 的关系

`Lv0–Lv4` 是底层内容解锁语义；`S0–S4` 是 learner-facing 长期学习阶段。Lv3 的 SPD 即使早已存在于资料库，也不会越级成为第一学习目标。
