# SF6 Character Skill-Transfer Map

Status: **FROZEN learning-taxonomy baseline**  
Accepted from the 31-character Master route discussion, 2026-09-17.

## Purpose

This file answers a different question from `CHARACTER_PAGE_GOLD_CONTRACT.md`.

- Gold Contract asks: **What must a high-quality character page contain?**
- This map asks: **What kind of SF6 knowledge transfers into this character, and what new skill does this character add?**

The taxonomy is **not a strength ranking** and is **not a claim that every character inside a group plays the same**.

It is a learning-transfer map: the previous group should teach reusable SF6 skills that lower the cost of learning the next group.

---

## 1. Foundation — learn normal SF6 first

### Ryu

Primary job: establish the reusable game skeleton before character-specific systems dominate attention.

Transferable skills:

- walking / spacing
- ground normal contact
- anti-air DP
- projectile / jump interaction
- `2MK -> DRC`
- Raw Drive Rush
- strike / throw / shimmy
- knockdown -> Oki
- DI reaction
- punish
- SA conversion / kill

Ryu is the baseline, not because every other character is “a Ryu”, but because later differences are easier to understand after the ordinary rules are familiar.

---

## 2. Standard-character bridge

Recommended learning cluster:

`Ken -> Akuma -> Luke -> Terry -> Mai -> Sagat`

Shared transfer base:

- conventional ground buttons
- projectile / anti-air structure
- normal confirm -> special
- `2MK DRC`-style Drive conversion where applicable
- ordinary strike/throw pressure
- conventional punish structure

The point of the cluster is **not** to erase character identity. Each character must still explain what is newly added:

- Ken: corner carry / rushdown bias
- Akuma: more mobility/options with lower health tolerance
- Luke: modern midrange conversion rhythm
- Terry: own route / special structure while retaining familiar fundamentals
- Mai: projectile + mobility + stock/Boosted state and more stateful route decisions
- Sagat: heavier commitment to fireball zoning / space denial

---

## 3. Fast close-range / mobility characters

Recommended learning cluster:

`Cammy -> Juri -> Elena -> Yasmine -> Rashid -> Kimberly`

Transfer base from earlier groups:

- grounded spacing
- anti-air
- normal confirms
- knockdown pressure

New learning emphasis:

- faster movement and range entry
- pressure reset / re-entry
- resource or stance layers
- character-specific mobility
- more volatile offense trees

Important: do not teach this group as “six rushdown skins.”

Examples of identity differences:

- Cammy: very clean ground skeleton; then spacing-dependent Cannon Strike / Hooligan layers punish predictable defense
- Juri: stock/resource changes future options
- Rashid: mobility / air and corner/setplay structure
- Kimberly: movement and setup-specific pressure

---

## 4. Charge-system chapter

Recommended learning cluster:

`Guile -> Dee Jay -> E. Honda -> Blanka -> M. Bison`

Shared new skill:

> Charge is stored **while doing other actions**, not performed as a separate waiting phase.

Teach charge discipline explicitly:

- charge while walking backward / crouch-blocking
- hold one axis while performing another action
- preserve charge through normals where possible
- understand when mobility/pressure requires giving charge up

Character pages must then explain how each character uses charge differently rather than reducing the whole group to “charge characters.”

---

## 5. High-reward guess / command-grab / big-body chapter

Recommended learning cluster:

`Marisa -> Lily -> Manon -> Alex -> Zangief`

Transfer shift:

Earlier characters often ask:

> “How do I win neutral and confirm?”

This group increasingly asks:

> “How do I create one high-value decision, and how do I punish the opponent's answer?”

Skills to teach:

- respect creation
- command-grab threat
- strike / throw / command-grab feedback loops
- delayed timing
- walking pressure
- approach vs guaranteed Oki distinction

Zangief is the clearest endpoint:

> strike makes the opponent respect -> respect makes SPD threatening -> fear of SPD makes strike stronger again.

Combo count is therefore not a proxy for character-learning depth.

---

## 6. High character-specificity chapter

Recommended learning cluster:

`Jamie -> Chun-Li -> A.K.I. -> Ed -> JP -> Ingrid -> C. Viper -> Dhalsim`

These characters are placed late because a larger fraction of their decision model is character-specific, not because they are automatically weak or impossible.

Examples:

- Jamie: Drink Level changes future option space and creates “current pressure vs future power” decisions
- Chun-Li: stance + charge + route-specific structure
- A.K.I.: poison / movement / setplay-specific logic
- Ed: nonstandard button/special structure and Flicker/Psycho interactions
- JP: long-range control creates a substantially different neutral model
- C. Viper: execution / movement / cancel structure is unusually specific
- Dhalsim: range and mobility rules differ so strongly that ordinary neutral knowledge must be deliberately reinterpreted

Dhalsim is a useful final contrast because the learner can compare his rule-breaking against a well-established model of “normal SF6.”

## 7. Required per-character transfer model

Every Gold character asset must explicitly answer three questions:

### A. What transfers in?

Which already-learned SF6 skills still work here?

Examples:

- normal anti-air discipline
- `2MK DRC`
- charge storage
- strike/throw
- projectile control
- shimmy

### B. What is genuinely new?

What extra decision or execution skill does this character require?

Examples:

- Drink economy
- command-grab respect loop
- spacing-dependent divekick
- stock/Boosted routes
- stance transitions
- portal/trap control

### C. What must be unlearned / corrected?

What habit from earlier characters becomes misleading here?

Examples:

- “every knockdown means guaranteed close Oki”
- “every positive-looking divekick is actually plus”
- “resource should be built whenever possible”
- “all neutral is played from normal footsie range”

This three-part transfer model is mandatory for Character Understanding. It prevents the roster from becoming either 31 isolated encyclopedias or 31 Ryu-shaped templates.

---

## 8. Milestones

For an all-Master project, useful milestones are:

`Ryu Master -> 5 Masters -> 15 Masters -> 31 Masters`

The learning burden is expected to be front-loaded: the first character teaches SF6 itself, while later characters increasingly reuse established skills plus a smaller character-specific delta.

This is a curriculum assumption, not a guaranteed time prediction for any individual character.

---

## 9. Relationship to S0-S4

The transfer map and S0-S4 solve different problems.

- Transfer map: **what knowledge comes from previous characters vs what is new here**
- S0-S4: **how much of this character's own complexity should be active right now**

A strong Role page should make both visible without overloading the learner:

1. what you already know from previous characters;
2. the one or two new ideas that define this character;
3. the complete character model in plain language;
4. only then the S0-S4 practical progression.

Do not use the transfer groups as rigid page templates. The character remains the semantic center.
